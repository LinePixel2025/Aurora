## 发布链路卡点（本轮新增）

1. **Qoder 搜索守护进程锁住 `release/win-unpacked/resources/app.asar`**：`electron-builder` 覆盖时 `EBUSY`；`mv release` / `mv win-unpacked` 都 `Permission denied`。用 Restart Manager 定位到 `Qoder CN.exe ... qoder-search.bundle.mjs daemon-server`（文件索引，不是构建进程）。**不要杀 IDE**：改 `electron-builder --config.directories.output=release/alt-058` 打包到子目录，把 exe / blockmap / latest.yml 复制回 `release/`，再用 `release.mjs … --unpacked release/alt-058/win-unpacked` 校验真实解包目录。旧的 `release/win-unpacked` 已被上次失败打包删掉 `skills` / `app-update.yml` 且仍被锁；下次要么重启 Qoder，要么继续用 `--unpacked`。
