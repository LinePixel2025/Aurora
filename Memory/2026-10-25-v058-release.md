## 发布链路卡点（本轮新增）

1. **Qoder 搜索守护进程锁住 `release/win-unpacked/resources/app.asar`**：
   `electron-builder` 覆盖时 `EBUSY`；`mv release` / `mv win-unpacked` 都 `Permission denied`。
   用 Restart Manager 定位到 PID 的 `Qoder CN.exe ... qoder-search.bundle.mjs daemon-server`
   （文件索引，不是构建进程）。**不要杀 IDE**；改为 `electron-builder --config.directories.output=release/alt-058`
   打包到子目录，把 exe / blockmap / latest.yml 复制回 `release/`，再用
   `release.mjs … --unpacked release/alt-058/win-unpacked` 校验真实解包目录。
   旧的 `release/win-unpacked` 已被上次失败打包删掉 `skills` / `app-update.yml` 且仍被锁，
   下次发布要么重启 Qoder 释放，要么继续用 `--unpacked`。
2. **`git push origin`（HTTPS）被重置**：`--publish --push` 里 GitHub 上传已成功，只在
   `git push origin HEAD` 失败。改用 `git push git@github.com:LinePixel2025/Aurora.git HEAD:main v0.5.8`，
   再 `git update-ref refs/remotes/origin/main HEAD` 对齐跟踪引用。
3. **订单顺序**：先换装 Center（0.5.2，含新 shim/断流），再上传 v0.5.8 更新资产；
   `.env` 不在部署包里，换装前后 sha256 一致，`AURORA_CENTER_SECRET` 保持原值。
4. `--publish-center` 用 `admin` + `AURORA_CENTER_PASSWORD`（环境已就绪，一次登录成功）；
   日志与记忆均不记录密码。
