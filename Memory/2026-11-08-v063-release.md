## 本轮卡点

- **curl 探测 GitHub 200 不代表 git push 能通**：发布时 `curl https://github.com` 与
  `api.github.com` 都返回 200，但 `git push origin main` 仍报
  `Failed to connect to github.com port 443`。按既有 SSH 443 一次性 URL 推送成功
  （`git push git@github.com:LinePixel2025/Aurora.git main` / `v0.6.3`），随后
  `git update-ref refs/remotes/origin/main <sha>` 对齐跟踪引用。结论：**以 git push 的实际结果为准，
  失败就切 SSH，不要因 curl 200 反复重试 HTTPS**。
- **Center 密码从用户环境变量读取**：当前进程 `$env:AURORA_CENTER_PASSWORD` 为空，但
  `[Environment]::GetEnvironmentVariable('AURORA_CENTER_PASSWORD','User')` 有值；发布时用后者
  当次注入，不落盘、不回显。
- 发布流程仍拆四步：`release.mjs --notes-file`（构建 + 打包 + verify 15/15 + 打 tag）→
