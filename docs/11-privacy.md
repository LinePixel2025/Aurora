# 隐私说明

本页说明 Aurora 在你这台电脑上**存了什么、存在哪、什么时候会联网**。
设计原则一句话：**数据不出本机，除非是你自己配置的服务。**

## 1. 一句话总结

- Aurora **没有**自己的服务器，**没有**账号体系，**没有**遥测 / 埋点 / 崩溃上报。
- 你的文件、会话、分类记录、配置全部存在本机用户数据目录里。
- 只有这几种情况会联网：调用**你自己配置**的 AI 模型、连接**你自己配置**的 MCP 服务器、
  检查更新（只访问公开的 Releases 仓库）、读取**你自己配置**的 ClassIsland 桥接端点。
- 凭据（API Key / MCP 环境变量）用 Windows 自带的加密能力加密后落盘，永不写成明文。

---

## 2. 数据存在哪

全部在 `%APPDATA%\Aurora\`（即 `C:\Users\<你>\AppData\Roaming\Aurora\`）：

| 文件 / 目录 | 内容 | 你能做什么 |
|---|---|---|
| `config.json` | 全部设置（科目列表、课表、代理、MCP 服务器、窗口位置…）。**凭据字段是密文** | 可读可改；「设置 → 高级 → 导出脱敏配置」会生成一份把凭据替换为 `***` 的副本 |
| `sessions\*.json` | 对话历史（你说的话与模型的回复、工具调用记录） | 可在对话窗查看 / 清空；直接删文件也可以 |
| `classification.json` | 分类流水（最近 500 条：文件名、判定科目、依据、是否修正） | 设置页可清空 |
| `logs\aurora-YYYY-MM-DD.log` | 运行日志，**已脱敏**，按天轮转保留 7 天 | 设置页可打开目录 |
| `skills\` | 你的自定义 Skill（`SKILL.md`） | 完全由你控制 |

**卸载**：Aurora 的卸载程序不会主动删除这个目录（避免误删你的对话记录）。
想彻底清干净，卸载后手动删掉 `%APPDATA%\Aurora\` 即可。

## 3. 凭据如何保护

- AI 模型的 API Key 与 MCP 服务器的环境变量（可能含 token）经 Electron `safeStorage`
  加密后，以**密文**（形如 `v10:…` 的 base64）写入 `config.json`。
- 解密只发生在**运行时内存**里，且只在即将发起请求时进行。
- 设置界面的「只读显示」与 `settings:get` / `settings:changed` 两条 IPC 通道
  **只回传「是否已设置」这个布尔值**，密文本身不会进入界面进程。
- 若系统的加密能力不可用（极少数企业机器会禁用），Aurora **不会退化成明文**，
  而是让凭据只驻留内存 —— 重启后需要重新填写。启动日志里会有明确告警。
- 日志、错误信息与「导出脱敏配置」中的凭据一律替换为 `***`。

## 4. 什么情况下会联网

Aurora 的所有出网请求都源自**你的配置**，没有硬编码的服务地址（更新源除外，见下）：

| 场景 | 目标 | 发送的内容 |
|---|---|---|
| AI 对话 / 分类判定 / 上下文摘要 | 你在「设置 → AI 模型」里填写的 `baseURL` | 你的提问、会话历史、被归类文件提取出的文字 |
| 「测试连接」 | 同上 | 一次最小请求，用于验证地址与 Key |
| MCP 工具调用 | 你在「设置 → MCP」里配置的服务器 | 模型决定的工具参数 |
| 检查更新 | 公开的 Releases 仓库（打包时内置） | 只读取版本信息，**不发送任何本地数据**；客户端不带任何凭证 |
| ClassIsland 桥接 | 你填写的本地文件 / `127.0.0.1` 端点 | 只读，不发送任何内容 |

**请注意**：当你把资料交给云端模型时，文件内容会离开本机——这是使用云端 AI 的固有含义，
不是 Aurora 额外的行为。想避免出网，可以：

- 使用本地模型（「AI 模型」预设里的「本地 / 自定义」，指向 Ollama / vLLM 等本地服务）；
- 或在「设置 → 模式 → ClassRoom → 分类行为」里关掉自动分类，只手动与模型对话。

代理设置只改变请求的**转发路径**，不会改变上面的数据流向。

## 5. 日志与导出

- 日志写入 `%APPDATA%\Aurora\logs\`，按天一个文件，保留 7 天，超期自动清理。
- 写入前统一脱敏：字段名匹配 `apiKey` / `token` / `authorization` / `secret` /
  `password` / `credential` / `envEnc` 的，值一律替换成 `***`。
- 日志只记**元数据**（文件名、时长、错误码、状态），不记录文件正文与对话正文。
- 「导出脱敏配置」生成的是完整配置的副本，凭据位置为 `***`，可安全分享给他人排障。

## 6. 权限与系统能力

Aurora 是桌面应用，不需要管理员权限。它会用到：

| 能力 | 用途 | 能否关闭 |
|---|---|---|
| 读写你指定的「智慧感知文件夹」 | 文件分类 | 不配置该文件夹即不启用 |
| 全局快捷键注册 | 唤出 AI 交互窗 | 可在设置里改绑；占用失败不影响其他功能 |
| 系统通知 | 分类完成、课前提醒 | 由 Windows 通知设置控制 |
| 读取前台窗口标题与应用名 | 让模型知道你在用什么程序 | 「系统感知」的一部分，采集失败会降级为「未采集」，不阻塞 |
| 读取电源 / 网络状态 | 同上 | 同上 |
| 开机自启 | 常驻托盘 | 设置页可关，默认关闭 |
| 打开资源管理器窗口 | 课前打开科目文件夹、点通知打开目录 | 关掉课前提醒即不触发 |

**不做的事**：不录屏、不读键盘输入、不访问通讯录 / 相机 / 麦克风、
不修改系统设置、不以管理员身份运行、不安装驱动或服务。

MCP 服务器以你显式配置的**参数数组**启动，**绝不经过 shell** ——
因此配置里的参数不会被解释成 shell 命令。
Skill 目录下的 `scripts/` **永远不会被自动执行**（技能只提供指令文本）。

## 7. 你可以怎么核对

不信任说明文档是合理的。以下方式可以自行验证：

1. **看配置文件**：打开 `%APPDATA%\Aurora\config.json`，确认凭据字段是
   不可读的密文而不是你的 API Key。
2. **看网络**：用任何抓包 / 防火墙工具观察 Aurora 的出网目标，
   应当只出现你自己填写的模型地址、MCP 地址与 Releases 仓库。
3. **看源码**：本项目源码可复核。所有出网请求集中在
   `packages/agent-core/src/llm/` 与 `packages/agent-core/src/mcp/`；
   代理与网络栈接线在 `apps/desktop/src/main/net.ts`；
   脱敏逻辑在 `packages/shared/src/config/store.ts` 的 `redactKeys`。
