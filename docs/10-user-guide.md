## 1. 安装

从 [Releases](https://github.com/aurora-desktop/aurora-releases/releases) 下载
`Aurora-Setup-<版本>.exe` 并双击安装。

### 关于 SmartScreen 的提示

安装包目前**没有代码签名**，Windows 首次运行会显示蓝色的
「Windows 已保护你的电脑 / 未知发行者」。这是未签名程序的正常提示，不是病毒告警。

继续方式：点「更多信息」→「仍要运行」。

> 为什么不做签名：代码签名证书需要按年购买。Aurora 是本地工具，源码与产物都可复核
> （见 [隐私说明](./11-privacy.md)）。接入证书后这条提示会自动消失。

### 系统要求

- Windows 10 / 11（64 位）
- 无需单独安装 .NET 或 Node

## 2. 首次启动：引导五步

首次启动会弹出引导向导，五步完成基础配置：

1. **欢迎**：说明 Aurora 做什么（常驻托盘，随时可用）。
2. **AI 模型**（必填）：选择预设（DeepSeek / OpenAI / 本地），填 `baseURL`、
   **模型名**与 **API Key**。填完必须点「测试连接」——它会真的发一次请求，
   失败会告诉你具体原因（Key 错、地址不通、模型名不存在）。
3. **选择模式**：默认推荐 **ClassRoom**（学生场景，当前唯一完整实现）；
   Work / Code 目前是占位（见 [已知限制](../AGENTS.md)）。
4. **模式设置**：ClassRoom 会走四步对话式引导（感知文件夹 → 科目 → 科目文件夹 → 课前提醒）。
5. **完成**。

引导随时可以重跑：「设置 → 模式 → 重新引导」。

> **API Key 存在哪？** 用 Windows 自带的加密（Electron `safeStorage`）加密后写入
> `%APPDATA%\Aurora\config.json`，**不会**明文落盘；界面与导出里只显示「已设置」。
> 详见 [隐私说明](./11-privacy.md)。

## 3. 四个窗口

| 窗口 | 怎么打开 | 用途 |
|---|---|---|
| **提示条** | 默认常驻在屏幕右缘；托盘菜单可显隐 | 8px 竖条（唯一常驻入口）；**悬停**展开面板看状态 / 模式 / 最近消息，**点击**呼出 AI 交互窗 |
| **AI 交互窗** | 点提示条；或托盘菜单 / 全局快捷键 | 完整对话：Markdown、流式回复、工具卡片、会话列表、分类流水 |
| **小 AI 交互窗** | 提示条面板上点「小窗对话」 | 320×480 精简对话，用独立的「快速会话」 |
| **设置窗** | 托盘菜单「设置」 | 常规 / 模式 / AI 模型 / Skill / MCP / 高级 |

> 「AI 服务窗」（顶置输入框 / 小圆球）已在 v0.6.0 后的前端刷新中**删除**，常驻入口收敛为
> 「提示条 + 托盘」；旧配置里的服务窗几何由配置迁移 v4 自动清理。

**对话窗支持拖拽发送文件**：把 PDF / Word / 文本 / 图片拖进对话区，
Aurora 会提取其中的文字交给模型（单个文件最多取 8000 字，一次最多 5 个）。
扫描版图片的文字**不会**被识别（OCR 暂未启用），只会带上文件名与尺寸。

**多会话**：对话窗左上「历史」可以查看所有会话、切换、或新建。小窗用独立的
「快速会话」，与对话窗的「完整会话」相互独立。

输入框里可以用：

- `/技能名`：显式调用某个 Skill（例如 `/system-status 现在几点`）
- `@技能名`：同上，会在输入框上方给出提示

## 4. ClassRoom：自动分类你的资料

设置好「智慧感知文件夹」后，**把文件拖进这个文件夹**，Aurora 会自动判断它属于哪个科目
并移动到对应科目文件夹，同时弹出通知（点通知可打开目标文件夹）。

判定顺序（越靠前越省钱、越快）：

1. **文件名规则**：文件名里含科目名，或命中你配置的关键词 → 直接归类，不调用模型。
2. **内容判定**：读取文件内容（PDF / Word / PPT / Excel / 文本）后交给模型判断科目。
3. **兜底**：置信度低于阈值或判断失败 → 进「待分类」文件夹并通知你确认，**不猜**。

**就地修正**：在 AI 交互窗的「分类流水」里，每条记录都能改成其他科目。修正后：

- 文件会被移到新科目文件夹；
- 这条修正会**沉淀成规则**，下次同类文件名直接命中规则，不再消耗模型调用。

**不移动文件**：如果只想要流水记录、不想让 Aurora 动你的文件，
在「设置 → 模式 → ClassRoom → 分类行为」里关掉「自动移动文件」。
此时文件会留在原地，Aurora 也不会重复处理同一个文件。

## 5. 课前自动打开科目文件夹

开启后，每节课**上课前 5 分钟**，Aurora 会：

1. 发一条系统通知（含科目与剩余分钟数）；
2. 自动打开该科目的文件夹，等你的资料就位。

课表有两种来源：

- **手动维护**（默认）：在「设置 → 模式 → ClassRoom → 课程表」里逐条添加
  （星期 × 开始 / 结束时间 → 科目）；
- **ClassIsland 联动**：见下一节。

勿扰时段（「设置 → 高级」）内不会提醒，也不会补发。

## 6. 接入 ClassIsland 课表

如果你用 [ClassIsland](https://classisland.tech/) 管理课表，可以让 Aurora 直接读它，
不必再手动维护一份。

**为什么要装一个桥接插件？** ClassIsland 是 .NET 应用，跨进程通信走命名管道，
且没有 HTTP API，Aurora 无法直接读取。桥接插件在 ClassIsland 内部把课表写成一份
本地 JSON，Aurora 只读这份文件（或它在 127.0.0.1 上开的只读端点）。

### 步骤

1. 构建并安装桥接插件：见
   [`integrations/classisland-bridge/README.md`](../integrations/classisland-bridge/README.md)
   （需要 .NET SDK 8.0+，用 `dotnet build -c Release`，把产物复制到
   `%APPDATA%\ClassIsland\Plugins\AuroraClassIslandBridge\`）。
2. 在 ClassIsland 里启用插件，确认它写出了 JSON 文件
   （默认 `%APPDATA%\ClassIsland\aurora-bridge\schedule.json`）。
3. 在 Aurora：「设置 → 模式 → ClassRoom → 课程表」
   - 「课程表来源」选 **ClassIsland 联动**
   - 「数据来源」选 **JSON 文件**（填上面那个文件路径）或 **本地 HTTP 端点**
     （填 `http://127.0.0.1:17945/schedule`）
4. 点「**测试连接**」。成功会显示今天有几节课；失败会给出具体原因。

### 需要注意

- **科目名要一致**：桥接数据里的科目名必须和 Aurora 科目列表里的名称相同，
  否则该节课会被跳过（Aurora 会在设置页与日志里给出告警）。
  两边叫法不同时，在桥接插件的配置里做一次映射。
- **课表里没有今天** → 显示 0 节课，课前提醒自然不触发（这是正常的，不是坏了）。
- 桥接不可用（插件没装 / 文件被删 / 端点超时）时，Aurora 会**当作今天没有课**继续运行，
  不会影响其他功能。
- 目前只同步「星期 × 节次 → 科目」，单双周、临时调课不在此列。

## 7. 快捷键与提示条

### 全局快捷键

默认是 `Alt+Space`：在任何程序里按下都能显示 / 收起 AI 交互窗。

> **`Alt+Space` 很可能注册失败**——它是 Windows 的系统窗口菜单键，通常已被系统占用。
> 设置页会明确显示「已注册」还是「被占用」。若被占用，改成 `Ctrl+Alt+空格`、
> `Ctrl+Shift+A` 之类即可（必须包含修饰键）。

改完保存立即生效，无需重启。快捷键只支持带修饰键的组合（避免误吞全局按键）。

### 提示条

- **透明度**：0.2 ～ 1.0，保存立即生效。
- **独立勿扰时段**：可以让提示条在某个时间段自动隐藏（例如晚自习时段不想被挡）。
  这与「设置 → 高级」里的勿扰时段是**两回事**：后者管的是主动打扰
  （课前提醒、敏感工具确认），本项只管提示条自己是否显示。

## 8. 网络代理

如果模型服务需要走代理（常见于国内访问 OpenAI，或公司网络要求），在
「设置 → 高级 → 系统代理」里填写，例如：

```
http://127.0.0.1:7890
```

也可以只写 `127.0.0.1:7890`（会自动补 `http://`）。支持 `socks5://`。

保存后**立即生效**：模型对话、「测试连接」、MCP 的 HTTP 传输都会走这个代理。
留空表示直连。改完不需要重启。

## 9. 常见问题

**Q：API Key 会不会被上传到别处？**
不会。凭据只在本机加密存储，只在调用**你自己配置的**模型服务时使用。
详见 [隐私说明](./11-privacy.md)。

**Q：为什么「测试连接」通过，但对话报错？**
两者走同一条网络路径了，若仍不一致，最可能是模型名不对——部分服务对
`/models` 列表宽松，但真正对话时要求精确的模型名。看日志
（「设置 → 高级 → 打开日志目录」）里的错误码会更清楚。

**Q：文件被分类错了怎么办？**
在 AI 交互窗的「分类流水」里点该条记录，改成正确科目。文件会被移过去，
并且同类文件名下次会自动按你的修正处理。要重置历史：设置页的「清空流水」
（不会删除已沉淀的规则）。

**Q：怎么把日志发给我看？**
「设置 → 高级 → 打开日志目录」，把当天的 `aurora-YYYY-MM-DD.log` 发出来即可。
日志已自动脱敏（API Key、token、password 等一律替换为 `***`），保留 7 天。

**Q：改了课程表要重启吗？**
不需要。课程表、模型配置、代理、日志级别、快捷键都是**改完即生效**。

**Q：托盘图标不见了？**
Windows 可能把它收进了隐藏图标区（点任务栏的 `^`）。Aurora 关掉窗口只是隐藏，
不会退出；要退出请右键托盘图标 → 退出。
