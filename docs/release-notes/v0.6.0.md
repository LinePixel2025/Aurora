# Aurora v0.6.0

本次版本汇总 **v0.5.9 → v0.6.0** 的全部更新。主线是 **Computer Use v39.2 的精简与收尾**
（顶部操作过程面板收敛为两层状态胶囊、结束即回前台、操作提示词强化）、**流光提醒的大屏可读性**
（卡片尺寸改为按显示器宽度取比例、字号随卡片流体放大）与**提示音可靠性重写**，以及
**设置页视觉收敛**与左栏 Center 药丸溢出修复。

本版**不改配置 Schema**（仍为 **v39**，无迁移，`notifications.size` 的取值与默认值也不变）、
**不改插件清单与宿主 API**（仍为 **v1**），已有配置 / 会话 / 插件 / 自动化数据全部保留；
Aurora Center 服务器**不随本版升级**（仍为 0.5.2，版本线独立）。

## 一、Computer Use v39.2：更少遮挡、结束即回前台、更强的操作提示词

- **顶部操作过程面板 → 两层状态胶囊**：窗口 **560×140 → 520×88**、贴在显示器顶边 **6px**，
  卡片按内容自适应（宽 ≤520、高 36–54）；只保留**当前步骤**（带步数、连续同动作 `×N`）与
  可选的**「下一步」**计划一行，**不再在屏幕上列历史步骤**（历史看对话状态条）。底色提到 94%
  不透明并加描边 / 阴影，顶部光带 **64 → 48px**，减少遮挡模型看屏与窗口标题栏。
- **结束即回前台**：`agent`（任务完成）/ `user`（状态条、托盘、快捷键停止）/ `idle`（闲置超时）/
  `budget`（动作上限）/ `error`（宿主失败）五种结束原因都会把主界面显示、最小化恢复并切回
  刚完成的会话；`settings` / `permission` / `model`（用户正在设置页改配置或切模型）/
  `system`（锁屏、休眠）/ `quit`（应用退出）**仍不抢焦点**。判据唯一一份在
  `apps/desktop/src/main/computer-use/foreground.ts`。
- **操作提示词强化**：运行说明与工具描述统一为「**截图看清现状 → 定位 → 同轮批量执行 2–4 步 →
  截图验收**」的循环，并补齐：
  - **定位优先级**：`computer_ui` 控件（先 `find` 再操作，不拉整棵树）→ `computer_window activate`
    + 快捷键 → 最后才用坐标点击；启动应用用 `computer_window launch`，不去桌面 / 开始菜单找图标；
  - **键盘输入前确认前台**是最近截图的目标窗口（`computer_keyboard` 会直接拒绝不一致的情况）；
  - **失败先重看**：目标窗口变了 / 命中测试失败 / 指针没落位 / 输入被拦时先重新截图确认现状，
    同一手段连续两次失败就换（UIA / 快捷键 / 请用户处理 UAC），不盲重试同一坐标。
- **授权结果带屏幕几何**：`computer_start` 回传各显示器的 id / 物理尺寸 / 缩放 / 物理原点，
  模型规划点击位置与窗口摆放不必先截一张图；截图结果会说明「顶部胶囊与光环是 Aurora 自己的
  浮层、不是被测应用」，避免模型把它们当成点击目标。
- 设置页 Computer Use 页与 docs/06 §28、docs/07 §7 同步；截图探针改为量卡片 / 窗口矩形并断言
  **没有历史行**。

## 二、流光提醒：大屏可读性与提示音可靠性

- **尺寸改为显示相对口径**：`notifications.size` 三档仍为 `compact` / `standard` / `large`，
  但卡片宽度改为按**所在显示器 DIP 宽度取比例**再夹取（紧凑 0.24 / 标准 0.36 / 宽大 0.46；
  夹取区间 460–700 / 640–1000 / 780–1280，且不超过「显示器宽 − 40」）。同一档在 1080p / 4K /
  投影上占相近比例，不再出现固定 360/420/480 在大屏上太小、后排看不清的问题。
  1920 屏落成 **460 / 691 / 883px**；1366 屏 460 / 640 / 780；2560 屏 614 / 922 / 1178；
  3840 屏 700 / 1000 / 1280。**取值与默认值不变，不升配置版本**。
- **字号随卡片流体放大**：卡片根节点作为容器查询锚点，标题 `clamp(19px, 3.3cqw, 34px)`、
  正文 `clamp(16px, 2.8cqw, 28px)`、内边距与文字间距同样按 `cqw` 放大，语义色条
  `clamp(3px, 0.5cqw, 5px)`，关闭按钮 `clamp(30px, 3.6cqw, 40px)` 锚定卡片右上角。
  1920 屏标准档：卡宽 ≈691px、标题 ≈23.6px、正文 ≈20px（旧值 420 / 13.5 / 12.5）。
- **高度不再做字符估算**：窗口首帧按固定 240px 显示，渲染层量出真实卡片高度后经 `banner:measure`
  立刻收缩到「卡片 + 24px」，多出来的透明区只存在约 1–2 帧（估算偏大是死区、偏小是裁字）。
- **提示音重写（修「有时不响」）**：Web Audio 现场合成三声上行音（A5 → C#6 → E6，三角波，
  快起慢落 0.72s），**模块级复用同一个 `AudioContext`**，播放前若 `state !== 'running'` 先
  `await resume()`，再从 `currentTime + 40ms` 开始调度 —— 旧实现每次新建上下文并把音符排在
  `currentTime`（挂起时为 0），上下文稍后恢复时音符已经过去，于是静默。每音峰值
  `0.26 × volume^0.7`（默认 60% 下 ≈0.18，旧实现 ≈0.03，几乎听不见），末尾接压缩器
  （-12dB / ratio 8）防叠加削波；失败一律静默降级。设置页音量行新增**「试听」**按钮，
  走同一个 `playBannerChime`，用来区分「Aurora 没响」与「系统没声」。
- 卡片窗 `autoplayPolicy` 显式钉成 `no-user-gesture-required`（与 Electron 默认一致，
  防将来默认变化让提示音变成「要用户先点一下」）。

## 三、设置页视觉收敛与左栏药丸溢出修复

- **侧栏 5 组收敛为 3 组**：**本机**（常规 / 会话管理 / 模式 / 提醒）／**智能**（AI 模型 / 语音 /
  Agent 设置 / Computer Use / 文件自感知）／**系统**（Aurora Center / 插件 / 高级）；条目顺序与
  标签不变（截图探针按 DOM 顺序读标签）。侧栏 200 → 208px、条目标高 34px、中文分组标题去掉
  大写字距，底部署名与内容区之间加发丝线。
- **每页统一骨架**：一页只有**一个页头**（标题 + 一句说明 + 下缘发丝线），区组统一为
  「标题 / 一句说明 / 字段行列表」三层，字段行之间用**发丝线**分隔而不是每项一张小卡；
  静止卡片只留 1px 描边（去掉投影与内高光），页面不再各自覆盖圆角与投影；空态与提示退成
  无框弱色文案（描边 + 填充会被读成输入框）。会话管理页补回页头并改用同一套页面骨架。
- **品牌行**：固定两行 —— `Aurora` + 发行线路小徽标 **`Line Production`**（9.5px 胶囊、
  强调色描边 + 10% 填充，纯标识不可交互），下一行 `设置`；两行总高约 40px，仍满足拖动区
  ≥32px 的探针下限。
- **左栏 Center 药丸溢出修复**：Center 药丸与模型徽标统一 `line-height: 18px` 对齐；
  Center 药丸不收缩、模型徽标允许收缩 + 省略号；按行内容宽三级让位（≤190px 有 Center 药丸时
  隐藏模型徽标、≤160px 隐藏 Center 药丸、≤150px 隐藏模型徽标），并把 `chat-nav-narrow`
  探针扩写成 Center + 模型**双药丸**压测（200 / 240 两点，量「不出 item / 不压相对时间 /
  item 无横向溢出」）。
- 截图夹具改为**窗口首读前种快照**，避免首帧读到旧数据；`settings-*` 各页与新品牌行探针同步。

## 四、兼容与迁移

- **配置 Schema 仍为 v39**：本版没有新增 / 修改字段，也没有迁移；`notifications.size` 三档的
  取值与默认值不变（`standard` 仍是默认），升级后旧配置原样生效，只是同一档在新版上更大更清晰。
- **插件清单 / 权限 / 宿主 API 仍为 v1**：已有插件无需修改；插件开发工具包仍停在 v0.5.9。
- **Aurora Center 服务器仍为 0.5.2**，版本线独立，本版不换装、不建 tag、不上传 GitHub。
- 现有配置、会话、插件、自动化数据全部保留（`%APPDATA%/Aurora` 不在安装目录内）；
  升级路径与 v0.5.9 相同（Center 源优先，GitHub Releases 回退）。
