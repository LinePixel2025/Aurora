# Aurora v0.4.0

本次版本是从 **v0.3.9** 到 **v0.4.0** 的完整更新，包含 Electron 44 升级、文件自感知与
记忆库、提示条自感知工作台、Aurora Glass 2.0、全局动效和多项窗口/界面修复。

## 一、运行时升级

- Electron：33.4.11 → **44.5.1**
- Chromium：130 → **152**
- Node.js：20.18 → **24.18.1**
- V8：13.0 → **15.2**

主进程、utility process 与原生模块统一使用 Electron 44 的运行时 ABI。升级带来更新的网页平台、
网络与安全栈，同时也要求剪贴板和部分事件 API 迁移。

## 二、文件自感知与知识库

- 新增 **文件自感知** 子系统：记录用户选定目录的文件变化与 Windows 最近使用记录。
- 支持 `.docx` / `.pptx` 后台内容分析；`.doc` / `.ppt` 只记录变化与使用，不伪造正文解析。
- `.docx` / `.pptx` 内嵌图片在用户显式同意正文出网后可随本轮分析；模型开启 `vision` 时读取视觉内容，
  否则只列图片元数据并明确标记“未读取图片视觉内容”。
- 每次分析使用隐藏会话 `awareness-<noteId>`，`origin: 'file-awareness'`，不进入主界面会话列表。
- 分析使用严格 JSON 返回；主进程负责校验、渲染 Markdown 与写盘，模型不能直接操作文件。
- 一份源文件对应一份稳定笔记，使用 `<!-- aurora:generated:start/end -->` 保护生成区；
  标记缺失或重复时停止自动更新并标记冲突。
- 知识库公开路径为 `<格式>/<首次感知日期>/<标题>--<fileId>.md`；同一源文件更新始终写回同一份笔记。
- 知识库根目录维护 `INDEX.md`，按格式与日期列出笔记链接、ID、来源、标签和摘要。
- 旧版私有目录笔记会在启动或配置重载时迁移；旧根目录笔记自动移动到新结构。
- 源文件删除不会删除笔记，只标记源文件不可用。
- 队列持久化：单进程并发 1，默认每日 20 个，单文件上限 50 MB；
  首次接管最多排队 100,000 个文件，超限会如实显示状态。

## 三、建议执行与提醒

- 模型返回可行动建议时，提示条可无需抢焦点地展开显示建议气泡。
- 建议支持 `action: { label, prompt }` 执行按钮。
- 点击执行会创建 Agent 空间的新会话，把建议 prompt 与来源上下文作为首轮输入，并打开主界面。
- 建议执行仍走既有工具权限、确认卡片和项目边界，不因“来自建议”而放宽。
- 同一 `noteId + sourceHash` 去重；忽略只影响当前版本，不删除笔记。

## 四、记忆库窗口

- 新增独立 **记忆库** 窗口（`memory`，1040×720，min 760×520，关闭 = 隐藏）。
- 左侧按源格式（docx / pptx）分组，组内按首次感知日期分组，支持搜索与冲突标红。
- 右侧安全渲染 Markdown 全文预览。
- 顶部支持「打开文件夹」「用系统打开当前笔记」「打开源文件」。
- 读取只允许知识库状态里登记的 noteId，不接受任意路径。
- 记忆库窗口补齐最小化 / 最大化 / 关闭按钮，主界面、设置与记忆库统一窗口材质和动效。

## 五、设置页与运行控制

- 设置页新增「文件自感知」（`?page=awareness`）。
- 支持显式联网同意、最多 3 个监控目录、知识库目录、最近使用开关、每日分析上限、单文件上限。
- 显示运行状态、队列进度、图片识别状态、记录列表、笔记数量与冲突摘要。
- 提供立即扫描、打开记忆库、打开知识库文件夹、清空历史。
- 未同意正文出网时，内容分析开关保持不可启用。
- “最近记录”页内只显示最近 5 条，超过后通过滚动弹窗查看完整记录。
- 配置 Schema 升级到 **v28**，新增默认关闭的 `fileAwareness` 分组；迁移 v27 → v28。

## 六、提示条自感知工作台

- 提示条展开宽度从 220px 调整为 **328px = 320px 工作台 + 8px 竖条**。
- 信息架构固定为：
  - 自感知状态总览
  - 可行动建议
  - 最近理解
  - 紧凑快速对话
  - 下一节课 / 系统状态 chips
- 底部保留「打开主界面 / 记忆库 / 设置」三个入口。
- 自感知数据只在展开态读取；收起态不轮询。
- 展开态通过 `onChanged` 事件驱动更新，并保留 30s 低频兜底。
- 修复提示条圆角面板外侧出现矩形原生材质或阴影的问题：提示条退出原生 Acrylic，
  改用自包含高不透明度圆角玻璃。

## 七、Aurora Glass 2.0 与动效

- 统一窗口画布、侧栏、顶部栏、输入区、设置、引导、提示条、记忆库与 Center 工作台的玻璃材质。
- 主界面、设置窗、记忆库使用 Windows 原生 Acrylic，可真实采样桌面和后方窗口。
- 左侧栏、右侧栏、设置侧栏、记忆库笔记列与 Center 导轨统一使用 `.rail-surface`：
  连续纵向高光、直线内缘、渐隐 hairline。
- 修复材质类补边框导致标签容量变化的问题：材质类只改已有边框颜色，不改变 `border-width` / `border`。
- 新增统一工作台入场动效：
  - `.anim-window`
  - `.anim-shell-left`
  - `.anim-shell-right`
  - `.anim-pane`
- 动效只使用 `opacity + transform`，位移 ≤ 8px、缩放 ≤ 0.5%、250ms，不使用常驻 `will-change`
  或无限循环。
- 设置页切换不再使用 `out-in`，避免透明 body + Acrylic 下页面停在空白过渡态。
- 修复 `Ctrl + +` 等窗口缩放快捷键，所有自家窗口支持 `Ctrl + -` / `Ctrl + +` / `Ctrl + 0`。

## 八、原生最大化与 Acrylic

- Electron 33 下 `backgroundMaterial: 'acrylic'` 在系统最大化后可能变灰、变白或永久破坏材质。
- Electron 44 已修复该链路；主界面、设置窗和记忆库恢复真正的系统 `maximize()` / `unmaximize()`。
- 移除旧版的工作区缩放、逻辑最大化状态与异步重试补丁。
- 实测最大化与还原后，Windows DWM 的 `DWMWA_SYSTEMBACKDROP_TYPE` 都保持 `3`（Acrylic）。
- 系统吸附、窗口动画和最大化语义恢复为 Windows 原生行为。

## 九、提示条透明窗口适配

- Electron 44 会对透明 frameless 窗口施加约 33 DIP 的平台最小宽度，收起态请求 8px 时会被夹取。
- 提示条继续请求目标尺寸，但使用实际窗口宽度贴回工作区边缘。
- 通过 `setShape()` 把可见与可交互区域精确裁成：
  - 收起态 8px
  - 展开态 328px
- 多余透明区不再绘制，也不接收鼠标事件。

## 十、Electron 44 API 迁移

- 剪贴板 API 全面 Promise 化：
  - `readText()` / `writeText()` 改为异步；
  - 图片读取改用 `clipboard.read()` + `ClipboardItem`；
  - `readImage()` 等旧窄接口移除。
- `console-message` 改用事件对象字段：
  - `level`
  - `message`
  - `lineNumber`
  - `sourceId`
