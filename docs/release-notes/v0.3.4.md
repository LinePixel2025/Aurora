# Aurora v0.3.4 更新说明

发布日期：2026-10-03 ｜ 安装包：`Aurora-Setup-0.3.4.exe`（Windows x64，未签名）

v0.3.3 之后的版本是一轮 **BUG 修复轮**：四条用户实测报上来的问题（Center 移动端滚动 /
菜单透明 / 语音输入、桌面左栏对话堆积、网页端提问卡）加一处界面减负（删掉右栏「办公能力」卡）。

**没有任何配置迁移**：配置版本仍是 **v25**，覆盖安装即用，凭据、项目、会话、自动化全不动。

同期 **Aurora Center 服务端更新到 0.3.5**（镜像 tag `aurora-center:0.3.5`）：提问卡多问透传、
移动端修复、语音输入的 HTTPS 引导都在网页包里 —— **服务端不更新的话，网页端修不到**。

---

## 📱 一、Center 移动端三处修复

用手机浏览器打开 Center 控制台，之前有三个"根本没法用"的问题，这一版一起修掉：

1. **对话界面滑不动**。根因在桌面与网页**共用**的「自动滚到底」引擎：它只认滚轮 /
   滚动条 / 翻页键这三种"人在滚"的信号，而手机触摸滑动不产生这些信号 ——
   于是引擎一直以为你"想贴着最新消息"，你每滑一下它就原样吸回底部。现在触摸拖动
   被当作与滚轮同级的真实输入：拖动即停跟随、拖回底部自动恢复跟随、抬手后的惯性滚动
   也不会被中途拽回。桌面端（含触屏笔记本）行为不变。
2. **二级菜单透明无底色**。移动端的设备栏 / 会话管理是浮在对话上的覆盖抽屉，底色用的
   却是"叠在实底上才成立"的半透明分层色 —— 抽屉后面的消息整片透出来。两枚抽屉换用
   不透明底色，暗浅两主题都核对过；网页验收里加了一条"抽屉必须完全不透明"的判据防回退。
3. **会话管理列表滚不动**。移动端样式把"撑满抽屉才能滚动"的高度约束拆掉了，
   会话一多整列被裁掉。恢复约束，列表多长都能滑。

## 🎙 二、HTTP 直连下语音输入的引导（Center 网页端）

浏览器的硬性安全限制：**非 HTTPS 页面不允许网页录音**（`getUserMedia` 不可用），
代码层绕不过。以 `http://IP:8787` 直连时点麦克风，之前只有一句干巴巴的提示，这一版改为：

- 你是从**域名**入口进来的（比如 `http://aurora.linetech.online`）→ 自动切到同路径的
  `https://` 并提示，语音输入直接可用；
- 你是 **IP 直连** → 明确提示「浏览器不允许网页录音，请用 HTTPS 域名访问」。

> 部署上域名走 Cloudflare 隧道（HTTPS 已就绪）；IP 直连入口继续保留作兜底，
> 只是它的语音输入受浏览器限制，朗读（TTS）不受影响。

## 🗂 三、桌面左栏：Center 单独分组 + 旧对话自动折叠

会话越攒越多后，左栏「Agent对话」区被撑爆，这一版两条口径：

- **Center 对话单独成组**：来自 Center 网页端的会话（会话 id 以 `center-` 开头的）
  从本地会话里拆出来，在 Agent对话区内渲染成独立的「Center」子分组（可折叠、带数量徽标、
  默认展开），不再和本地对话混在一串里。
- **旧对话自动折叠**：本地会话与 Center 分组各自**默认只展示最近 8 条**，更早的收进
  「更早 · N」折叠行（点开可见全部）。你正在用的会话哪怕排在后面也**永远可见**，
  不会出现"切到旧会话后列表里找不到"。

## 🙋 四、网页端提问卡补全（Center 0.3.5）

上一版提问卡上 web 后，转发链把三样东西弄丢了，这一版补齐：

- **一次多问**（`questions`）：之前网页端只渲染第一问，其余几问看不到也答不了 ——
  现在整卡分节渲染、一次提交；
- **"只能选不许填"**（`allowCustom: false`）：之前网页端总会显示自由输入框，
  现在与桌面端同口径，该挡的挡住；
- **逐问作答**（`answersByQuestion`）：之前多问的作答会被拍平成一串文字，模型分不清
  哪句答的是哪问 —— 现在按问分组透传。

## 🧹 五、右栏「办公能力」卡移除

Work 模式右栏里的「办公能力」提示卡（三条静态说明）已删除，右栏只剩任务清单等实际内容。

---

## 升级与部署

- **桌面端**：覆盖安装 `Aurora-Setup-0.3.4.exe` 即可。
- **Center 服务端**：0.3.4 → 0.3.5，数据目录（`./data`）不受影响；
  `docker compose up -d --build` 后网页强刷一次（旧网页包有缓存）。
  桌面端与 Center 版本号互相独立，但**建议一起更**：移动端修复与提问卡补全都在网页包里。
