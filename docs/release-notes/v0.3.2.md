# Aurora v0.3.2 更新说明

发布日期：2026-10-02 ｜ 安装包：`Aurora-Setup-0.3.2.exe`（Windows x64，未签名）

v0.3.1 之后的版本，三块内容：**Agent 的回复终于"排好版"了**（表格 / 公式 / 图表 / 高亮代码，
桌面与网页端同一套渲染）、**两个老问题修掉**（子代理跑错目录、设置页那个没用的「设为当前」）、
**Aurora Center 网页端跟着一起升级**。

**有一处配置迁移**：Schema 从 **v24** 升到 **v25**（移除已失效的全局「当前项目」字段）。
覆盖安装即用，项目清单、会话绑定、其余设置与凭据一个都不会被改。

---

## 📐 一、回复排版升级：表格、公式、图表、代码高亮

以前 Agent 的回复只会渲染标题、列表和代码块，稍微复杂一点的内容（一张对比表、一段公式、
一个流程）就退化成难读的纯文本。这一版补齐了：

| 能力 | 写法 | 长什么样 |
|---|---|---|
| 表格 | 标准 Markdown 表格 | 表头加粗、斑马纹、列对齐，宽表可横向滚 |
| 数学公式 | `$行内$` / `$$整段$$` | 专业排版（KaTeX），求和、矩阵、分数都正常 |
| 流程图 / 时序图 | ` ```mermaid ` 代码块 | 直接画成图（SVG），主题跟随深浅色 |
| 数据图表 | ` ```echarts ` + JSON 配置 | 柱状 / 折线 / 饼图等（canvas），配色跟随应用强调色 |
| 代码高亮 | ``` 后面写语言名 | 关键字 / 字符串 / 注释着色，认几十种常用语言 |
| 提示块 | `> [!NOTE]` / `> [!WARNING]` 等 | 带色条的提示卡，不再是普通引用 |
| 任务列表 | `- [ ]` / `- [x]` | 只读勾选框（对话不写入你的待办，那由任务卡负责） |
| 链接 | `[文字](网址)`、裸网址 | 可点击，外链新窗口打开（带防护属性） |
| 有序列表 / 删除线 / 水平线 | `1.` / `~~` / `---` | 与正文层级协调的样式 |
| 图片 | `![说明](网址)` | 降级为可点击的文字链接（远程图片受安全策略限制，不会自动加载） |

几件你会实际感受到的事：

1. **图表是"按需加载"的**：一条消息里没有图表时，这两个绘图库根本不会加载；
   有图表时进入视野才画，且同一条消息反复重画会直接复用结果 —— 长对话不会被拖慢。
2. **画不出来不会变空白**：语法写错时，图上会显示一句「渲染失败，已按源码展示：<原因>」，
   并把源码留在下面（可复制）。公式写错同理，以红字标出原文。
3. **每张图带三条工具**：复制源码、下载（流程图存 `.svg`、数据图存 `.png`）、查看大图。
4. **代码块可直接复制**：悬停右上角出现「复制」，复制的是纯代码、不带行号与高亮标签。
5. **公式与图表的字体随包自带**，完全离线可用，不需要联网加载任何东西。

## 🪟 二、桌面与 Aurora Center 网页端：同一套排版

网页端（Center Console）此前是另一份简化渲染器，两端样式会漂移。这一版起
**两端共用同一份渲染器与同一份样式**：你在桌面上看到一张表、一张流程图，
在 Center 网页端看到的是同一张 —— 包括配色在深浅色主题下的表现。

## 🔧 三、修掉的两个问题

1. **子代理跑错目录（重要）**：在某个项目里让主 Agent 派子代理去调研时，
   子代理此前会把"工作目录"解析成固定的 `桌面\Aurora` —— 于是它 grep 的文件、
   写下的文件全落在错误的目录里，报告中却看不出异常。现在子代理的工作目录与
   文件边界**跟随父会话**（它当前绑定的项目 / 工作目录），和主对话完全一致。
   子代理自己的任务清单位于独立空间，不会污染主对话的清单（这一点没有变化）。
2. **设置页「设为当前」按钮删了**：这个按钮从 v0.2 起就不再决定任何会话在哪个目录干活
   （会话的工作目录由"会话绑定项目"决定），留着只会让人以为点了就生效。现在项目区只做
   「登记 / 改名 / 重选目录 / 删除」；项目目录失效时该行会显示「目录不可用」提示与
   修复入口。左栏的「当前」徽标与「打开当前项目目录」按钮一并移除。

## 🛠 其他改动

- 思考过程（reasoning）在两端都按原有形态展示（浅色小字、可折叠）；本轮不动它的渲染方式。
- 安全基线不变：模型输出的任何原始 HTML 一律转义，链接协议白名单（`javascript:` 被拒），
  外链带 `rel="noopener noreferrer nofollow"`。
- 应用内渲染层 CSP 显式声明 `font-src 'self' data:`（公式字体本地化所需）。
- 安装包体积基本不变；首屏加载体积增加约 0.5MB（公式排版库），绘图库按需加载。

## 📦 升级说明

- 直接覆盖安装即可；配置自动从 v24 迁移到 v25（只删除已失效的字段）。
- 项目仍在：设置页「会话 → 项目」里登记的目录一个不少；会话与项目的绑定关系也不变。
- Aurora Center 服务端同步升级到 0.3.2（网页端排版与桌面端一致）。
