# Aurora v0.2.3 更新说明

发布日期：2026-09-27 ｜ 安装包：`Aurora-Setup-0.2.3.exe`（Windows x64，未签名）

这一版修复了 **「权限申请卡（确认卡）无法同步到 Aurora Center 网页端」** 的四类丢失场景，
并让 Center 网页端升级为 **真正的远程会话管理台**：可以管理客户端上的远程会话
（列表 / 切换 / 可见性 / 权限 / 项目）、**远程切换客户端的模型与思考等级**、查看
**Token 用量**。

配置 Schema **不变**（仍是 v17）：本版不迁移任何配置，覆盖安装即用。
会话级的新数据（可见性 / 权限覆盖 / 项目绑定）存在会话文件里，与配置版本无关。

---

## 🐛 一、修复：确认卡同步不到网页端（四类场景全堵）

上一版（v0.2.2）确认卡虽然会推送到 Center 网页端，但实测有四类场景会「丢了」：

### 1. 本地会话里让 Agent 发文件，网页端看不到申请

原来只有从网页端发起的远程会话（`center-` 开头）才会把确认卡推给 Center——
你在客户端本地会话里说「把这个文件发给 Aurora Center」，本机弹卡、网页端毫无动静。

现在：**`center_send_file`（对外发送文件）在任何会话里触发，确认卡都会同步推到
网页端**——它是把本机数据发往 Center 的动作，无论从哪发起都该让你看见并批复。
本地会话的其余活动照旧不出网（不会把你的日常对话推到网页端）。

### 2. auto 权限档把申请卡整个「吞掉」

`auto` 档的规则是「项目根之内免确认」。但发文件恰恰经常发生在项目根内——结果就是
**连本机都不弹卡，文件直接被传走**，网页端自然什么都收不到。

现在：**外发类工具（当前即 `center_send_file`）不受「根内免确认」约束**，三档权限下
都逐次弹卡确认（只读档则工具整体不可用）。文档口径见 docs/06 §11.2。

### 3. 网络抖动期间的申请静默丢失

连接器（客户端 ⇄ Center 的长连）短暂掉线 / 重连瞬间，确认请求会被直接丢弃。

现在：离线期间的确认请求进入**补发队列**（最多 20 条，重连后自动按序补发）；
长时间离线仍按原超时规则（60 秒）在本地按拒绝收尾，不会让工具挂起。

### 4. 网页端停在别的页面就看不见申请

确认卡原先只显示在「当前打开的那个会话」视图里——你停在客户端列表或别的会话上，
申请就躺在那里过期。

现在：控制台顶部新增**全局待批复确认卡栏**，列出所有未过期的权限申请（含本地会话
来源的），每条显示工具名 / 入参摘要 / 倒计时，可直接批准或拒绝；与各会话内的卡片
先到先得，任何一边批复即生效。

## 🖥️ 二、Center 网页端：远程会话管理台

新增「会话」面板（客户端详情区内，默认折叠），面向**客户端上的 `center-` 远程会话**：

- **会话列表**：枚举客户端上的远程会话（含历史会话——不再只显示本页签刚创建的那个），
  显示标题 / 会话 id / 更新时间；点击即可在网页端切换查看，事件流实时跟进；
- **在客户端打开**：一键让客户端主界面切到该会话（客户端聊天窗口同步切换，
  可直接接手继续对话）；
- **可见性开关**：控制该会话是否出现在客户端主界面左栏（默认可见；隐藏后客户端
  看不到它，但网页端仍可继续远程输入）；
- **会话级权限档**：为单个会话覆盖权限档（只读 / 逐次确认 / 自动）——只影响**这一个
  远程会话**的工具确认行为；客户端全局权限档仍然只能由用户在本机设置页调整，
  Center 改不了；
- **会话绑定项目**：为会话指定项目（决定该会话 Agent 的缺省工作目录、文件边界与
  AGENTS.md 注入），选项来自客户端的项目列表。

> 边界说明：会话权限一旦设置，目前无法从网页端恢复「跟随全局」，需在客户端侧处理；
> 本地会话对 Center 完全不可见、不可枚举、不可切换。

## 🧠 三、远程切换模型 / 思考等级 + Token 用量

- **模型与思考等级远程切换**：网页端可直接切换客户端的**激活模型提供商**、
  **模型**与**思考等级**（自动 / 低 / 中 / 高），可选项从客户端配置读取，改动即时生效；
  凭据（API Key）与接口地址**不在可改范围**，协议层面就无法触达。
- **Token 用量**：会话视图新增用量条——当前轮次与该会话累计的
  prompt / completion / 总 token 消耗，以及占上下文窗口的比例。

---

## 🔐 四、安全说明

- 会话级权限覆盖的作用面被限制在 Center 自己创建 / 可见的远程会话上；全局
  `agent.permissionMode` 与免确认命令模式仍只接受本机设置页修改（与历版口径一致）。
- 远程批准确认卡不绕过任何本地闸门：两条通道（本机卡片 / 网页端）先到先得、幂等，
  任何一边批准即放行、拒绝即拦下。
- 模型切换命令只接受「提供商 id / 模型名 / 思考等级」三个字段，API Key 与 baseUrl
  凭据路径在客户端侧硬编码拒绝。

---

## ⬆️ 五、升级说明

- **桌面端**：覆盖安装即可（配置 Schema 未变）。若你在用 Aurora Center，
  客户端会自动重连。
- **Center 服务器**：需同步升级到 v0.2.3 才能使用会话管理与模型切换（旧服务器会
  忽略新命令，其余功能不受影响）。部署方式见 `packages/center/deploy/README.md`。
- 确认卡的四类修复中，第 1 / 2 / 4 条只依赖桌面端升级即可生效；第 3 条（补发队列）
  两端同升效果最佳。
