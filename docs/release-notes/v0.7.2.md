# Aurora v0.7.2

本次版本汇总 **v0.7.1 → v0.7.2** 的全部更新。主线是 **Windows 10 原生材质适配修复**：
DWM 原生 Acrylic 只在 Windows 11 22H2（build 22621）及以上存在，Win10 上改为强制实色，
修掉「窗口被记成已挂材质、实际透明无模糊」造成的提示条裸漏桌面 / 面板发灰；
同时确认安装向导保留**安装目录选择**。配置 Schema 仍为 **v44**（无迁移、无字段变化），
插件清单与宿主 API 仍为 **v1**，Aurora Center 版本线不变。

## 一、Windows 10 原生材质适配（主线）

- **根因**：Electron 的 `setBackgroundMaterial()` 在 Win11 22H2 以下**静默 no-op、不抛错**
  （`shell/browser/native_window_views.cc` 里 `GetVersion() < WIN11_22H2` 直接 return）。
  旧实现只靠 try/catch 判断失败，Win10 上窗口照样被记入 `nativeGlassWindows`，并先把
  底色设成 `#00000000` —— 实际没有 DWM 模糊，提示条背后直接是桌面，主界面浅色档也会发灰。
- **主进程**：新增 `apps/desktop/src/main/glass-support.ts`，按 `process.getSystemVersion()`
  的 build **≥ 22621** 判定；`WindowManager.glassAllowed()` 在平台 / 窗口名单之后先过这一关。
  Win10（含最后的 19045）与 Win11 21H2 一律不挂材质，建窗即用不透明主题底色。
- **渲染层**：沙箱 preload 同步暴露 `app.nativeGlassSupported`（与主进程同名判据，
  沙箱不能 import 工作区包，两处手抄并在注释中互相指向）；`applyAppearance()` 在
  `nativeGlassSupported === false` 时强制 `data-glass="off"`，与手动关闭毛玻璃走同一套实色令牌
  —— 面板、输入区、提示条 tint 全部压成实色，不再出现「透明窗口 + 半透明 tint」。
- **Win11 行为不变**：22H2+ 仍按原样挂 Acrylic；`appearance.glass` 开关语义不变，
  Windows 11 上开关打开时与原版逐像素一致。
- **回归护栏**：
  - 新增单测 `glass-support.test.ts`（3 例）：22621+ 支持；19045 / 22000 不支持；非 Windows 与异常版本串不支持。
  - 冒烟新增 2 条断言：主进程诊断的 `nativeGlass` 必须与系统版本一致（非 Win11 不得标记 `chat`）；
    `data-glass` 必须与原生材质可用性一致。基线由 **295 → 297**。
- 文档：[07 §5.1](../07-ui-spec.md)、[AGENTS.md](../../AGENTS.md) 判据与冒烟基线同步。

## 二、安装向导保留安装目录选择

- 安装包继续使用 **NSIS 向导式安装**（`oneClick: false` + `allowToChangeInstallationDirectory: true`），
  安装时可进入「选择安装位置」页修改目录；`perMachine: false`（默认按用户安装）、
  `allowElevation: true` 保持不变。
- 打包配置补了显式注释（[electron-builder.yml](../../apps/desktop/electron-builder.yml)），
  防止后续有人误删其中任意一项退回固定目录 / 一键安装。
- 卸载仍保留 `%APPDATA%/Aurora` 配置与会话；需要彻底清除时手动删除该目录。

## 三、兼容性

- **Windows 10 x64（含 22H2 / 19045）**：全部核心功能可用；无桌面模糊，窗口与面板为实色。
- **Windows 11 21H2（22000）**：与 Win10 同路径（没有 22H2 的 DWM 材质接口），实色回退。
- **Windows 11 22H2+**：原生 Acrylic 行为与 v0.7.1 一致。
- **Windows 7 / 8.1 / 32 位**：仍不支持（Electron 23+ 最低 Win10 x64，且 Electron 44 已移除 ia32）。
- 配置 Schema 无变化（v44），升级不触发迁移、不丢配置 / 会话 / 插件 / 自动化数据。
