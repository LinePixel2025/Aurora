# Aurora v0.6.2

本次版本汇总 **v0.6.1 → v0.6.2** 的全部更新。四条主线：**智慧提醒**（免打扰期内的提醒先攒着，
期结束后由 Agent 汇总成一条投递，配置 Schema 随此升级到 **v40**）、**时间轮盘**（设置页与自动化
编辑器里所有「时刻」选择全部换成直观的钟面弹层）、**流光提醒三档视觉差异拉开**（紧凑 / 标准 /
宽大三档字号与密度真正分层）、**Computer Use 一组实测修复**（重复启动、截屏坐标错位、窗口
激活与弹出窗读取）。

本版配置 Schema 从 v39 升到 **v40**（新增智慧提醒字段的默认值，迁移自动完成，无感）；
插件清单与宿主 API 仍为 **v1**；Aurora Center 服务器**不随本版升级**（仍为 0.5.2，版本线
独立，本版无 Center 代码改动）。已有配置 / 会话 / 插件 / 自动化数据全部保留。

## 一、智慧提醒：免打扰期内先攒着，结束后汇总成一条（v40）

- 提醒页新增「智慧提醒」区组（总开关默认关）：开启后，免打扰期内的提醒**不再逐条弹出**，
  而是先进本机队列（上限 50 条），期结束后**结算成一条摘要投递**。
- 免打扰期有两个来源，命中任一即生效：
  - **手动时段**：开始 / 结束时刻（支持跨天，开始大于结束即跨午夜）；可「每天重复」，
    关闭重复则只在当天生效一次、期结束后自动清除；
  - **上课期间不提醒**：仅 ClassRoom 模式生效，按课程表判定是否正在上课（与课前提醒同源，
    ClassIsland 状态快照只展示不触发）。
- 期结束的时机：时段出窗 / 下课 / 总开关关闭 / 时段被清空，任一发生且队列非空即结算——
  不用等到第二天。
- 结算方式：「结束后由 Agent 总结」开启（默认）时，由模型把攒下的提醒**总结成一段摘要**
  投递；总结失败或开关关闭时，**逐条原文投递**——两种路径都不丢提醒。
- 边界（与既有语义一致）：`notify_banner` 与插件 `ctx.banner` 是**显式**流光请求、提问卡
  （ask_user）是定点交互提醒，都不受抑制；摘要投递自身跳过抑制闸（否则摘要也会被自己
  抑制成环）；流光通道下摘要卡片停留约 12 秒（内容长，6 秒读不完）。

## 二、时间轮盘：所有「时刻」选择改成钟面

- 之前的 5 组「时刻」输入，要么靠手打 `HH:mm` 文本（填错格式只有保存后才知道），要么是
  系统原生 time 弹层（外观与应用整体设计脱节）。本版引入统一的**时间轮盘**组件：
  - 字段行是一枚 36px 触发器按钮（时钟图标 + 当前时刻，未设置时显示示例时刻占位）；
  - 点开弹出钟面：外圈 **0–23** 小时刻度，点选或拖动指针取值，选完小时**自动切到分钟盘**
    （12 个 5 分钟刻度、拖动按 1 分钟步进）；顶部大号 `HH:mm` 两段可点击来回切换；
  - 底部「确定」才落盘，「清除」（有时段语义的字段提供）= 不启用；「取消」/ Esc /
    点击外部 / 滚动页面都只是关闭、不改任何值。
- 覆盖范围：智慧提醒免打扰时段、勿扰时段（提醒页与通用页两个入口）、提示条静默时段、
  课程表每一节次的起止时刻、自动化编辑器「每天定时」触发器的触发时刻。
- **时长类字段不变**（提前 N 分钟、流光停留 N 秒、各类超时毫秒——钟面表达时长并不直观，
  数字框与滑杆是它们的正确形态）。
- 字段的存储格式不变（仍是 `"HH:mm"` 字符串），旧值原样显示；「留空 = 不启用」「支持跨天
  开始大于结束」等保存语义与旧版完全一致。

## 三、流光提醒三档视觉差异拉开（v40）

- 弹窗大小三档此前只是宽度不同，本版把字号与密度也分层（字号仍随卡宽流体联动）：
  - **紧凑**：卡宽比例 0.20 的细窄条，标题下限 14px、正文下限 12.5px、正文至多 2 行——
    挂在桌面角落不抢视线；
  - **标准**：0.36 不变；
  - **宽大**：0.52 的半屏量级，标题上限 44px、正文上限 36px、内边距加大、正文至多 4 行——
    教室投影场景一眼可读。

## 四、Computer Use 一组实测修复

- **不再重复打开同一应用**：`launch` 启动前先查同应用是否已有运行中的窗口，已在运行就直接
  唤起（不再起第二个实例）；启动后没检测到新窗口时**不再误报失败**，而是提示模型先截图
  确认——此前这条误报会让模型换着法子再开一次。另加同参数 8 秒冷却防抖。
- **截屏与点击坐标不再错位**：截屏按**实际源图尺寸**换算物理坐标（Electron 缩略图尺寸不保证
  等于请求尺寸），窗口裁剪先在源图像素里裁再反算——高分屏 / 多显示器上「点不在截图里的位置」
  类问题根治。
- **同一应用 ≠ 同一进程**：微信 / 浏览器等多进程应用的截图目标与点击落点可能分属不同进程，
  旧校验按 pid 直接拒绝；现在同一窗口句柄 / 同一进程 / **同一可执行文件**都算同一目标，
  换了别的应用才报「目标已变化」；目标窗口被移动 / 缩放 / 最小化时明确报错要求重新截图。
- **窗口激活成功率**：后台窗口唤起改为多级兜底（BringWindowToTop + AttachThreadInput +
  SetForegroundWindow → SwitchToThisWindow → 系统 AppActivate），实测后台 Edge / 记事本
  互切均成功；仍被系统前台锁拒绝时返回可读原因而非裸失败。
- **系统弹出窗可读取**：快速设置等 UIA 弹出窗（不在常规窗口列表里）可按窗口句柄直取，
  不再误报「读取前台窗口失败」。
- **过程提示更完整**：每个动作的「下一步」计划改为必填，模型漏填时由内核用同一轮紧邻的
  下一个动作语义自动补上，顶部状态条不再出现空提示。

## 五、兼容性与升级

- 配置 v39 → v40 自动迁移（补智慧提醒默认值），升级无感；时间轮盘不改变任何字段的存储
  格式与保存语义。
- 自动更新：Center 更新源优先，GitHub Releases 回退，与 v0.6.1 相同。
- 已知边界（沿旧）：Windows 系统占用 `Alt+Space` 全局热键注册失败是预期路径（会回传原因，
  不静默）；未配置 STT / TTS provider 时对应按钮不渲染。
