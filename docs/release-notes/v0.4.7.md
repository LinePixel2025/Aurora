# Aurora v0.4.7

本次版本汇总 **v0.4.6 → v0.4.7** 的全部更新。由于桌面端安装包自 **v0.4.5** 起一直未重新发布
（v0.4.6 / v0.4.7 当时只动了 Center），本版安装包同时收进 v0.4.5 之后**全部桌面端改动**：
外观三件套（明暗档位 / 毛玻璃开关 / `set_appearance`）、提示条原生 Acrylic、输入卡工具行下限、
四周流光与「流光特效」开关。Center 侧本版沿用已部署的 0.4.7（后台工作台重构 ＋ 用量分页 ＋
官方模型配置表单）；桌面与 Center 的更新源、GitHub Releases 三者自本版起重新对齐。

## 一、桌面端 · 外观与个性化（配置 v32 → v33）

- **明暗档位**：设置 →「通用 → 外观」新增主题档位（跟随系统 / 亮色 / 暗色）。
  真值只有一处 —— 主进程写 `nativeTheme.themeSource`，渲染层走 `prefers-color-scheme`，
  四个窗口（提示条 / 主界面 / 设置 / 引导）与设置页各页一起跟随，改档即刻生效、无需重启。
- **毛玻璃开关**：可整体关闭毛玻璃。两处必须同时降级，本版做成**同一份配置驱动的两条腿**：
  主进程摘掉原生窗口材质，渲染层把 `.glass-*` 令牌压成实底（含被提示条浮层消费的那条回退令牌），
  不会出现「窗口变实色、面板还半透」的半关状态。
- **`set_appearance` 工具**：AI 侧新增外观工具（`sensitivity: 'safe'`，三个固定字段、无路径参数），
  与设置页写的是同一份配置；外观三件套同时进「可写面」清单，Agent 改完设置页即时同步。
- **四周流光与开关（v33）**：自感知流光从顶部一条改为**铺满显示器四周**（上下左右同一套极光，
  中部完全透明、鼠标事件照常穿透，不影响系统级输入）；「通用 → 外观」新增**流光特效**开关
  （`appearance.awarenessGlow`，默认开启）。配置版本 `CONFIG_VERSION 32 → 33`，旧配置自动迁移。

## 二、桌面端 · 提示条与输入卡

- **提示条恢复原生 Acrylic**：重新对提示条启用 Windows 原生毛玻璃材质，并用「窗口区域裁切」
  同时保住圆角 —— 圆角处不再露出矩形材质，收起态（8px 竖条）不挂材质、展开态挂上，
  材质与圆角是**同一条弧**。面板底 `panelAlpha 0.62`，暗浅两档都核对过。
- **输入卡工具行**：给工具行芯片加显式宽度下限，修掉「把左栏拉宽后，权限按钮与来源下拉重合」。
- **原生下拉跟随主题**：`<select>` 弹出列表（`option` 底色）跟随明暗档反色，暗档不再白底刺眼。
- **启动期模式广播**：渲染层改为**先订阅再加载**，避免启动瞬间的 `mode:changed` 被永久丢掉。
- **吸底跟随**：窗口从最小化 / 隐藏恢复可见时重启吸底心跳巡检，回到前台不再「跟丢」滚底。

## 三、Aurora Center（0.4.6 / 0.4.7）

### 用量页

- 筛选区新增「全部 / 近 7 天 / 近 30 天」快捷区间；手改日期自动切换为自定义区间并退选快捷项。
- 统计卡从 3 张改为 4 张：主卡「区间总计」展示 token 总量、请求次数与占终身比；
  输入 / 输出 / 缓存命中三张分项卡各带占比或命中率；token 数以 K / M 紧凑格式展示。
- 「最近请求」改为**服务端分页**（每页 15 条）：`GET /api/usage` 新增 `offset`，响应新增
  `recentTotal`；`totals` / `daily` / `lifetime` 仍按全量计算，翻页不影响 KPI 卡与折线图。
  页脚为 `首页 / 上一页 / 第 x / y 页 / 共 N 条 / 下一页 / 末页`，到界与读取中禁用；
  无记录不渲染分页条。筛选变化回第 1 页；请求失败不提交页码、不动表格；目标页越界自动夹回末页并只重取一次。
- 趋势图配色与主题令牌联动（输入 = 信号色渐变、输出 = 品牌蓝、命中 = 虚线灰），
  tooltip / 图例 / 坐标轴跟随暗浅主题；空数据不再是空白画布。设备列显示设备名而非裸 `clientId`。
- 图表 resize 加「宽度真变 + rAF 合帧」两道闸，避免滚动条抖动的宽度变化把重绘塞进每一帧。

### 管理端官方模型配置

- 表单重做：能力页签带**启用状态 / 开放模型数 / 未保存脏点**；字段成对给出字段名与一句说明
  （协议附上游端点路径、Base URL 提示末尾不要 `/`）；API Key 支持显示切换、保存状态 chip 与清除
  （`apiKey: null` 才清空，空串表示不修改）。
- 模型表有列名（开放 / 模型 ID / 显示名 / 能力参数 / 操作），空 ID 与重复 ID 当场标红，
  未开放行弱化显示；空态、`全部开放 / 全部关闭`、`还原` 齐备；≤720px 沿用全局表格卡片化。
- **「拉取模型」改为合并而不是替换**：既有条目（含开放位与能力参数）原样保留，上游新增的 id
  追加并**默认未开放**，并回报「新增 N / 保留 M」。
- 服务端 `adminConfig()` 的密钥异常原因（主密钥缺失 / 轮换后旧密文解不开）以警示条展示；
  前端校验与服务端同款规则对齐，服务端报错原文照旧展示。

### 官网入口与工作台

- 官网入口、登录后工作台与首屏性能一轮改进；官网顶栏改毛玻璃并修掉「内容透出叠字」的层级根因。
- 后台全站毛玻璃材质（侧栏 / 顶栏 / 控制台，含 `backdrop-filter` 不可用时的实底回退）与移动端适配：
  移动底部导航、控制台双抽屉实底、表格卡片化（≤720px 隐藏表头、按字段名分行）。

## 四、验收与测试

- 桌面端：`pnpm typecheck` / `pnpm lint` / `pnpm build` 全绿；`pnpm test` **171 文件 / 2554 用例**通过；
  `scripts/verify-p1.mjs` **26/26**（`version=33`、迁移 **33/33**）；端到端冒烟 **204/204**；
  窗口截图全量 94 项（暗 / 浅两档，唯一恒红项仍是范围外的既存项 `chat-model-picker.png`）；
  Center `verify:web` **88/88**（43 场景 × 暗浅两档 ＋ 2 个单档主题场景）。
- 新增探针：窄栏工具行、提示条材质与 tint、四周流光（四条边带贴边且沿边覆盖 ≥95% 视口、
  650ms 前后真有位移；主进程断言窗口矩形 ≥ 显示器 bounds）；全屏流光实测帧成本
  mean 4.81ms / worst 8.2ms（≈60fps）。
- 稳定性：四条抖动截图探针（吸底 / 归档 / 侧栏 / 流式突发）改为身份键 + 有界等待 + 离群容忍，
  隐藏窗口下不再整轮挂死。

## 五、升级说明

- **桌面端**：安装包 `Aurora-Setup-0.4.7.exe` 与 `latest.yml` 同时发布到 GitHub Releases 与
  Aurora Center 更新源，0.4.5 / 0.4.6 客户端会在下一次检查更新时升级到 0.4.7。
  已装旧版无需卸载；配置从 v32 / 更早版本自动迁移到 v33。
- **Center**：本版 Center 代码与已部署的 `aurora-center:0.4.7` 一致，无需重新换装；
  数据目录 `./data` 与 `.env`（含 `AURORA_CENTER_SECRET`）不受影响。
