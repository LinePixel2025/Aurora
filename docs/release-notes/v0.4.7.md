# Aurora v0.4.7

本次版本是从 **v0.4.6** 到 **v0.4.7** 的完整更新，Aurora Center 同步升级到 **0.4.7**；
桌面端本版无功能变更（安装包不重新发布，自动更新源保持 0.4.5/0.4.6 现状）。重点是把
Center 后台两处「用得最多、但一直将就」的界面做扎实：用量页的明细翻页、管理端官方模型配置表单。

## 一、用量页：最近请求分页

- 明细改为**服务端分页**：`GET /api/usage` 新增 `offset`，响应新增 `recentTotal`
  （过滤后的明细总数，与分页无关）；`totals` / `daily` / `lifetime` 仍按**全量**计算，
  翻页不会改变 KPI 卡与折线图。
- 网页端「最近请求」每页 **15 条**，页脚为 `首页 / 上一页 / 第 x / y 页 / 共 N 条 / 下一页 / 末页`，
  到界与读取中禁用；无记录时不渲染分页条（沿用空态文案）。
- 筛选条件变化回第 1 页；请求失败**不提交页码、不动表格**；目标页越界（区间缩小 / 明细被清理）
  自动夹回末页并只重取一次。
- 补上本页缺失的基础件（按钮 / 输入框 / 错误条）：此前筛选框与按钮吃的是浏览器原生外观。

## 二、管理端官方模型配置

- 表单重做：能力页签带**启用状态 / 开放模型数 / 未保存脏点**；字段成对给出字段名与一句说明
  （协议附上游端点路径、Base URL 提示末尾不要 `/`）；API Key 支持显示切换、保存状态 chip 与
  清除（`apiKey: null` 才清空，空串表示不修改）。
- 模型表有列名（开放 / 模型 ID / 显示名 / 能力参数 / 操作），空 ID 与重复 ID 当场标红，
  未开放行弱化显示；空态、`全部开放 / 全部关闭`、`还原` 齐备；≤720px 沿用全局表格卡片化。
- **「拉取模型」改为合并而不是替换**：既有条目（含开放位与能力参数）原样保留，上游新增的 id
  追加并**默认未开放**（一次拉回上百个模型不该自动对客户端开放），并回报「新增 N / 保留 M」。
- 服务端 `adminConfig()` 的密钥异常原因（主密钥缺失 / 轮换后旧密文解不开）此前被界面忽略，
  现在以警示条展示；保存前的前端校验与服务端同款规则对齐，服务端报错原文照旧展示。

## 三、验收与测试

- 新增验收场景 `official-models`（22 条判定）：字段与列名齐全、拉取合并不替换、全开全关、
  行内空 / 重复 ID 校验、保存被前端拦截、切页签后草稿仍在。
- `usage` 场景补齐分页判定：一页 15 条、共 20 条夹具 → 第 2 页 5 条、边界按钮禁用、翻回第 1 页；
  `mobile-workbench` 补官方模型表的窄屏卡片化判定。
- 验收夹具改为真实链路：假上游（`/v1/models` + 带 usage 的 `/v1/chat/completions`）+ 临时
  `AURORA_CENTER_SECRET`，配好 llm 能力后用桩机自己的 client token 真调 20 次网关生成明细；
  换主题前复位配置，两档主题从同一服务端状态起跑。
- 验收基线 **88/88**（43 场景 × 暗浅两档 ＋ 2 个单档主题场景）；全仓单测 2520/2520、
  typecheck / lint / build 通过。

## 升级说明

- 服务器按 `packages/center/deploy/README.md` 打包上传，`docker compose up -d --build` 换装；
  数据目录 `./data` 与 `.env`（含 `AURORA_CENTER_SECRET`）不受影响，镜像 tag 升为
  `aurora-center:0.4.7`。
- 桌面端无需操作：本版无桌面变更，安装包与自动更新源不动。
