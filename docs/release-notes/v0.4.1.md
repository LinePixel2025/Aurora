# Aurora v0.4.1

本次版本是从 **v0.4.0** 到 **v0.4.1** 的完整更新，包含全新应用图标与品牌标统一、
文件自感知扩展与后台模型 / 记忆过期、Office 结构化工具、权限档口径调整、
Windows 游戏模式联动，以及一批界面与打包修复。

## 一、全新应用图标

- 设计稿入库 `scripts/assets/aurora-icon.png`，`pnpm icons` 由它居中裁成正方形，
  再用**面积平均**重采样出 `tray.png` / `tray-16/32.png` / `icon-64/256.png`
  与 7 个条目的 `icon.ico`，同时同步渲染层品牌标 `assets/aurora-mark.png`。
  换图标只需替换那张 PNG 再跑一次脚本。
- 托盘、窗口 / 任务栏、exe 三处图标统一为新图标；界面品牌标（主界面左栏、设置侧栏、
  提示条头部、首次引导、聊天空状态）与 Center Web 顶栏统一走共享 `.aurora-mark`。
- 修复两处「打包后图标丢失」：
  - 托盘图标此前没有进 `extraResources`，安装版会静默退回内置兜底圆点；
  - `win.signAndEditExecutable: false` 会把 exe 资源编辑**整个**跳过，产物停在
    Electron 默认图标。改用 `win.signExecutable: false`：只跳签名，图标与版本资源照常写入，
    且实测不触发 winCodeSign 下载（内网 / 离线照样出图）。

## 二、文件自感知扩展

- 正文类型从 `.docx` / `.pptx` 扩展到图片与常见文档：DOCX / PPTX / XLSX、PDF、ODF、
  RTF、HTML、EPUB、CSV / MD / TXT 等；`.doc` / `.ppt` / `.xls` 仍只观察、不解析。
- Office 正文优先结构化提取：表格走 CSV，其余走 Markdown，保留标题层级、列表、
  表格行列与页 / 幻灯片边界；失败才退回纯文本。
- 图片只在**有效后台模型**开启视觉输入时读取像素，关闭时只发送文件名与尺寸等元数据。
- 提示条「最近理解」支持多提醒完整换行与折叠；记忆库补齐筛选与搜索背景。

## 三、自感知后台模型与记忆过期

- 新增自感知**独立后台模型**：显式选择后严格使用该 provider + model；provider 被删除、
  模型为空或凭据缺失时**暂停队列并显示原因，不静默回落到主模型**。
- 新增记忆默认有效期、单条覆盖与 Agent 可见性过滤；过期只停用 Agent 可见性，
  **不删除**状态与 Markdown 笔记。
- 新增 `awareness_recent` / `awareness_search` / `awareness_read` 与累计 token 统计。
- 修复建议执行后的会话跳转顺序：`createSession → persistEmptySession → presentSession → send`。

## 四、Office 结构化工具

- 新增 `office_read` / `office_create` / `office_edit`，在 `office-worker` utilityProcess 中
  用纯 JS 引擎（`@office-open/docx|xlsx|pptx@0.14.6`）处理，不阻塞主进程事件循环。
- 默认另存 `<原名>-Aurora-<时间戳>.<扩展名>`；`overwrite: true` 才覆盖，且覆盖前先写二进制快照。
- DOCX 生成使用真实 Word 语义：标题落 `Heading1`–`Heading6`，项目符号 / 编号落
  `w:numPr` + `word/numbering.xml`，不再写字面 `•` / `1.`。
- COM 只保留为**显式兜底**（旧格式 / 宏 / 复杂格式），不再是主路径，也不会在结构化工具
  失败后自动回落到 COM。
- 修复命令编码与超时诊断：PowerShell 前缀先 `chcp 65001`；超时结果明确说明已终止整棵进程树。

## 五、权限档与变更前确认

- 明确三档语义：`readonly` 只读；`confirm` 按项目根「根内免确认、根外弹卡」；
  `auto` 为默认档、完全权限，敏感工具不再逐次弹确认卡。
- 「变更前确认」与「完全权限」的措辞、设置页摘要与文档统一到上述口径，
  主进程与渲染层共用同一份纯函数判定，避免「界面说只读、实际还能写」。

## 六、Windows 游戏模式联动

- 检测 Game Bar 进程与独占全屏 D3D；进入游戏时隐藏提示条并暂停文件自感知，
  退出后按进入前的可见性与开关状态恢复。
- 探针是**单条常驻 PowerShell 子进程**，只在 active 翻转时输出；启动后把工作集从约
  100MB 压到 14MB，稳态 CPU 接近 0。
- 配置新增 `general.gameMode` 开关（默认开启）。

## 七、界面修复

- 设置窗顶部改为完整 32px 可拖动标题带，窗口按钮在同一带内并 `no-drag`。
- 玻璃侧栏内的固定输入控件改用实心底，修复记忆库搜索框「没有背景」与滚动内容穿透。
- 自感知文件提醒标题与正文完整换行；自动化历史弹窗切换标签时先清空旧数据。

## 八、发布流程

- 发布脚本强制要求 `--notes-file`：自动读取上一版本 tag、打印相对提交与 diff，
  并直接用 Release Notes 创建 annotated tag，禁止单行文案。

  `v29 → v30` 新增 `general.gameMode`），`v0 → v30` 迁移链完整。
