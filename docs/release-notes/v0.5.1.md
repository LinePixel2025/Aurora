# Aurora v0.5.1

本次版本汇总 **v0.5.0 → v0.5.1** 的全部更新。核心是**插件系统 v36**：
第三方代码现在可以用一份 `manifest.json` 扩展 Agent 工具 / Skill / 斜杠命令、自动化动作与事件、
右栏面板、**桌面与提示条小组件**、主题与配置；插件以独立进程运行，也可从 Aurora Center 插件市场安装。

配置 Schema 由 **v35 升到 v36**（新增 `plugins` 分组）。Aurora Center 代码版本线保持独立
（线上 0.4.9），本次双投对象是桌面安装包的三个更新资产。

## 一、插件系统 v36（核心）

### 1. 清单优先

- 工具、Skill、命令、自动化动作 / 事件、面板、小组件、主题、配置字段全部在 `manifest.json` 声明，
  运行期**不允许动态注册**；
- 桌面安装器、Center 市场与 `scripts/verify-plugin.mjs` 共用同一份 zod schema，安装前即可完整展示权限与贡献；
- 未声明的贡献一律在清单校验阶段拒绝（含「声明了 widgets 但缺 `ui.widgets`」）。

### 2. 受控运行时（不是沙箱）

- 一个启用插件一个 `utilityProcess`（上限 8），白名单 RPC（单帧 1 MiB、在途 32、超时 / cancel）；
- 崩溃按 1s / 5s / 15s 退避重启，10 分钟内反复崩溃自动停用；30s 心跳，连续 2 次未回重启；
- **插件进程持有当前用户权限，安装即信任**：权限门控拦的是 Aurora API，不是系统能力。

### 3. 权限与工具

- 权限：`tools` / `skills` / `commands` / `automation` / `automation.events` / `storage` / `config` /
  `net` / `net.private` / `notifications` / `logging` / `ui.panels` / `ui.widgets` / `themes` / `events`；
- 工具最终名 `plugin.<id>.<name>`（≤ 64），**默认 `confirm`**；用户「信任此插件」后才放行清单里的 `safe`；
- 只读权限档只注册 `readonly: true` 的插件工具；插件工具不参与 `agent.tools.enabled` 门控。

### 4. 面板与沙箱页面

- 声明式面板复用受控组件（无 HTML / `v-html`），节点 500、深度 20、JSON ≤ 256 KB；
- 页面型面板走 `aurora-plugin://`：逐 session 注册协议、独立 `plugin-<id>` partition、
  专用 preload（只暴露 `window.auroraPlugin`）、强制 sandbox / contextIsolation、禁弹窗 / 下载 / 权限请求；
- 页面 RPC 由宿主渲染层带 guest id 中继，主进程校验 `webContentsId` 归属后才转发。

### 5. 自动化、主题与市场

- 自动化新增触发器 `plugin-event` 与操作 `plugin-action`；事件边沿触发，并有防自激守卫；
- 主题令牌只允许表面 / 文字 / 边框 / 圆角，强调色与毛玻璃仍由外观设置独占；
- Center 插件市场：公开列表 / 详情 / 下载校验（SHA-256）/ 图标，管理员上传 / 发布 / 删除；
  同版本不可覆盖，桌面端校验通过后才落安装状态。

## 二、桌面 / 提示条小组件与事件推送

### 1. 桌面小组件

- 新增 `contributes.widgets` 与 `ui.widgets` 权限；每个可见 widget 一张**无边框、透明、置顶、
  不占任务栏**的浮动卡片（不做壁纸层嵌入 / 桌面图标层 / 点击穿透）；
- 位置、尺寸、显隐写 `<userData>/plugin-widget-layout.json`，**独立于 settings、不升配置版本**；
  拖动 / 缩放 250ms 防抖原子写，屏幕变化时重新夹取到 workArea；
- 单插件 ≤ 4 个 widget；同时存在的桌面窗口 ≤ 8；设置页每个桌面 widget 一枚「显示在桌面」开关；
- 插件停用 / 卸载 / 总开关关闭即销毁窗口并保留用户位置；开发目录热重载不丢位置。

### 2. 提示条小组件

- `slot = "edge-bar"` 的条目渲染在提示条展开面板底部，**只接受声明式 schema**：
  清单层拒绝 `entry` 与 `defaultSize`，不创建窗口、不嵌 webview；
- 单条最高 220px、内部滚动；没有小组件时整块不渲染，不改变提示条窗口 shape / 尺寸逻辑。

### 3. 事件推送（无需刷新）

- 插件新增 `ctx.ui.panelEvent({ panelId | widgetId, event, payload })`：把事件推给自己已打开的面板 / 小组件；
- 主进程校验：目标必须在清单内、二者二选一、面板目标要 `ui.panels`、小组件目标要 `ui.widgets`；
- 事件名 `^[a-z][a-z0-9_.-]{0,63}$`，payload ≤ 64 KB，每插件每秒 ≤ 20 条（超出丢弃并记 warn，不打断插件）；
- 路由：右栏面板 → `plugins:panelEvent`；桌面 / 提示条小组件 → `plugins:widgetEvent`；
  页面型目标经 `webview.send('aurora:event')` 交给 `window.auroraPlugin.onEvent`；
- 同一事件只投给发起插件自己的目标，不跨插件串台。

## 三、Center 官方模型稳定性

- 客户端为官方模型目录增加磁盘缓存（`userData/center-model-services.json`）：
  启动即用上次快照，「目录尚未加载」走静默回落，不再误报「官方服务故障」；
- Center 网关超时改为**分段 + 空闲计时**：首字节 120s，之后每收到一块重置 120s，
  不再用总时长截断长回复（Center 0.4.9 已部署，客户端本次不带服务端改动）；
- 回落提示只显示真实落点（本机 Provider id），不再打印另一个 `center-*` id。

## 四、设置页与示例插件

- 设置 → 插件「已安装」改为紧凑卡片：默认只保留名称 / 版本 / 状态、一行摘要与桌面小组件开关；
  权限、扩展点、配置、信任、重启 / 目录 / 日志 / 卸载收进「详情」；
- `examples/plugins/hello-aurora` 扩展为完整示例：声明式面板 + 沙箱页面 + 桌面小组件 +
  提示条小组件 + `panelEvent` 推送命令；
- 新增 `examples/plugins/class-board`：班级事务示例（本周值日桌面卡片 / 今日事务提示条 /
  Agent `add_task` 工具 / 面板即时刷新），同时提供可安装 zip 的打包方式。

## 五、配置与数据

- **迁移 `v35 → v36`**：新增 `plugins` 分组（`enabled` / `devDirs` / `activeTheme`），
  已有配置原样保留；`plugins` 整组在 `SETTINGS_READONLY_PREFIXES`，AI 的 `set_setting` 不得
  安装 / 启停 / 信任插件；
- 安装态在 `<userData>/plugins/registry.json`；插件配置 / 存储在 `plugin-data/<id>/`；
- 插件配置**不支持密文字段**，也不向插件暴露任何 Aurora 凭据；
- 桌面小组件布局独立于 settings，删掉布局文件只丢位置，不丢插件数据。

## 七、升级说明

- 安装包 `Aurora-Setup-0.5.1.exe` + blockmap + `latest.yml` 同时发布到 GitHub Releases 与
  Aurora Center 更新源；0.5.0 及更早客户端会在下一次检查更新时升级；
- 已装旧版无需卸载，配置与会话不受影响；配置自动执行 `v35 → v36`；
- **升级后行为变化**：设置页新增「插件」入口；未安装插件时无感知；安装插件后其工具默认需确认；
- Aurora Center 服务器自身不跟随桌面版本号：Center 代码版本线独立，本次只更新「更新源资产」。

## 八、已知限制

- 插件进程**不是 OS 沙箱**，安装即信任；OS 级隔离不在本版；
- 桌面小组件是置顶浮动卡片，不是壁纸层 / 桌面图标层嵌入；
- 提示条小组件只支持声明式 schema，页面型小组件只能在桌面槽位使用；
- 插件返回工具结果只支持文本；市场不提供签名 / 发布者认证；
- 插件自动更新与已安装插件热更新仍不在本版范围（开发目录除外）。
