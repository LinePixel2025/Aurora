# Aurora v0.3.3 更新说明

发布日期：2026-10-02 ｜ 安装包：`Aurora-Setup-0.3.3.exe`（Windows x64，未签名）

v0.3.2 之后的版本，三块内容：**模型终于能"一个会话一个"**（不再一个下拉改全局）、
**让 Agent 向你提问这件事变得好用**（一次可以问几个问题、跨会话不再互相顶掉、
问过什么答过什么都留档）、**客户端能与 Center 双向传文件**（此前只能往外发，现在也能收）。

**没有任何配置迁移**：配置版本仍是 **v25**，覆盖安装即用，凭据、项目、会话、自动化全不动。
（内部把会话文件的格式号从 v3 提到 v4 用于记录提问留痕 —— 缺字段就是"没有留痕"，
老文件天然合法，**不会**触发任何重写或迁移。）

---

## 🧠 一、会话级模型：一个会话一个模型

以前"模型"是**全局一份**：你在对话窗的模型下拉里选了什么，所有会话都跟着变；
想给某个会话单独用贵一点的模型（比如写作会话用长思考模型、随手问用便宜的），做不到。

这一版起，对话窗的模型下拉管的是**当前这个会话**：

- 下拉里多了一条 **「跟随全局（<当前全局模型>）」** —— 想回到"跟着默认走"，选它即可；
- 会话左栏的行上会显示一个**模型小徽标**，一眼能看出"这个会话绑了模型"（没绑的不显示）；
- **设置页「AI 模型」里改的仍然是全局默认**，两者的关系是「默认值」与「这个会话要不要覆盖它」，
  不再互相打架；
- 「思考等级」仍然跟着模型走（每个模型一套参数），所以换了模型，思考等级自动跟着换。

**Aurora Center 网页端也能看、能切**：控制台右侧「会话管理」里每个会话多了一个模型下拉，
语义与桌面端完全一致（选「跟随全局」= 清除覆盖）。注意网页端「模型」页签改的是**客户端全局默认**，
和会话级覆盖是两份数据 —— 网页端上两处都写清了各自的含义。

> 内核侧的口径：解析链只有一级 —— **会话覆盖 > 全局默认**；覆盖里指向的模型配置若被删除、
> 或模型名被清空，会**静默回落全局**（不会报错，也不会把一个坏模型硬塞给请求）。

## 🙋 二、Agent 提问卡（`ask_user`）四件事

Agent 在需要你拍板时弹的那张卡，这一版把"能不能好好用"补齐了：

1. **一次可以问几个问题**：相关的两三件事会被收进**同一张卡的分节**里，你一次提交完事，
   不用连着弹三张卡（不相干的问题仍会拆成多轮问 —— 那是有意为之，避免信息堆一起）。
   回填给模型的是**逐问的问答对照**，它不会只记住第一问。
2. **跨会话不再互相顶掉（修 bug）**：此前如果两个会话同时提问（或一个后台自动化会话提问），
   后到的卡片会**覆盖**先到的那张 —— 内核还在等回执，界面上却已经看不到那张卡了，只能等超时。
   现在按会话并存，每一张都在。
3. **可以要求"只能选，不许自己填"**：某些提问必须从给定选项里挑（例如"选一个已存在的文件"），
   卡片上就不会出现自由输入框。
4. **等待时长可以按次配**：默认 3 分钟；需要你去别处查一下再回来答的场合，可以把这一次的
   等待放宽到最长 10 分钟（最短 30 秒）。

**新增：提问留痕。** 提问与你的作答会写进会话文件（仅限 Center 远程会话），
于是**在 Center 网页端刷新页面、换设备后，仍然能看到"刚才问了什么、答了什么"**，
以一张只读的已结算卡留在对话流里。本地会话的提问卡仍然是瞬时卡片（问完即收，不留档）。

## 📁 三、和 Aurora Center 双向传文件

此前只有"客户端 → Center"：让 Agent 调 `center_send_file` 把文件发到网页端下载。
这一版补上反方向：

- **网页端 → 客户端**：在 Center 控制台对选中的设备点「**发送文件**」（或在「文件」页对某份
  暂存文件点「**发送到客户端**」并选一台设备），文件会传到你的电脑上，落在**系统「下载」目录**，
  落盘后弹一条系统通知告知完整路径，重名自动追加 ` (1)`（**绝不覆盖**你已有的文件）。
- 门控照旧：客户端设置里**关掉「允许文件传输」就连按钮都不出现**（不是点了报错）；
  单文件大小上限沿用 `center.maxFileMb`（默认 64 MB）。
- 「文件」页现在多了一列**来源**，区分"客户端发来的"与"网页上传的"。

## ⚡ 四、其他改动

- **流式增量改为两端共用同一份实现**（按帧合并）：桌面端此前就有这个缓冲，本轮只是把它挪到
  共享层与 Center 网页端共用 —— **桌面的观感与 v0.3.2 一致**，网页端的流式渲染更跟手了。
- **Center 服务器同步升级到 0.3.4**，与本版客户端配套（会话模型下拉、文件下发、提问卡结算
  都需要服务端支持）。
- 安全基线不变：模型输出的原始 HTML 一律转义、链接协议白名单、外链带防护属性、
  凭据全程 `safeStorage` 加密且不回传渲染层。
- `ask_user` 的提问卡片与信息只在**本机**与**你已登录的 Center** 之间流转；本地会话的提问
  绝不出网（这条从 v0.3.3 的 Center 通信实现起就没变过）。

## 📦 升级说明

- 直接覆盖安装即可：**配置无需迁移**（仍是 v25），会话文件格式号的变化对老文件透明。
- 会话级模型是**新数据**：升级后所有会话默认"跟随全局"，与你升级前看到的模型一致；
  想给某个会话单独指定，在对话窗的模型下拉里选一次即可（左栏随即出现模型徽标）。
- 若同时使用 Aurora Center：请确保服务端已升级到 **0.3.4**（否则网页端看不到会话模型下拉、
  「发送文件」与提问卡的实时结算）。
- ClassIsland 桥接插件（`AuroraClassIslandBridge-v3.0.zip`）**本轮无改动**，随包一并附上；
  已安装过的不需要重新装。
