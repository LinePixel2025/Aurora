# Aurora v0.4.9

本次版本汇总 **v0.4.8 → v0.4.9** 的全部更新。核心是两轮内核改造（**任务编排对齐主流代理（配置 Schema v34）**
与**子代理同轮多实例并行**），自动化历史重做为三层详略并支持双端对话回放，自感知流光改
Apple Intelligence 光谱，桌面与 Center Web 的输入卡同时支持图片粘贴与贴按钮浮层，并修掉
左栏会话行在窄栏下的文字重叠。配置 Schema 由 **v33 升到 v34**（`agent.loop` 三退一）。
Aurora Center 同步换装 **0.4.8**（输入卡重做 + 图片附件链路；Center 版本线独立，不建 tag、
不上传 GitHub Releases）。

## 一、内核 · 任务编排对齐主流代理（配置 Schema v34）

- **同轮并发批次**：相邻且声明 `parallel` 的只读调用并批起跑；两道闸门在循环里 ——
  confirm 级**永不并发**（一次弹两三张确认卡比慢一点严重得多），非 `parallel` 是串行屏障。
  批次只改起跑时机，卡片状态与 tool 消息始终按模型写下的**原始顺序**落地（配对链一断，
  服务端直接 400）。
- **运行中插话**：会话正忙时普通发送改为**排队**，在轮次边界插进正在跑的那次请求
  （旧口径是 `E_BUSY` 硬回绝，用户只剩「干等」或「把已跑几轮一起丢掉」两个选择）；
  输入卡给三个动作：**排队发送 / 打断并发送 / 停止**（停止把排队的退回输入框）；
  模型直接收敛、边界从未到来时由收尾补发一轮。
- **工具执行 10 分钟兜底**：per-call `AbortController`，超时先中止再回填 `isError`、循环继续；
  `task` 子代理显式不限（它的上限是轮次与取消）。只兜真挂起，不抢既有预算。
- **`agent.loop` 三退一**：删 `maxRounds` / `maxTotalTokens` / `autoContinueRounds`，只剩
  `maxParallelCalls`（1–32，默认 8，超出排队等位）；轮次上限回到内核常量
  `RUNAWAY_MAX_ROUNDS = 512` 并删掉 attempt 循环与自动续轮；token 只统计不限制；
  `pendingReason` 三态→两态、`AgentJob.budget` 只剩 `usedTokens`。
- **job 账本**：接上 `job.todos` 的唯一生产者（JobPanel 自 v15 起就在渲染这个死字段）、
  `stepsDone` 上限 200、续跑把 `maxRounds` 刷成当前生效值。
- 迁移：`v33 → v34` 是本链第一条**删字段**的迁移（旧值不映射，docs/08 §1/§2）。

## 二、内核 · 子代理同轮多实例并行

- `task` 声明 `parallel`，复用同轮并发批；新增按父会话的 `SUBAGENT_MAX_PARALLEL = 3` 限流与
  **整段写锁** —— 写入类子代理串行（确认卡不叠加，也不会交错读改写同一文件）。
- `permission: 'write'` 改为按「子表里是否真的有写工具」落**实际授予**：只读档不再显示
  「可读写」，降级原因写进结果；子代理页按实际权限展示徽章。
- 补限流器 / 并发 / 排队 abort / 实际授予单测与 systemPrompt 口径；冒烟新增 3 条
  多子代理并发与持久化断言。

## 三、自动化 · 历史详略三层 + 双端对话回放

- **列表按本地日期分组**（组标题吸顶），一行只放读得完的事实、第二行放派生摘要，
  点行就地展开明细；`historyChanged` 改为静默重拉当前页，不再清列表、收起回放。
- **运行记录补派生量**（`triggerDetail` / Agent 的 `toolCallCount + summary` / Normal 的
  `steps[]`）：由引擎在既有事件订阅里累加，不回读会话文件，正文仍只在会话里。
- **Agent 回放两端复用现成对话渲染器**（桌面 `MessageList`、Center `MessageStream` +
  只读 `loadRunTranscript`）：Markdown / 轨迹折叠 / 工具卡 / 子代理卡 / 图片全部一致。
- **Center 端补上回放**（docs/13 §10 早已写明却从未实现）：连接器前缀闸门只对
  `session.history` / `session.readImage` 两条只读命令放行 `auto-` 会话，
  `session.list` 依旧不可枚举、实时事件依旧不出网。
- Normal「无详情层」口径作废（原实现连失败原因都看不到），探针断言随之从
  `normalClickable === 0` 翻成展开后 `step-item` 恰好 2；历史分页加 `offset` 并把 limit 钳到 200。
- 吸顶日期标题改实底并贴住滚动区上沿（修「时间标识错乱」），回放明细里点工具调用不再收起整条记录；
  capture 新增 4 条断言（明细点击后仍在 / 工具行展开 / 标题底色不透明 / 吸顶处离上沿 ≤1px）。

## 四、自感知 · 流光改 Apple Intelligence 光谱

- 配色从强调色单色回到**多色光谱**（品红→紫→蓝→青→琥珀），每层 ≤36% 不透明度 + 大半径模糊
  叠加呈「液态弥散光」；删除 bottom / left / right 三边与 curtain 光帘动画，**只保留顶部一条
  光谱极光带**。探针同步改为只检查 top 边带、halo 不再断言 curtain。
- 实测帧成本 mean 4.2ms（此前 5.5ms）；几何、显隐门控（「流光特效」开关）与鼠标穿透不变。

## 五、双端输入卡 · 图片粘贴与贴按钮浮层

- **图片粘贴**：桌面 / Center Web 输入卡支持 `Ctrl+V` 粘贴图片、卡内 56×56 缩略图与移除；
  桌面新增 `chat:stageImage` 与 96px 预览，抽出共享 `prepareAttachments`；
  Center 扩展 `session.input` 图片附件链路（fileId 校验 / 下载 / 能力位 / 5 分钟超时）。
- **浮层统一锚点**：模型 / 思考改为自绘芯片，权限 / 模型 / 思考等**五个输入卡浮层统一底边锚点**
  并贴各自触发按钮（靠右时按卡右缘回退），互斥且都在卡上方。
- 上下文详解卡改单列 label/value，修复长文本互相重叠。
- 同步 capture / `verify:web` 探针、文档与项目记忆。

## 六、修复 · 左栏会话行窄栏文字重叠（用户实测）

- 现场：左栏拖到夹取下限 200px 时行内容宽只剩 ~118px，96px 的模型徽标把标题**挤成 0 宽**，
  相对时间溢出 18px、正好压在 hover 归档钮上（看起来就是「文字重叠」）。
- 修法（`SessionRow.vue`）：行内优先级定死为 **标题 > 相对时间 > Center 药丸 > 模型徽标**；
  标题 `flex: 1 1 auto` + `min-width: 3em`（永不归零）、相对时间不收缩不换行、药丸可收缩、
  `@container (max-width: 150px)` 在窄栏整枚隐藏模型徽标、`.nav-item` 加 `overflow: hidden` 兜底。
- 新增截图场景 `chat-nav-narrow.png`（左栏 200 现场 + 200 / 240 两点压测）。

## 九、升级说明

- **桌面端**：安装包 `Aurora-Setup-0.4.9.exe` + blockmap + `latest.yml` 同时发布到
  GitHub Releases 与 Aurora Center 更新源；0.4.5 – 0.4.8 客户端会在下一次检查更新时升级。
  已装旧版无需卸载，配置与会话不受影响。
- **配置迁移 v33 → v34**：`agent.loop` 删除的三个循环字段不映射；轮次上限回到 512、
  token 只统计不限制（旧配置里的上限值被丢弃，属预期）。
- **Aurora Center**：线上从 `aurora-center:0.4.7` 换装到 `0.4.8`；数据目录 `./data` 与
  `.env`（含 `AURORA_CENTER_SECRET`）不动。协议只做增量（新增图片附件字段），旧客户端不受影响。
- **升级顺序**：先换装 Center 0.4.8（兼容旧客户端），再发 0.4.9 安装包 —— 本次发布按此顺序执行。
