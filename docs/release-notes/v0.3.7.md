# Aurora v0.3.7 更新说明

发布日期：2026-10-03 ｜ 安装包：`Aurora-Setup-0.3.7.exe`（Windows x64，未签名）

v0.3.7 是 v0.3.6 之后的**右栏工作台轮**：右栏从「四个固定标签」升级为
**浏览器式多标签容器**，默认窗口也变大了一圈。其中两项是**真 bug 修复**
（其中一个 v0.3.6 声称修好了、其实没生效，见第二节）。

配置版本推进到 **v26**，唯一的迁移是把仍小于新默认尺寸的窗口几何放大一次（只放大、不缩小），
凭据、会话、项目、自动化数据一概不动。

---

## 🗂 一、右栏变成「浏览器式多标签」工作台

右栏顶部的标签条现在像浏览器一样工作：

- **可以同时开很多标签**：文件预览、终端、浏览器都能多开 —— 比如两个终端一边跑脚本一边看输出、
  三个网页对照查资料、两个文件预览并排看代码；
- 初始还是四个标签（上下文 / 文件 / 终端 / 浏览器），点 **＋** 开新标签（菜单里选种类）；
- **标签多了不会挤成一条**：标签宽度固定，放不下的收进右侧 **「＋N」** 菜单，点开是完整列表
  （可切换、可关闭）；**当前激活的标签永远留在可见区**；
- **每个标签有自己的标题和关闭按钮 ✕**：文件标签显示当前目录或文件名、终端标签显示它的工作目录名、
  浏览器标签显示网页标题；
- **切标签不再重新加载**：看过的网页切走再切回来不会重新加载（滚动位置、表单内容都还在），
  终端也不会重建 —— 它们只是被藏起来了；
- **终端每个标签一条独立 shell**：关掉终端标签就是关掉那条 shell（最多同时 6 个）。

## 🖱 二、网页里的链接：要另开窗口的，现在真的另开一个标签

网页里 `target="_blank"` / `window.open` 形式的链接（搜索结果、外链、登录跳转）此前**点了没反应**。

> v0.3.6 的更新说明里写过「改为在同一个面板里打开」—— **那条当时其实没生效**。
> 真实原因：内置网页视图一直没开启 `allowpopups`，这类「另开窗口」的请求在渲染层的
> 网页视图里就被丢掉了，**根本到不了**应用主进程的处理逻辑 —— 所以那条修法从来没被触发过。
> 本版把它真正修好了，并且用**真实的鼠标点击**做了端到端验证（见验证记录）。

现在的行为：

- 这类链接会**另开一个新的浏览器标签**加载目标地址，**当前页原地不动**（不再把你看的页面顶掉）；
- 浏览器工具条右端新增 **「＋ 新建标签页」**，就地再开一个浏览器标签（新标签打开主页）；
- 只有 `http(s)` 放行；`file:`、自定义协议、`about:blank` 一律拒绝（与地址栏同一口径）；
- **不会弹出真正的系统窗口**：一切新窗口请求都由 Aurora 接管成右栏标签。

## 🪟 三、主界面默认尺寸变大

- 默认 **1120×720 → 1280×800**，最小 **940×600 → 1060×660**；
- **你现有的窗口会在下次启动被抬到新默认**（配置迁移 v25 → v26：只把小于新默认的宽/高抬上来，
  **只放大、不缩小**，位置与你自己拖得更大的尺寸原样保留）；
- 最小宽 1060 = 左栏 240 + 主区 420 + 右栏 384 + 余量 —— 低于它右栏会被挤到最窄；
- **上限刻意不取更大**（如 1360×860）：实测「主区越宽 → 消息里的图表画布每帧越大」，
  在软件渲染的显示环境（如远程桌面 / 虚拟显示适配器）下高密度流式的帧距会掉到 300ms 级，
  比我们修过的那个回归还差。想要更大可以自己拖窗口 —— 那是你的取舍，不该由默认值替你决定。

## 🐞 四、两个真 bug 修复

1. **右栏缩到最小时，「＋」按钮被裁掉、点不到**（你实测报的那个）：
   标签宽度原来按「舒适宽 88px」起步，右栏被挤到 280px 时整条留给标签的空间只剩 132px，
   `88 + 两枚按钮 + 间距` 超宽，最后那枚「＋」被裁切掉 —— DOM 里有、看得见与否全看运气，反正点不到。
   现在改成**按钮宽度先留够、标签让位**（可让到 48px），280px 下标签 74px + 两枚按钮正好放下；
   回归护栏把「两枚按钮完整可见」和「＋ 真的能被点中」都钉住了（含反向复核）。
2. **网页里要另开窗口的链接点了没反应** —— 见第二节。

## ⬆️ 升级方式

直接运行 `Aurora-Setup-0.3.7.exe` 覆盖安装即可：配置、会话、项目、自动化与凭据全部保留，
数据目录 `%APPDATA%/Aurora` 不会被清理。首次启动会自动完成 v25 → v26 配置迁移（仅窗口尺寸）。

ClassIsland 联动插件契约未变，无需更新。

> 注：本轮**服务端没有任何改动**，Aurora Center 仍是 0.3.6（与桌面端是两条独立的版本线，
> 各自按自己的改动推进，互不影响）；桌面端本轮的编号走补丁位（0.3.6 → 0.3.7）。
