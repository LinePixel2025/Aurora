# Aurora v0.3.6 更新说明

发布日期：2026-10-03 ｜ 安装包：`Aurora-Setup-0.3.6.exe`（Windows x64，未签名）

v0.3.6 是 v0.3.5 之后的**侧栏优化修补版**（原计划编号 v0.3.5.1 —— 四段式版本号无法用于
Windows 安装包与自动更新，故按三段式发为 0.3.6）。四项改进，其中一项是**真 bug 修复**：

1. **内置浏览器之前打不开网页**（白屏 / 半残 / 点链接没反应）—— 根因已定位并修掉，见第三节；
2. 左栏也能像右栏一样**拖动调宽**；
3. 终端底色**固定为黑色**（此前跟随系统主题，浅色系统下是白底黑字）；
4. 右栏「文件」标签变成**文件管理器**：绑定了项目的会话直接展示项目文件夹；
   并新增一项能力 —— **AI 可以把成果（HTML 报告 / 网页 / 图片）直接展示在你的右栏**。

**没有任何配置迁移**：配置版本仍是 **v25**，覆盖安装即用，凭据、项目、会话、自动化全不动。

---

## 🐞 一、修复：内置浏览器打不开网页

v0.3.5 引入的内置浏览器（右栏「浏览器」标签）在很多网站上打不开或显示残缺，
比如搜索引擎结果点不动、页面只剩文字骨架。

**根因不在浏览器面板本身，而在应用的网络层**：Aurora 给**自己的界面**设了一条内容安全策略
（CSP，用于加固渲染层），但这条策略此前被**无条件**加到了*每一条*网络响应上 ——
包括内置浏览器里加载的**外部网页**。于是外部页面被强加了"只允许加载本站脚本"的限制：
它自己的内联脚本、CDN 上的脚本与样式、别的域名的图片全部被浏览器拒绝执行。
结果就是页面白屏、半残、按钮点了没反应 —— 看起来完全像"浏览器坏了"。

修复后，CSP **只注入 Aurora 自己的窗口页面**，外部网页按它自己的安全策略正常运行。
这条修复同时改善了面板的几处体验：

- **链接点得动了**：网页里 `target="_blank"` / `window.open` 形式的链接（例如搜索结果）
  此前被整个丢弃，现在改为**在同一个面板里打开**（仍然不会弹出新窗口）;
- **加载失败有提示**：断网、域名不存在、代理不可用时，面板上直接写明失败原因，
  不再是静默白屏；
- **本机地址更省事**：地址栏输入 `localhost:5173` 这类地址会自动按 `http://` 处理
  （以前会被当成 `https://` 而连不上）—— 配合下面的"AI 展示成果"，本地服务预览更顺手。

## 🪟 二、左栏可拖动调宽

左栏（会话列表）此前固定 240px。现在**右缘可以拖动调宽**（200–420px，双击复位，
宽度记忆在本地），写长标题的会话名不再总要靠悬停看全 —— 与右栏是同一套手感。

## 🖥 三、终端固定黑底

终端面板此前跟随系统主题：浅色系统下会是**白底黑字**，与"终端"的视觉预期不符。
现在统一为**纯黑底 + 浅色文字**，与系统主题无关。同时终端的重排更灵敏了 ——
拖动左右两侧栏改变宽度时，终端会立刻按新的宽度重算行列，不再留着旧的换行位置。

## 📂 四、文件标签变成文件管理器 + AI 可以把成果展示在右栏

### 1. 「文件」标签 = 小文件管理器

- **绑定了项目的会话**：打开「文件」标签直接看到**项目文件夹**的内容（标题写明
  「项目：xxx」）；没绑项目的会话展示当前工作目录。
- 双击进入子目录、面包屑式的「上级」按钮逐层返回；「返回」在预览与列表之间切换。
- **目录在前**、文件按名称排序（带数字感知：`lesson2` 排在 `lesson10` 前面）。
- 点文件即在面板内预览（Markdown / 文本 / 图片），原有"粘贴路径预览"和
  "最近预览"照常可用。
- 边界与文件工具完全一致：只能看到当前会话工作目录之内的内容，越界直接拒绝并说明原因。

### 2. 新工具：`show_preview` —— AI 把成果直接展示在右栏

以前 AI 做完一个 HTML 报告 / 图表 / 页面，只能把一大段源码贴进对话里；
现在它可以调用新工具 `show_preview`，把成果**直接显示在右栏的预览面板**里
（自动展开右栏并切到「浏览器」标签），再用一两句话说明要点：

- 支持两类目标：**网页地址**（http / https）与**本地文件**（HTML / 图片等）；
- 本地文件必须写在**当前会话的工作目录（项目文件夹）之内**，越界会被拒绝并如实告知；
- 展示的是本地文件时，地址栏显示文件路径本身，方便你确认看到的是哪一个产物。

> 用法上不需要你做什么：让 AI 做可视化产出（"生成一份报告页面"）时它就会用上；
> 生成的文件也照常落在你的项目文件夹里。

## ⬆️ 升级方式

直接运行 `Aurora-Setup-0.3.6.exe` 覆盖安装即可：配置、会话、项目、自动化与凭据全部保留
（配置版本 v25 无迁移）。数据目录 `%APPDATA%/Aurora` 不会被清理。

ClassIsland 联动插件契约未变，无需更新。

> 注：本轮**服务端没有任何改动**，Aurora Center 仍是 0.3.6（与桌面端同号，但两者是独立的
> 版本线，各自按自己的改动推进，互不影响）。
