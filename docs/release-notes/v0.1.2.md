# Aurora v0.1.2 更新说明

发布日期：2026-09-26 ｜ 安装包：`Aurora-Setup-0.1.2.exe`（Windows x64，未签名）

这一版是**对话体验版**，主题是「让对话看起来像在实时发生，让输入框好用起来」。三块内容：

1. **回复不再整段蹦出来** —— 修复「等模型把话全部说完才显示」的老毛病，正文逐字出现，思考过程在
   正文之前就能看见并自动滚动；
2. **输入框重做** —— 自动增高的输入区、`/` 命令与技能补全、工具行里的**权限模式**开关、
   底部常驻的**上下文详解条**（token 用量与上下文占用一眼可见）；
3. **看得见用量** —— 每轮请求的输入 / 输出 token 与「本会话累计」都会记录并展示，
   上下文快满时颜色会报警。

配置 Schema 升到 **v11**（新增 `llm.providers.<id>.contextWindow`），**启动时自动迁移，无需任何手动操作**；
安装包直接覆盖升级即可，会话历史与凭据均不受影响。

---

## ✨ 一、回复逐字出现（此前要等模型全部说完）

### 你之前看到的现象

提问后界面一直空着，光标转很久，然后**整段回复一次性出现**——中间没有任何「正在写」的过程。
对比其它桌面端 Agent（ChatGPT / Claude Desktop 等），少了最关键的「在实时思考与作答」的观感。
流式响应其实一直是开着的，问题出在最后一公里。

### 根因

内核把模型吐出的正文增量**只累积、不转发**：因为一条助手消息要先落盘才拿到自己的 id，
而落盘发生在整轮流结束之后——于是它只能攒完整段，再作为**一条**消息事件发出去。
有意思的是「思考过程」当时反倒是边收边发的，所以出现了「思考有动静、正文一直空等」的反差。

### 修复

把消息 id 的分配**提前到流开始之前**：内核在每一轮开始前先领一个 id，正文与思考的每个增量都带上它
即时下发，轮次结束时落盘沿用**同一个 id**。于是你看到的那条「正在写」的消息，与磁盘上保存的最终消息
是**同一条**（历史回看、切换会话都不会错位或重影）。同时思考增量也带上了归属 id，因此纯思考阶段
（正文还没开始）不再是空白——思考块会先出现。

现在你能看到：正文从左到右逐字写出，末尾有一枚光标与「墨还没干」的淡出边缘，写完整段即定格。

## ✨ 二、思考过程：实时可见、自动翻滚、带动效

- 思考块在**思考开始的那一刻**就展开出现（此前要等正文到达才看得到，等于白等）；
- 块内文字**自动跟到最新一行**（滚动是按帧合并的，思考再密也不会卡），你可以随时往上翻看前面的推理，
  **手动上翻后会暂停跟随**，滚回底部自动恢复——回看时不会被新内容拽走；
- 块头有旋转的等待指示点与**已思考秒数**；一旦模型开始写正文，块头文案变成「已深度思考」，
  动画与秒数收起，块保持展开；整轮结束后自动收起为一行摘要，想看全文点一下即可。

## ✨ 三、输入框重做

输入卡自上而下一共三段（与主流桌面端 Agent 一致）：

**① 输入区**：随内容**自动增高**（一行起步，最多 200px，再多就在框内滚动，不会把对话挤没）。
`Enter` 发送、`Shift + Enter` 换行（`Ctrl + Enter` 同样发送）。

**② 工具行**：

- **权限模式**（工具行最左，盾牌图标）—— 两档：
  - **变更前确认**（默认）：写文件 / 执行命令 / MCP 工具 / 改设置执行前都会弹确认卡，你点「允许一次」才执行；
  - **完全权限**：不再逐次询问，直接执行（仅在日志里留痕）。
  切到完全权限需要**点两下**（第一次只是把选项翻成「再点一次确认」），因为它等于把确认闸门一直敞开，
  一个误点不该放权；开启期间这一档会一直用警示色显示，提醒你闸门当前是开着的。
  这一项与「设置 → 智能与工具」里的同名开关是**同一个设置**，改哪边都一样。
- 右侧依次是模型下拉、思考等级下拉、麦克风（配置了语音输入才出现）、停止 / 发送。

**③ 上下文详解条**（输入框最底部，常驻一行）：

- 显示**上下文占用**：`已用 / 窗口` + 进度条 + 百分比，以及本会话累计 token；
- 占用到 60% 变黄、85% 变红——看到变色就该考虑开新对话了；
- 点一下展开明细：最近一轮的输入 / 输出 token、本会话累计、上下文窗口、消息条数与字符数、当前模型；
- 「窗口」来自「设置 → AI 模型 → 编辑 → 高级参数 → **上下文窗口**」（新字段）。**不填就是未知**，
  此时只显示用了多少 token、不显示比例——分母不知道就不猜；
- 模型服务没返回用量时，这里如实写「暂无用量数据」，**不会拿字符数换算一个数字糊上去**。

## ✨ 四、`/` 命令与技能补全

在输入框敲 `/` 会弹出候选浮层，分两组：

- **命令**（选中即执行）：`/new` 新对话、`/clear` 清空当前消息区、`/stop` 停止回复（回复中才有）、
  `/subagents` 打开子代理页面、`/settings` 打开设置窗口；
- **技能**（选中只补全）：你的全部启用中技能，例如 `/system-status`，补全后接着写需求即可。

操作：`↑` `↓` 选择、`Enter` 或 `Tab` 确认、`Esc` 关闭。浮层打开时 `Enter` 属于浮层，不会把半截命令发出去。

## 🔧 五、其它改动

- **设置页**：AI 模型 → 编辑 → 高级参数新增「上下文窗口」（token）；provider 卡片在填过之后会以
  `上下文窗口 128k` 的形式显示，未填则不显示这一行。
- **模型兼容性兜底**：为拿到 token 用量，流式请求会带上 OpenAI 标准的 `stream_options.include_usage`；
  **不认这个字段的网关**会在报错后自动去掉它重试一次——「个别网关打不开对话」比「拿不到用量」严重得多，
  这一层降级就是为了避免前者。
- **文档**：`docs/06 §16.2` 新增「正文流式渲染与 token 用量」的完整设计说明；`docs/07 §2.3` 新增
  「输入框规格」；`docs/08 §1` 补 `contextWindow` 字段与 v11 迁移；用户手册（`docs/10`）同步了新的
  输入框操作与权限说明。
- **验证**：新增 3 个界面探针场景（斜杠浮层 / 权限两段式 / 端到端「真发一条消息」）与 4 条流式契约断言，
  其中端到端探针会临时拉起一个**本地假模型**，断言回复文本与 token 数字确实画到了界面上。
- **顺手修掉一个自测缺陷**：ClassIsland 自测夹具的课程按「当前时间 +3 分钟」推算星期，跨零点时会落到
  次日导致断言误报（在 23:58 跑自测实测踩到），现已按今天 / 明天各写一份。

## 🐛 六、修复

- **回复延迟显示**：见第一节（根因在内核只累积不转发正文增量）。
- **纯思考阶段空白**：思考增量此前不带消息归属，而助手消息要等正文到达才创建，因此模型思考的整段时间
  界面上什么都看不到；现在思考增量带上归属 id，思考块随之立即可见。
- **「朗读」按钮在流式途中闪出**：正文开始写时不再提前清除「生成中」标记，该标记只在整轮结束
  （成功 / 失败 / 手动停止）时统一清除；同时修掉「只调工具、没有正文的那轮消息一直显示省略号动画」的问题。

## ⬆️ 升级说明

- 直接用 `Aurora-Setup-0.1.2.exe` 覆盖安装；配置、会话历史、分类流水、凭据全部保留。
- 首次启动会**自动执行配置迁移 v10 → v11**（为每个模型配置补一个 `contextWindow: 0`，即「未知」）。
  想看到上下文占用百分比，去「设置 → AI 模型 → 编辑 → 高级参数 → 上下文窗口」按服务商文档填一个数值即可
  （例如 DeepSeek 常见 64k / 128k 档位）。
- 使用 ClassIsland 联动的用户：桥接插件仍为 **v3.0**，与 v0.1.0 相同、**未变更**；已部署过的无需重新部署
  （本 Release 仍附带 `AuroraClassIslandBridge-v3.0.zip` 供新用户）。命令通道与课表契约完全不变。
- 自动更新：已安装旧版的用户会在后台收到更新提示（更新源 `LinePixel2025/Aurora-releases`）。
