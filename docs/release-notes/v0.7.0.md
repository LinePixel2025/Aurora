# Aurora v0.7.0

本次版本汇总 **v0.6.4 → v0.7.0** 的全部更新。主线是 **TTS 朗读优化**：语气可设定、语种可锁定、
分块边播边取大幅降低首声延迟；同批包含全局统一缩放与 DPI 适配、流光提醒自定义音效（Schema v42）、
右栏文件面板重做，以及 Center 网关对 Qwen-Audio-TTS 新端点的支持。

本版配置 Schema **v41 → v43**（两条自动迁移，均幂等且不覆盖用户已写值）；插件清单与宿主 API
仍为 **v1**（无变化）；Aurora Center 服务器随本版升级到 **0.6.0**（版本线独立：网关新增
Qwen-Audio-TTS 端点路由、网页端朗读分块边播边取）。已有配置 / 会话 / 插件 / 自动化数据全部保留。

## 一、TTS 朗读优化（主线，Schema v43）

- **语气指令**：TTS provider 新增 `instructions` 字段（自然语言描述语气 / 情感 / 说话方式，
  ≤1000 字符，空 = 不发送）。设置页编辑卡新增 textarea 与四个常用风格 chips（温柔舒缓 /
  活泼明快 / 沉稳正式 / 新闻播报）。按协议下发：OpenAI 兼容走顶层 `instructions`、DashScope
  原生走 `input.instructions`、Qwen-Audio-TTS 走 `input.instruction`（单数）。**效果取决于模型
  是否支持指令控制**（Qwen-Audio-TTS 系列、`gpt-4o-mini-tts`、百炼 `qwen3-tts-instruct-flash`
  支持；`tts-1` 与千问AI平台 `qwen3-tts-flash` 不支持，hint 如实提示）。
- **合成语言**：新增 `language` 字段（`auto | zh | en | ja | ko | fr | de | es | it | pt | ru`，
  默认 `auto` = 不发送）。DashScope 原生下发 `input.language_type`（短码映射 Chinese / English
  等全称），Qwen-Audio-TTS 下发 `input.language_hints: [短码]`；OpenAI 兼容无语言参数、不发送。
  指定语种可显著降低「中文读出外语腔」的 Auto 误判。
- **Qwen-Audio-TTS 协议**（新接口类型 `dashscope-audio`）：千问AI平台
  `/api/v1/services/audio/tts/SpeechSynthesizer` 非实时端点，支持语气指令与复刻音色
  （如 `loongstella`）。请求体 `input.{text,voice,format,rate,instruction,language_hints}`，
  语速 `rate` 协议限 0.5–2.0（主进程夹取）；响应与 DashScope 原生同形（POST 拿签名 URL +
  无鉴权 GET 下载），共用同一条下载 / MIME 推导尾段；模型级失效自动回退到
  `qwen-audio-3.1-tts-flash` 并写回设置。端点容错与 DashScope 原生同一套（含「只改类型不改地址」
  的旧端点尾巴替换）。
- **分块边播边取**：朗读文本先清洗、总量截断到 `tts.maxChars`，再按句界分块（首块 ≤120 字、
  后续每块 ≤300 字）；首块合成完即开播，播放期间预取下一块（同一时刻最多 1 个在途合成）。
  长回复首声延迟从「整段合成完」降到「首块合成完」。桌面 `useTts` 与 Center Web 共用同一份
  纯管线（`@aurora/shared/browser` 的 `runTtsPipeline`）；停止 / 换读 / 失败语义不变
  （后块失败播完当前块再提示）。
- **朗读前清洗**：剥离围栏代码块 / 图片 / 裸 URL / Markdown 标记（链接留文字），幂等；
  渲染层分块前与主进程入口各洗一次，Center 中转的全量文本同样被清洗。`[excited]` 等情感标签
  原样保留（Qwen-Audio-TTS 支持文本内标签）。
- **合成缓存**：主进程内存 LRU（16 条 / 32MB），key 含全部合成参数 + 清洗后文本；
  重读同一条即时出声，改任何参数自然 miss；只缓存成功、不落盘。
- **设置页**：编辑卡新增「语气指令」「语言」两个常显字段（hint 按接口类型切换）；语速 / 格式
  hint 与夹取按协议区分；预设增至四条（新增 Qwen3-TTS 与 Qwen-Audio-TTS，自带 `type` 与
  `language: 'zh'`）。
- **Center**：网关 `routeKind` 接受新端点 rest 并为 `dashscope-audio` 型服务换音频签名票；
  网页端朗读改为按块发多条 `tts.synthesize` 中转命令（命令形状不变，hub / connector 零改动）。
- 文档：[06 §13.1–§13.8](../06-agent-core.md)、[08 §1/§6](../08-settings-onboarding.md)、
  [11 §4](../11-privacy.md)、[12 §6.4](../12-aurora-center.md)。

## 二、全局统一缩放与 DPI 适配

- 单一全局倍率（0.5–3、步长 0.1），`Ctrl +/−/0` 任一业务窗口触发七窗同步，落盘
  `ui-zoom.json`（不进 Schema）；≠100% 显示缩放徽标；提示条宿主宽与原生 shape 随倍率缩放；
  内部浮层与插件窗口不跟随。
- DPI：默认尺寸 fit 工作区、恢复几何按所在显示器 clamp/cap、小屏最小尺寸放宽；
  显示器增删 /  metrics 变化时提示条重新贴边、其余窗口重夹。
- 设置标题栏重设计：40px 品牌标题栏（aurora-mark + Aurora + Line Production 徽标 + 设置），
  侧栏品牌块移除。

## 三、流光提醒提示音：Win11 风格 + 自定义音效（Schema v42）

- 默认提示音对齐 Windows 11 风格（渲染层合成参数变化）。
- `notifications.customSoundPath`（v42 迁移补空串 = 默认音）：可选本地音频文件作为提醒音，
  自定义优先、失败回落默认合成音；音量与朗读共用提醒音量设置。

## 四、右栏文件面板重做

- 结构拆分：FilePanelToolbar / FilePanelList / FilePreviewBody + fileTypeMeta / FileKindIcon；
  列表 32px 行高、8 个类型色相、搜索 + 名称 / 大小排序、选中强调条、首读骨架、空态三档与窄栏降级。
- Office / PDF 正文：预览专用 ExtractPool（12s 超时，不与分类 / 自感知共用串行池）+
  512KB × 12 条内存 LRU，秒开且不带 evidence 头部；提取失败回落信息卡。
- 版式预览：manifest 只带首页、其余页按 index 单取；独立 office-port（产物落
  `userData/office-previews/panel`，LRU 6 + 24h sweep）；OfficeCLI 截图分页改 `--page`
  （修复 `--start/--end` 在截图模式被静默忽略、每页都拍第 1 页的问题）；版式失败自动回落正文。
- 系统打开：`preview:open`（默认程序 / 资源管理器定位）。

## 六、兼容性与升级

- 配置迁移两条，均**幂等且不覆盖用户已写值**：
  - `v41 → v42`：已有 `notifications` 补 `customSoundPath: ''`（= 默认提示音，行为不变）；
  - `v42 → v43`：每个已有 `tts.providers.<id>` 补 `instructions: ''` / `language: 'auto'`
    （= 不发送，请求体逐字不变）；`dashscope-audio` 为纯增量枚举，旧配置天然合法。
- 升级后建议：TTS 编辑卡把「语言」设为中文以锁定语种；要用语气指令请改用 Qwen-Audio-TTS
  接口类型（`qwen3-tts-flash` 不支持指令控制）。
- **Center 0.6.0 需重新部署**后网关才路由 Qwen-Audio-TTS 新端点（桌面直连网关不受影响）；
  部署按 `packages/center/deploy/README.md`（数据在 `./data`，不受影响）。Center 自身更新
  不打 tag、不上传 GitHub Releases。
- 自动更新：Center 更新源优先，GitHub Releases 回退，与 v0.6.4 相同。
