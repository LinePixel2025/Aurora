# Aurora v0.0.4 更新说明

发布日期：2026-09-25 ｜ 安装包：`Aurora-Setup-0.0.4.exe`（Windows x64，未签名）

本版本聚焦**三个高频使用场景的体验修复**：语音设置添加模型报 404、提示条快速对话不刷新
且旧对话污染上下文、设置「智能与工具」页信息过载。无配置结构变更（Schema 仍为 v9），
安装后直接覆盖升级，无需重新引导。

---

## 🎙 语音设置：添加模型不再 404，支持直接拉取模型列表

**修复的问题**：在「设置 → 语音」添加 TTS 模型后，点「连接测试 / 保存并试听」报
「接口或模型不存在（HTTP 404）」——多数情况是 baseURL 漏了 `/v1`（如填了
`https://api.siliconflow.cn`），或误把聊天接口的完整路径当成了 baseURL。

**改动**：

- **baseURL 自动规整**：
  - 只填域名（如 `https://api.siliconflow.cn`）→ 自动按 OpenAI 惯例补 `/v1`；
  - 误填 `/chat/completions`、`/completions`、`/models`、`/audio/transcriptions` 结尾 →
    自动剥掉这些尾巴再拼接；
  - 填了自定义路径（如 `/api/v1`、`/compatible-mode/v1`）→ 尊重原样，不擅自改写。
- **404 错误信息增强**：失败提示现在会显示**实际请求的完整 URL**，并给出排查建议
  （baseURL 是否以 /v1 结尾、模型名是否正确、该服务商是否支持 OpenAI 语音端点），
  不再只有一句模糊的「接口或模型不存在」。
- **新增「获取模型列表」按钮**：像「AI 模型」页一样，直接从服务商的 `/models` 接口
  拉取模型清单，在模型名输入框下拉选择，不用再手打模型名；手填依然可用。
  拉取请求走统一网络通道，系统代理设置对它生效。

## 💬 提示条快速对话：实时刷新 + 5 分钟滑动上下文

**修复的问题**：屏幕右缘提示条的快速对话面板不会自动出现最新消息（主界面的提问
永远看不到）；且会话历史无限累积，全部塞给 AI，越聊越跑偏。

**改动**：

- **展开即最新**：悬停展开面板时自动重拉最近 20 条消息并定位到底部；
- **每 5 分钟自动刷新**：面板保持展开期间每 5 分钟自动同步一次（AI 正在回复时跳过，
  不会打断输出）；
- **主界面消息实时同步**：在主界面发的提问现在会实时出现在提示条面板里；
- **5 分钟滑动上下文（防污染）**：快速对话发给 AI 的上下文**只包含最近 5 分钟内的
  消息**，更早的旧对话仅保留在界面上、不再参与推理，也不再注入历史摘要——
  悬置很久之后随手一问，AI 就像刚打开新对话一样聚焦当前问题。
  需要带完整上下文的长对话，请用主界面（左栏「快速对话」项或普通会话）。
- 附带修复：主界面**二次进入**同一会话时会话列表显示为空的问题。

## ⚙ 设置「智能与工具」页：信息架构收拢

**修复的问题**：该页由三张旧页合并而来，默认全部展开导致页面极长；同一安全警示
重复出现 4 处；启停控件三种样式混用；技能表格信息冗余。

**改动**：

- **技能、MCP 两组默认收起**，组头摘要直接显示状态（「已启用 3 / 共 4」「2 台服务器 /
  1 台启用」），收起也能一眼看清；「电脑操控工具」组保持展开（它是本页核心）；
- 同一安全说明收敛为一处完整表述，删除其余重复段；
- MCP 服务器的「停用 / 启用」按钮改为与工具、技能一致的**勾选框**；
- 操作回执统一为页面顶部一处提示，不再三处各自弹；
- 技能列表从 6 列精简为 4 列（来源并入名称徽章，删除与勾选框重复的状态列）；
- 数字输入框（超时 / 上限）改为定宽，不再拉伸整行。

## 升级说明

- 直接运行 `Aurora-Setup-0.0.4.exe` 覆盖安装；已安装版会通过应用内自动更新收到推送
  （`latest.yml` 已同步更新源仓库）。
- 配置、会话、技能与凭据全部保留；本版本无配置迁移。
- 若之前在语音设置遇到 404 的 baseURL 不必修改——现在会自动规整；当然，填标准格式
  `https://api.siliconflow.cn/v1` 依然最稳。
