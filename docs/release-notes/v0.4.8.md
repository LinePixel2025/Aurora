# Aurora v0.4.8

本次版本汇总 **v0.4.7 → v0.4.8** 的全部更新：桌面端两项功能改动（Center 官方图片 / 语音模型
的客户端选模真正生效、自感知四周流光改强调色单色）与发布口径整理。Aurora Center 服务器代码
本版无改动，线上沿用已部署的 `aurora-center:0.4.7`（用量分页 + 官方模型配置表单），无需换装。

## 一、桌面端 · Center 官方模型支持客户端选模并真正生效

- **选模入口两处、写同一字段**：设置 → 供应商页的生图 / TTS / STT 官方行新增「官方模型」下拉，
  与 Aurora Center 页「官方模型」区组双向联动（同一 `center.officialModels.<cap>.model`）；
  此前供应商页展示被落盘镜像的 defaultModel 写死值压制，现在展示与实际分派一致。
- **读时改写层**：主进程新增 `center/aware-settings.ts`，官方服务启用时把用户所选模型与其目录参数
  （生图 `size`、TTS `voice` / `speed` / `format`、STT `language`）覆写进 `center-*` Provider 的
  返回副本 —— 生图、TTS（含试听与拉模型）、STT、Center 远程中转四条链路共用同一副本，一处选择全链生效。
- **解析链与镜像同源**：选中项 → defaultModel → 首个（空串 = 未选择）；所选模型被 Center 下线时
  自动回落 defaultModel 并记一次去重日志，不触发「回落本机模型」提示。
- 新增 20 例单测覆盖解析链、覆写与回落；docs/08 §8、docs/12 §12.2 同步生效口径。

## 二、桌面端 · 自感知四周流光改强调色单色

- **配色**：四边光幕从彩虹渐变（青→蓝→紫→粉→橙）改为**强调色单色柔光** —— 唯一色源是
  `--aurora-blue`，混白得薄荷高光、混深色得波谷，三档明暗起伏替代色相流转做层次，
  与提示条「正在感知」卡片的视觉语言同源。
- **跟随强调色**：流光浮层窗口接入 `applyAppearance`（读设置 + 订阅变更），换强调色
  （青绿 / 紫 / 玫瑰 / 琥珀…）时四边光幕与卡片一起变；默认强调色下为蓝色系。
- **四边一致**：左右边带不再是横向彩虹被压进 72px 竖条的静态色带，四条边观感统一。
- 几何、动画节奏、入场 / 退场与全部显隐门控（含「通用 → 外观」的**流光特效**开关）不变；
  配置版本保持 v33，无迁移。实测帧成本 mean 5.53ms / worst 6.3ms（≈60fps）。
