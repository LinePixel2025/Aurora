# Aurora v0.8.1

本次版本汇总 **v0.8.0 → v0.8.1** 的全部更新。主题是**子代理体验**（派得更积极、看得更像普通
对话、建得更方便）与**界面提示的可读性**。

本版**不升配置 Schema**（仍为 **v46**，无迁移）、插件 API 仍为 **v1**；Aurora Center 版本线
不变（0.7.0，本次不升）。已有配置 / 会话 / 子代理 / 插件 / 自动化数据全部保留。

## 一、子代理派发更积极

v0.8.0 把子代理做成可配置能力，但真实会话里调用率仍偏低。本版把提示词从「许可式」升级为
**触发式硬规则**：

- `BASE_PERSONA` 增加一条通用倾向：复杂任务先拆解，能独立并行的子任务优先派子代理，
  单文件 / 几次读取的小任务自己做。
- `task` 工具规范改为「先分流再动手」：满足任一条件就派，不要边读边决定 ——
  ① 读 ≥3 个文件或跨 ≥2 个目录才能答清的调研 / 排查 / 对比 / 汇总；
  ② 实现型任务能拆成独立子任务（要改文件 / 跑命令就选 `write` / `execute` 档）；
  ③ 需要逐文件批量处理或审查。同时写明**小任务豁免**，避免调度成本大于收益。
- `task` 工具描述首句同步改为「优先用本工具分流多步任务，不要自己逐个文件读，省的是当前
  对话的上下文预算」。
- 派发协议、三档权限、并发上限（同会话 3 个 / 写子代理串行）、确认链全部不变。

## 二、子代理对话统一为普通对话样式

「子代理」页面、`task` 工具卡展开体、右栏查看器共用的对话视图，此前是独立的气泡 + 带边框
工具小卡片，与主对话明显两种观感。本版改为**与主对话同一套排版语言**：

- 主代理的任务指令**右对齐强调色胶囊**（与「用户气泡」同款）；子代理正文**左对齐、不套
  气泡**，走与主对话同一份 Markdown 渲染器（同一安全基线：先转义再白名单标记）。
- 工具调用改为**轨迹行**：左侧竖脊 + 节点圆点、状态点色 + 每行一枚语义图标 +
  「动词 + 关键参数」的可读标题 + 结果摘要，点开看参数与结果全文。
- 每轮带头像列；最后一条有正文的助手消息标「最终报告」；只读口径（无输入框 / 无干预入口）
  与底部说明不变。
- `task` 行的展开体不再重复「参数 / 结果」（对话已包含任务指令、每次工具调用的参数与结果、
  最终报告，是严格超集）；右栏查看器也去掉重复的两行任务指令。

## 三、新建子代理：弹窗 + Aurora 起草

设置页「Agent → 子代理」的创建入口从页内四行小表单改成**完整的创建弹窗**：

- **让 Aurora 起草**：一句话描述想要的子代理（附四个示例），点「生成草稿」后由新增的
  `subagents:draft` 通道调用当前模型，生成 `name` / `description` / `instructions` / `access`
  预填表单。**草稿不自动保存** —— 用户改完点「添加子代理」才走 `settings:update`。
  无模型、网络失败、输出畸形分别给可读原因；生成中禁用按钮；`Ctrl+Enter` 可直接生成。
- **手动填写**永远可用：名称（≤40）/ 用途说明（≤200）/ 三档工具权限（分段按钮，`execute`
  就地提示敏感后果）/ 指令（≤4000），带长度计数与重名提示；上限 20 条保持不变。
- 新增通道只服务设置页：`agent.subagents` 整组仍在 `SETTINGS_READONLY_PREFIXES`，
  Agent 自己既不能调用该通道，也不能用 `set_setting` 自建子代理或放宽档位。
- 隐私：只有用户主动点「生成草稿」时，才把你写的需求与已存在子代理名称发给模型；
  不发送会话历史、文件或本地数据（见 docs/11 §4）。

## 四、提示不再压字：主区顶部居中通知

「添加项目」「进入 / 退出计划模式」「计划批准」「标签上限」「Computer Use 授权」等短回执，此前
固定在窗口**左下角**：既会压住左栏底部的模式徽章 / 设置齿轮，又因为底色近乎透明，左栏文字会
透上来像「字体重叠」。本版改为：

- 渲染在**主区标题栏下方、水平居中**，实底 + 1px 描边 + 阴影，max-width 520 可换行；
- 左侧语义图标、右侧关闭按钮、底部 2px 自动消失进度条（成功 2.6s / 失败 6s，
  `prefers-reduced-motion` 下降级为无动画）；
- `role="status"` + `aria-live="polite"`；容器不接收指针（只有 × 可点），不挡正文选中与点击；
- 全部来源仍走 `flashProjectNotice` 这一条通道，行为（连点先清旧、失败留久一点）不变。
