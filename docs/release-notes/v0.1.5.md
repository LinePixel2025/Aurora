# Aurora v0.1.5 更新说明

发布日期：2026-09-26 ｜ 安装包：`Aurora-Setup-0.1.5.exe`（Windows x64，未签名）

这一版的主题是 **「从能用到敢用」**：给 AI 装上**项目边界**、**权限档位**、**改前留底**与**可续跑的长任务**。

v0.1.4 让 AI 学会了精确改文件，但那时它还缺四件"生产环境必须有的东西"：
它不知道自己在哪个项目里干活、你没法把它的写权限收紧、它改错了没法一键回滚、
一个长任务跑到一半停下来就再也接不上。这一版把这四件补齐，
**配置 Schema 从 v12 升到 v15**（自动迁移，无需重新引导；直接覆盖安装即可）。

---

## ✨ 一、项目机制：AI 现在知道自己在哪个项目里

设置 → 通用 → **「项目」**可以登记若干项目（名称 + 根目录）并指定**当前项目**。

- AI 会从**项目根一路向下到当前工作目录**逐层读取 `AGENTS.md`（同目录有 `AGENTS.override.md` 时后者优先），
  作为「项目约定」注入它的系统提示词 —— 于是"这个仓库用什么包管理器、提交信息怎么写、别碰哪些目录"
  这类约定可以写进 `AGENTS.md`，AI 每次都会读到。单次收集上限 24 层 / 32 KiB，超限会明确标注截断。
- 右栏新增**「当前项目」卡**：一眼看到现在在哪个项目、根目录在哪，一键打开文件夹；
  目录被改名 / 移动盘拔掉时会**标红**并给出「重新选择目录」。

## ✨ 二、三档权限：收紧到什么程度，由你决定

对话窗输入框右侧的下拉（以及设置 → 智能与工具）可以在三档之间切换：

| 档位 | 行为 |
|---|---|
| **只读** | 写文件、改文件、跑命令、打开路径这些工具**根本不注册**（不是"注册后再拒绝"，AI 的清单里就没有它们）；`todo_write` 同样摘掉，保留只读的 `todo_read` |
| **变更前确认**（默认） | 与历史行为完全一致：敏感工具逐次弹确认卡片 |
| **完全权限** | 在**当前项目根之内**免确认（仍写审计日志），越界操作照旧弹卡 |

- 确认卡片上多了第三个按钮 **「本会话都允许」**：放行本次，并且**本会话内同名工具**不再询问
  （换会话、换工具都会重新问）。
- 项目根边界用 **realpath 前缀校验**（`..`、符号链接、目录联接都别想绕），覆盖读写文件、列目录、
  搜索与命令的工作目录；**没有配置项目时行为与以前完全一致**。

## ✨ 三、改前自动留底：一键回滚

AI 的每一次 `write_file` / `edit_file`，都会在**真正写盘之前**把原内容存一份（`%APPDATA%/Aurora/backups/`）。

- 右栏**「文件备份」卡**列出最近几份，点「回滚」把文件恢复到某一份快照；
  **回滚本身也会先留一份**，所以点错了还能再撤回。
- 保留策略：每个文件最多 20 份、单份 512 KiB 以内、整个备份目录 200 MiB
  （设置 → 智能与工具 → 「文件备份」可调；关掉开关时界面会明确提示"改动将不可回滚"）。
- 文件太大 / 备份已关闭 / 读不到原文件时**不会静默跳过** —— 工具结果里会写明"未保存快照：…"，
  AI 和你在对话里都能看到。

## ✨ 四、长任务可暂停、可续跑

一次请求现在是一条**任务（Job）**：每跑完一轮就把"跑到第几轮、下一步做什么、已完成哪些步骤、花了多少 token"落盘。

- 轮次用完或 token 预算触顶时，任务进入 **「已暂停」** 并**说明原因**（轮次上限 / token 预算 / 已取消），
  不再是"静默收尾"。
- 右栏**「任务」面板**显示进度（第几轮、token 用量、步骤时间线、待办），点 **「继续」** 就**接着上次的进度跑**
  —— 不会把你那条提问重复记一遍；点「取消」结束它。
- **关掉应用再打开，没跑完的任务仍在面板里，可以直接继续**（这一版专门做了两次启动的实测验证）。
- 三个上限可配且**改完立即生效**：设置 → 智能与工具 → **「Agent 循环」**
  （每轮最多几轮工具调用 / token 预算，0 = 不限 / 轮次用尽后允许自动再续几轮）。
- 左栏底部新增「任务」入口，带任务数角标。

## 🔧 五、顺带修掉的一个老 bug

会话与待办清单的「首读竞态」：并发首次读取时，其中一个可能拿到**空的历史快照**，
随后一次写入会把磁盘上的历史**整体覆盖**（丢消息）。现在改成共享同一个读盘 promise，
并在读回时与在途写入合并。这个 bug 在"启动后立刻连续操作"时最容易撞上。

## ⚠️ 已知问题（下一版修，升级前请知悉）

这一版做了三份独立的只读代码审查，**如实披露**还没修的三条：

1. **自动续轮的第二次及之后请求会丢上下文**：默认开启的"自动续轮"（用完轮次后再续 2 轮）在第二轮
   发出的请求里**没有本轮提问、也没有上一轮的工具结果**，模型可能重复执行已经做过的写/命令操作。
   **临时规避**：设置 → 智能与工具 → 「Agent 循环」把「自动续轮次数」改成 **0**（此时轮次用尽会正常
   暂停在任务面板里，点「继续」是安全的）。
2. **`agent.loop.*` 与 `agent.snapshots.*` 目前 AI 的 `set_setting` 也改得动**（文档与实现不一致；
   `agent.permissionMode` 与项目配置不受影响）。也就是说 AI 理论上能自己放大轮次/预算、
   或在写文件前关掉备份开关 —— 该调用需要你确认，但与本版"这几项 AI 改不动"的表述不符。
3. **配了当前项目后，缺省工作目录/搜索根仍在项目根之外**：不指定 `cwd` 的 `run_command` 在
   **完全权限**档下会在用户主目录执行（不弹卡）；在「变更前确认」档下同类命令会失败；
   `grep` / `glob` 不指定根时同样会越界报错。**临时规避**：让 AI 传绝对路径，或暂时用「变更前确认」档
   （每次都会问你）。

其余已知限制见 `AGENTS.md` 的「尚未生效 / 已知限制」：三档权限 + 项目根前缀校验**不是** OS 级沙箱
（`run_command` 仍是当前用户权限）；无项目时不做边界校验。

## 📦 安装与升级

- 直接用 `Aurora-Setup-0.1.5.exe` 覆盖安装：配置、会话历史、分类流水、技能与凭据**全部保留**，
  配置 Schema 自动从 v12/v13/v14 迁移到 v15。
- 首次安装仍是四步引导（欢迎 → AI 模型 → 模式 → 完成）；API Key 经 Windows `safeStorage` 加密后落盘。
- 安装包**未签名**，Windows SmartScreen 可能提示"未知发布者"，选择「仍要运行」即可。
