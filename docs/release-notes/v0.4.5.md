# Aurora v0.4.5

本次版本是从 **v0.4.4** 到 **v0.4.5** 的完整更新，桌面端与 Aurora Center 同步升级到
**0.4.5**。重点完善 Provider 与 Center 官方模型的联动、对话窗模型选择口径、能力路由，
并修复 Center 登录按钮整行 hover / 点击误触发的问题。

## 一、模型来源与模型双下拉

- 对话输入区由“单个模型下拉”改为“**模型来源 + 模型**”双下拉，来源明确区分
  `Center 官方` 与 `用户模型`，不再提供语义含糊的“跟随全局”清除项。
- `用户模型` 聚合全部非 `center-*` Provider 的 `model` 与 `modelList`；同名模型以
  `Provider · 模型` 区分，选择后仍写入 `(providerId, model)` 对。
- `Center 官方` 来源只在 Center 官方语言模型开启且保留 Provider 有候选时出现；
  切换来源立即选择该来源的默认模型，切换模型立即写入当前会话覆盖。
- 没有 `meta.llm` 会话覆盖的旧会话会如实展示当前实际生效的模型，但不会因为打开页面就补写；
  只有用户第一次主动选择来源或模型时才固化为会话覆盖。
- Center 官方模型不可用时隐藏 Center 来源，已有覆盖按现有提示逻辑回落；Center 模型的思考等级
  由管理员目录参数决定，客户端只读展示，不允许改写本地 `center-*` 参数。

## 二、Center 官方模型路由

- 解析链固定为：**会话覆盖 > Center 官方语言模型 > 本机全局默认 Provider**。
  Center 官方语言模型有效时可以直接作为默认模型，不再强制要求先配置本机 Provider。
- 首次引导完成条件同步更新：本机有效默认 Provider 或有效 Center 官方语言模型满足其一即可，
  避免已登录且已启用 Center 官方模型的用户仍被反复要求配置本机模型。
- Center 官方模型关闭、登录失效或目录不可用时，回落到本机可用 Provider；没有本机候选时
  如实报错，不静默改发其他服务。
- 已有会话若仍保存 `center-*` 覆盖，但 Center 官方模型已经关闭，会按最新路由回落本机 Provider，
  并清理该覆盖，避免每次请求重复命中失效来源。

## 三、TTS / STT / 生图路由与只读官方卡片

- TTS、STT、生图各自以能力配置的 `active` 为实际分派依据；Center 官方开关只决定
  `center-*` Provider 是否可用，不再无条件覆盖用户选择。
- 首次开启某类 Center 官方服务时自动切到对应官方 Provider；之后用户可切回本机模型，
  官方开关保持开启也不会抢回默认。
- Provider 页为启用后的 `center-imagegen` / `center-tts` / `center-stt` 显示只读官方卡片，
  包含目录状态与可用模型，但不提供凭据、Base URL、模型编辑或删除入口。
- 切回本机模型不会关闭 Center 官方开关；官方卡片继续展示并标记为“未作为默认”。
  目录不可用时保留卡片并显示暂不可用状态。

## 四、文件自感知后台模型

- 设置页会把文件自感知后台模型固化为显式的 provider + model；旧配置为空时仍在运行时兼容
  跟随全局主模型，首次打开设置页后写入显式选择。
- 显式后台模型不可用时继续暂停队列并显示原因，不回落主模型，避免把文件正文发送给用户未选择的
  Provider。
- 隐私文档和设置说明同步改为“显式选择的后台模型”，与运行时代码保持一致。

## 五、修复

- 修复桌面端 Center 页面「登录账户」按钮在鼠标位于同一行、但未进入按钮矩形时也触发 hover 的问题。
  根因是共享 `SettingField` 使用 `<label>` 包裹按钮，浏览器会把整行 hover / click 代理给内部按钮。
- `SettingField` 新增 `as="div"`：只含按钮的字段不再使用 `<label>`，从结构上断开浏览器代理；
  普通输入框、选择框和文本域仍保留点击标签聚焦的便利。
- Center 登录字段的 capture 回归同时断言根节点为 `DIV`，并验证点击标签文字不会触发登录按钮。
- 发布流程强制 GitHub Releases 与 Aurora Center 更新源双投；只上传一端时发布不算完成。

## 六、兼容与限制

- 配置 Schema 保持 **v31**，本版本没有配置迁移；会话文件版本保持 **v7**，没有数据迁移。
- Center 官方语言模型仍可在会话级覆盖；生图、TTS、STT 不引入会话级路由，沿用能力级 `active`。
- Center 官方模型目录、上游密钥和用量口径与 v0.4.4 一致。本版本不改 Center 数据目录结构。
- Windows x64 安装包仍 **未代码签名**，首次安装会出现 SmartScreen「未知发行者」提示；
  需要管理员权限时另会弹出 UAC。
