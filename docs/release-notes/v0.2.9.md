# Aurora v0.2.9 更新说明

发布日期：2026-09-30 ｜ 安装包：`Aurora-Setup-0.2.9.exe`（Windows x64，未签名）

这一版是一轮**细节优化**：输入框、动效、设置页、自动化历史、Center 移动端、
外观自定义、侧栏与触摸，共十一处。另有 **Aurora Center 服务端同步更新**（移动端对话显示修复）。

**有一处配置迁移**：Schema 升到 **v21**（新增 `general.edgeBar.display / position` 与
`appearance` 分组）。覆盖安装即用，已有设置一个都不会被改。

---

## ⌨️ 一、输入框与消息区

1. **权限选择文字不再溢出组件边框**：窗口较窄或高 DPI 缩放下，输入卡工具行的三枚芯片
   （权限 / 模型 / 思考档）此前既不收缩也不裁剪，文字会顶出输入卡的圆角边框。
   现在三者按「键位提示 → 模型 → 思考档 → 权限」的顺序依次让位、各自省略号收尾，
   任何宽度下都不会溢出。
2. **工具调用完成即自动折叠**：Agent 执行工具时展开查看进度的卡片，翻到成功 / 失败终态后
   自动收起，只留一行结果摘要（点开仍可回看）；不再一直占着消息区。
3. **运行态动效升级**：运行中的工具卡现在是「扫光 + 边框呼吸」双层表达，状态点外加一枚
   扩散涟漪；思考块的左侧竖轨同步呼吸。完成瞬间仍有一次性确认弹跳。
4. **主区切换有了过渡**：对话 ↔ 子代理 ↔ 自动化页面切换、任务面板出入、自动化两个弹窗
   （编辑器 / 历史）的呼出与收起都改为淡入淡出 + 入场微弹，不再硬切。

## ⚙️ 二、设置页

5. **文案再精简一轮**：电脑操控工具、项目、勿扰时段、管理员启动等区组的说明压到一句。
6. **技能列表错位修复**：技能表改为固定列宽（名称 32% / 脚本与启用列钉宽），
   长描述与适用场景最多两行截断（悬停看全文），行高不再参差。

## 🤖 三、自动化

7. **历史弹窗更可用**：失败记录在行内直接显示一行失败原因（悬停看全文）；
   Agent Mode 记录有常驻的「查看对话」入口，回放头带上自动化名 / 触发时间 / 状态 / 用时；
   运行中的记录状态图标自旋 + 颜色呼吸。
8. **Normal Mode 操作组件扩容**：新增 **打开网址** 与 **打开应用** 两种组件。
   安全边界不变：网址只放 http(s)（保存校验与执行器双层把守，`file:` / 自定义协议一律拒绝）；
   应用走与「打开文件夹」同一通道（`shell.openPath`，不经 shell、无参数拼接面）；
   两者的参数都只能由你在界面里配置 —— AI 写不进自动化定义。

## 🎨 四、外观自定义（新）

9. 设置页「常规 → 外观」新增**强调色**主题：品牌蓝（默认）/ 青 / 紫 / 玫瑰 / 琥珀五档，
   改完即时生效、四个窗口统一跟随。**Agent 也能帮你调**：它可以用 `set_setting`
   改 `appearance.accent`（仅此一个外观字段，且只是换个颜色）。

## 🪟 五、提示条与触摸

10. **提示条的位置可配了**：设置页「常规 → 提示条」新增「所在显示器」（主显示器 / 跟随鼠标）
    与「屏幕位置」（右缘 / 左缘）两个下拉，保存后立即重排，无需重启。
11. **触摸体验**：触摸屏上点竖条 = 展开 / 收起面板（此前纯悬停驱动，触摸根本打不开）；
    会话归档钮与代码复制钮在无悬停设备上常显（此前永远等不到显形的那一下）。
12. **主界面左栏去杂糅**：原本单独挂在左栏底部的「任务」入口收拢进固定项组
    （快速对话 / 子代理 / 自动化 / 任务），删除了两处重复定义的同一套样式。

## 🌐 六、Aurora Center

13. **移动端对话显示修复**：≤720px 竖屏下「远程控制 / 会话列表」两块面板此前最多吃掉 80vh、
    把对话区压扁。现在两块面板收进分段切换条背后（默认收起、点开互斥展开、内部滚动），
    对话区保底 60% 高度；输入框字号提到 16px，规避 iOS 聚焦缩放。
    服务端已随本版部署，网页端刷新即用。

- **配置迁移 v20 → v21**：只为已有 `general.edgeBar` 补两个缺省字段、整组缺失时补
  `appearance`；你已写的值原样保留。`pnpm verify` 的迁移条数断言随之变为 21 条。
- 提示条新字段子集对 Agent 可写（`general.edgeBar.display / position`），
  `set_setting` 的可写清单已同步。
