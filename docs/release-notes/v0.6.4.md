# Aurora v0.6.4

本次版本汇总 **v0.6.3 → v0.6.4** 的全部更新。主线是**插件临时输入窗口**：桌面小组件为
「点击不抢前台」固定了 `focusable: false`，卡内文本输入拿不到键盘焦点；本版给插件补上宿主创建的
临时对话框（`contributes.dialogs` / `ui.dialogs`），窗口中可正常键入文字，支持 Aurora 声明式组件
或自定义 HTML / CSS，确定 / 取消 / 关闭 / 超时 / 插件退出后**立即销毁**，不常驻。

本版配置 Schema 保持 **v41**（无配置迁移）；插件清单与宿主 API 仍为 **v1**（新增 `ui.dialogs`
权限与清单贡献，旧插件不受影响）；Aurora Center 服务器**不随本版升级**（仍为 0.5.2，版本线独立，
本版无 Center 代码改动）。已有配置 / 会话 / 插件 / 自动化数据全部保留。

## 一、插件临时对话框（声明式 / 自定义 HTML·CSS）

- **清单贡献**：`contributes.dialogs`（≤ 4），每项 `schema` 与 `entry` 二选一；
  `defaultSize` 限制 320–900 × 160–800；声明贡献必须同时声明新权限 **`ui.dialogs`**。
- **运行期 API**：`ctx.ui.openDialog({ dialogId, params? })` 在窗口销毁后返回
  `{ submitted, values, data? }`；`params` ≤ 64 KB。同一插件同一时刻只允许 1 扇，
  全部插件合计 ≤ 4 扇，最长存活 10 分钟（到点按取消结算）。
- **声明式**：`schema` 复用面板的受控组件（输入 / 文本域 / 选择 / 开关 / 数字 / 滑块等），
  宿主绘制底部「取消 / 确定」；点确定时把控件值（`bind` → 值）作为 `values` 返回。
  可选实现 `invokeDialog(dialogId, method, params, ctx)`（`params = { params, values, init }`）
  做校验或动态换 schema；返回 `{ close: false, toast }` / `{ close: false, error }` 可保留窗口，
  返回 `{ close: true, data }` 关闭并结算。
- **自定义 HTML / CSS**：`entry` 指向包内页面，走与面板完全相同的 `aurora-plugin://` 沙箱
  （专用 preload、独立 partition、CSP、禁弹窗 / 下载）；页面 URL 带 `?dialog=<id>`，
  用 `window.auroraPlugin.request()` 与插件通信，插件返回 `{ close: true }` 后窗口销毁。
- **窗口行为**：与桌面小组件相反，**可激活**（`focusable: true`）以接收键盘输入；无边框、居中、
  不可缩放 / 最大化；标题栏与关闭键由宿主绘制。确定 / 取消 / × / Esc / 10 分钟 / 插件进程退出
  都会**销毁**窗口，不写几何、不常驻、不上报 Center。同一插件已有窗口时再次调用回
  `E_PLUGIN_INVALID_ARGS`。
- **只在本机**：临时对话框不进入 Center 侧栏镜像，也没有远程批准 / 页面托管。

## 三、兼容性与升级

- 配置 Schema 保持 **v41**，无迁移；插件 API 仍为 v1，旧插件不需要改动。
- 新增 `ui.dialogs` 权限只在插件声明 `contributes.dialogs` 时必需；安装弹窗会逐条展示。
- 自动更新：Center 更新源优先，GitHub Releases 回退，与 v0.6.3 相同。
- 已知边界：
  - 在 `invokeTool` 里等待用户输入时，需把该工具的清单 `timeoutMs` 调大（默认 60 秒会把
    「用户还在输入」判定为工具超时；窗口不会自动关，但本次工具调用已经失败）；
  - 每个插件同时 1 扇、全局 ≤ 4 扇、最长 10 分钟；不可缩放 / 最大化，关闭后不保留位置与内容；
  - 临时对话框只在本机，不上报 Center。
