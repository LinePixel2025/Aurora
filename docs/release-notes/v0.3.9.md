# Aurora v0.3.9

本次更新聚焦客户端性能：降低 CPU 占用、提升流式渲染帧率、收敛内存，并加快启动。

- **空闲 CPU**：前台窗口探针从每 5 秒一次改为 60 秒 TTL 懒刷新，系统感知首次被消费时才激活；
  纯空闲时不再周期性启动 PowerShell 探针。实测空闲 60 秒应用 CPU 约 765ms（1.28% 单核），
  上一版约 1499ms（2.50%）。
- **流式渲染**：回复未收盘时按约 80ms 节流且不做语法高亮，收盘后一次性高亮；
  超长代码块与未知语言不再走昂贵高亮。爆发探针最坏心跳 91ms、最坏帧间隔 63ms、
  长任务 1 个（最大 56ms），限额为 160ms / 110ms / 20 个。
- **内存**：会话摘要不再把磁盘上全部会话消息常驻内存，已装载会话按 LRU 有界淘汰；
  20.9MB 会话数据下摘要内存增量约 0.5MB（旧行为约 23MB）。
- **图片与面板**：对话图片进入视口才读，并由主进程缩略到长边 720；
  隐藏的浏览器标签 10 分钟无激活后释放页面；滚动心跳空闲降到 250ms 一次。
- **启动**：electron-updater、systeminformation、chokidar 改为按需加载，
  生产构建启动约 244ms（上一版 610–693ms）；四进程常驻内存约 377MB。

安装包为 Windows x64，未代码签名。
