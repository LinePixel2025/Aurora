# Aurora v0.4.4

本次版本是从 **v0.4.3** 到 **v0.4.4** 的完整更新，桌面端与 Aurora Center 同轮升级到 **0.4.4**。
重点是 Aurora Center 官方模型网关、真实 Token 用量和客户端自托管更新，同时纳入 v0.4.3 之后
完成的文件自感知重置、源文件清库与流光连续性修复。

## 一、Aurora Center 官方模型

- Center 新增语言模型、图像生成、TTS、STT 四类官方模型能力；每类配置一个上游和多个开放模型。
- 管理员可配置上游协议、Base URL、模型与 API Key；生成参数按模型保存，包括视觉、上下文窗口、
  思考等级、生图尺寸、音色、语速、格式和识别语言。
- 上游 API Key 使用 `AURORA_CENTER_SECRET` 经 HKDF 派生 AES-256-GCM 密钥后落盘；
  管理接口只回传 `apiKeySet`，客户端目录不包含上游地址、密钥或未开放模型。
- 网关保持上游协议、SSE 流式输出、工具调用和错误状态；语言模型支持 OpenAI Chat Completions 与
  Responses，生图支持 OpenAI 兼容协议，TTS / STT 支持 OpenAI 兼容与 DashScope。
- DashScope TTS 的临时音频 URL 改写为 Center 短期签名代理地址，客户端不直接访问上游。
- 客户端配置升级到 **Schema v31**，Center 页新增四类官方模型开关与模型下拉；语言模型支持全局默认
  和会话级覆盖。
- 官方模型不可用时按能力提示一次并回落本机 Provider；没有本机可用 Provider 时明确报错，
  不静默改用其他服务。

## 二、Token 用量

- Center 只记录上游响应中真实返回的 `usage`，不按字符估算，也不持久化提示词、回复、音频或图片。
- 请求明细按日 NDJSON 保存并保留 **180 天**；终身累计按用户、客户端和模型持续保存。
- 普通用户只能查看本人用量；管理员可查看全站并按用户、设备、模型和日期筛选。
- Center Web 新增 `#/usage` 页面：终身总量、区间输入 / 输出 / 缓存命中折线图和最近请求记录。

## 三、客户端自托管更新

- Center 新增 Release 存储与公开下载路由，支持 `latest.yml`、安装包与 blockmap。
- 更新下载支持 HEAD、Content-Length 和 Range / 206，可继续使用 electron-updater 差分更新。
- 管理员网页、`scripts/release.mjs --publish-center` 和 `aurora-center releases publish`
  都可上传并发布。
- 发布先进入 staging，校验 `latest.yml` 的 version / size / sha512 与安装包、blockmap 一致后，
  才原子切换当前 latest；校验失败不影响已发布版本。
- 客户端优先使用当前配置的 Center 更新源；Center 未配置、请求失败或 `latest.yml` 缺失时回落
  GitHub Releases。Center 明确返回“已是最新”时不再回落。
- `AURORA_UPDATE_FEED` 仍保留为最高优先级的本地更新源验证开关。

## 四、自感知与流光修复

- 自感知重置只删除 Aurora 管理的笔记、索引、队列、记录、用量、版本备份与 `awareness-*` 会话，
  保留配置、源文件和知识库目录内无关文件；重置后恢复监听但不自动扫描。
- 分析记录只保留内容实际变化后的 `done` / `error` / `conflict`，删除源文件写
  `skipped(delete)`，不再堆积未变化的中间状态。
- 源文件删除时同步清理 Markdown、状态项、`INDEX.md` 条目和版本备份，避免陈旧记忆继续进入 Agent。
- 前台 Agent 忙碌时暂停启动新的后台文件分析，Agent 全部结束后自动恢复。
- 顶部流光改为完整状态机：批量分析在文件交接处不广播空闲帧，仅批次结束或门控暂停时退场。
- 修复流光顶部空隙：光幕从显示器物理边界第 0 像素开始，不再受工作区上方间隔影响。

## 五、兼容与限制

- 配置 Schema 从 **v30 升级到 v31**：为 `center` 补四类默认关闭的 `officialModels` 选择。
  迁移只补缺失字段，不改变已有 Center 设置。
- 会话文件版本仍为 v7；本次没有会话数据迁移。
- 官方模型用量只统计语言模型 Token；生图、TTS、STT 没有统一 Token 语义，不折算成 Token。
- 首版不包含用户配额、计费或逐用户授权；所有登录用户可使用管理员开放的能力。
- Center 公网部署仍建议 TLS 反代；`AURORA_CENTER_SECRET` 必须稳定保存，轮换后旧上游密钥密文
  不能自动解密。
- Windows x64 安装包仍 **未代码签名**，首次安装会出现 SmartScreen 提示。
