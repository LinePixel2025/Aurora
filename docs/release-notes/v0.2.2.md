# Aurora v0.2.2 更新说明

发布日期：2026-09-27 ｜ 安装包：`Aurora-Setup-0.2.2.exe`（Windows x64，未签名）

这一版把 **Aurora Center 从「远程开对话」升级成完整的远程控制中心**，并给 Agent 加上了
**会话级项目**。九项 Center 增强 + 一项 Agent 改造：

- Center 网页端可以**注册账号**了（不再依赖管理员手工建号）；
- 桌面端点一下「登录账户」→ 自动打开 Center 网页 → 网页上输一次账号密码，
  客户端**自动登录连上**（设备授权，密码不再进桌面端）；
- 远程会话里 Agent 的**完整运行状态**（思考 / 工具调用 / 任务清单 / 子代理）实时可见，
  **敏感操作的权限申请卡也推到网页端**，远程点一下批准即可；
- 客户端发来的文件有了**独立管理页**，且 **24 小时后自动删除**；
- Center 网页支持**手机浏览器**（两档断点完整适配）；
- 「配对令牌」概念**整体退场**——账号体系下它已无用武之地。

配置 Schema **不变**（仍是 v17）：本版不迁移任何配置，覆盖安装即用。

---

## 🌐 一、Aurora Center 扩展（服务器 + Web 端）

### 1. 自助注册

- 登录页新增「注册」切换：用户名（3–32 位字母数字下划线连字符）+ 密码（≥ 8 位），
  注册成功直接进入控制台。
- 服务器 `config.json` 加 `allowRegistration`（默认开启），不开放注册的内网部署可一键关闭。

### 2. 设备授权登录（推荐的接入方式）

v0.2.1 的账号直登仍可用，但新增更适合日常的路径：

1. 桌面端 设置 → Aurora Center → 点「**登录账户**」；
2. 自动打开浏览器进入 Center 网页确认页（显示形如 `ABCD-1234` 的确认码供核对）；
3. 在网页上**注册 / 登录并一键确认**；
4. 客户端自动拿到凭据、绿灯连上——**密码全程不经过桌面端**。

挑战 10 分钟有效、一次性消费；clientId 已被其他账号绑定时确认会被拒绝（防抢注）。
原「密码登录」降级为回落按钮。

### 3. Agent 运行状态完整可见 + 权限申请网页批复

- 远程会话此前只能看到正文 / 思考 / 工具卡；本版补上**任务清单（todo）卡**与
  **子代理卡**，网页端看到的与桌面主界面同规格。
- **敏感工具的权限申请卡同步推送网页端**（`confirm.request`）：显示工具名、入参摘要与
  倒计时，远程「批准 / 拒绝」直接生效。桌面本机卡片照旧弹出，两边先到先得、幂等；
  超时（默认 60s）或客户端离线一律按拒绝——远程批准只是把「问用户」的界面延伸到网页，
  不绕过任何本地闸门。

### 4. 文件管理页 + 24 小时自动删除

- 新增 `#/files` 文件管理页：所有客户端上传文件的清单（来源 / 大小 / 备注 / 上传与
  过期时间），行内下载与删除。
- 上传文件**24 小时后自动删除**（服务器启动 + 每 15 分钟清理一轮）；旧版上传的文件按
  上传时间补算过期点。

### 5. 移动端适配

- 网页控制台针对手机浏览器做了两档断点（≤ 720px / ≤ 480px）：客户端列表横向滚动、
  会话区全宽、表格可横向滚动、触摸目标不小于 40px——在手机上批一张确认卡、
  收一个文件不再需要放大镜。

### 6. 一个账号多台机器，各看各的

- 同一账号可同时登录多台客户端（每台一个设备标识）；
- 普通用户在网页端**只能看到自己名下的客户端**，会话 / 文件 / 确认卡也只路由给
  属主与管理员；管理员跨属主可见的管理语义不变。

### 7. 「配对令牌」退场

- 手动创建配对令牌的入口全部删除：CLI `aurora-center token` 子命令、REST 令牌接口、
  Web 管理页的令牌面板。
- 客户端接入统一走**账号登录 / 设备授权**；历史 tokens.json 数据与新机制兼容，
  令牌仍只存哈希、明文只出现一次。

### 8. 措辞统一

所有界面与 CLI 的「口令」一律改为「密码」。

## 🗂️ 二、Agent：会话级项目

项目不再是全局开关——**每个会话可以绑定自己的项目**：

- 主界面右栏新增「会话项目」卡，下拉选择（或「未指定（跟随全局）」），即选即生效；
- 生效范围与全局项目完全同权：工具缺省工作目录 / 搜索根、`run_command` 缺省 cwd、
  文件边界校验、auto 权限档的「项目根内免确认」、AGENTS.md 指令注入，全部按会话解析；
- 未指定项目的会话回落到设置里的工作项目，再按原有链回落——老习惯完全不受影响；
- 两个会话绑不同项目，各拿各的 AGENTS.md、各落各的项目根，互不串台；
- Center 远程发起的会话同样适用（默认未指定，跟随全局）。

## ⬆️ 升级与兼容性

| 事项 | 说明 |
|---|---|
| 配置迁移 | 无（Schema 保持 v17），覆盖安装即用 |
| Center 服务器 | **需要同步升级到 v0.2.2**（注册 / 设备授权 / 确认批复 / 文件管理都是新端点；旧服务器上这些功能不可用） |
| 客户端连旧服务器 | 账号密码直登照常可用；「登录账户」设备授权会提示失败 |
| 数据兼容 | 服务器 users / clients / tokens / files 数据全部保留；旧上传文件自动补算 24h 过期点 |
| 部署 | Docker 离线流程不变（`packages/center/deploy/README.md`）：重新打包 → scp → `docker compose up -d --build` |

## 🔒 安全边界（如实说明）

- Center 仍**无端到端加密**：远程会话明文过服务器，公网部署务必置于 TLS 反代之后；
- 权限申请推网页端**不放大**任何权限：批准的仍是客户端本机那次工具调用，超时按拒绝；
- 上传文件 24h 自动删除，但删除前的暂存期内服务器管理员可见（与「管理员可见所有
  远程会话」同一产品语义）。

## 🐛 其他

- 远程会话出现时，客户端主界面左栏现在会**自动刷新**显示（此前要切一次会话才出现），
  并带「Center」来源标签；
- 设置页 Center 探针与运行时截图探针同步新按钮结构（全量 54 项通过）。
