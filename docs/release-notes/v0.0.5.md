# Aurora v0.0.5 更新说明

发布日期：2026-09-25 ｜ 安装包：`Aurora-Setup-0.0.5.exe`（Windows x64，未签名）

本版本的核心是**TTS 供应商新增「DashScope 原生」接口类型**：千问AI平台（maas.qianwenaiapi.com）
等只提供 DashScope 协议、没有 OpenAI 兼容 `/audio/speech` 端点的服务商，现在可以直接用于
语音朗读。无配置结构变更（Schema 仍为 v9），安装后直接覆盖升级，无需重新引导。

---

## 🎙 TTS 供应商新增「DashScope 原生」类型

**背景**：此前 Aurora 的 TTS 只支持 OpenAI 兼容协议（`POST <baseUrl>/audio/speech`）。
部分服务商——典型如千问AI平台——的网关是 DashScope 式 API 面，实测**不存在** OpenAI
兼容的语音端点（`/v1/audio/speech` 与 `/compatible-mode/v1/audio/speech` 都是 404），
导致这类平台无法用作朗读源。

**新增能力**：

- **「接口类型」下拉**：设置 → 语音 → TTS 供应商编辑卡新增接口类型选择——
  `OpenAI 兼容（/audio/speech）` 与 `DashScope 原生（百炼 / 千问AI平台）`；
  baseURL、输出格式、语速的提示文案会随类型切换。
- **DashScope 原生合成协议**：`POST {base}/services/aigc/multimodal-generation/generation`
  → 从响应 `output.audio.url` 取得 24 小时有效的音频地址 → 自动二次下载。
  下载请求**不带鉴权头**（签名 URL 带鉴权头可能被拒）、有独立超时预算；
  播放格式以下载响应的 `content-type` 为准（实测部分网关会忽略请求的输出格式，
  恒回 WAV——Aurora 已适配，不会因此播放失败）。
- **baseURL 自动规整**：DashScope 类型下，只填域名（如 `https://dashscope.aliyuncs.com`）
  → 自动补 `/api/v1`；误填成 `…/api`（少了 `/v1`，本次实测最高频的填错方式）→ 自动补全；
  填了完整路径 → 尊重原样。
- **「获取模型列表」适配**：DashScope 原生 `/models` 接口是**分页**的（千问AI平台实测
  518 个模型、TTS 系列排在后段），现在会自动翻页拉全；模型 id 字段（`model`）与
  展示名（`name`）都能正确识别。OpenAI 兼容类型行为不变。
- **错误提示更对症**：404 提示按接口类型给出对应建议（DashScope 类型提示
  「baseURL 是否以 /api/v1 结尾」）；识别 DashScope 式的 400 `url error`
  （含义是「该模型不走 HTTP 合成端点」），会直接提示更换模型。
  音频签名 URL 中的鉴权参数值一律脱敏后才进错误文案，不会泄漏到界面或日志。

## ✅ 千问AI平台实测结论（重要，配置前请读）

本版本用真实账号对千问AI平台网关做了端到端验证，以下组合**实测可用**：

- **模型**：`qwen-tts`、`qwen3-tts-flash`（合成成功，返回 WAV 音频）；
- **音色**：qwen-tts 只认**内置音色**——`Cherry`、`Serena`、`Ethan` 等；
- **baseURL**：`https://maas.qianwenaiapi.com/api/v1`。

以下情况**调不通**（属于平台侧限制，非 Aurora 问题）：

- `qwen-audio-3.x-tts-*`、CosyVoice、Sambert 系列：在该网关只走 WebSocket 实时接口，
  HTTP 端点一律返回 400 `url error`——请换用 `qwen-tts` / `qwen3-tts-flash`；
- 声音复刻音色 id（如 `longanlufeng`）：qwen-tts 不接受，请改用内置音色。
  复刻音色需要等平台提供非实时复刻模型，或 Aurora 后续支持 WebSocket 协议。

**推荐配置**：接口类型 `DashScope 原生`、baseURL `https://maas.qianwenaiapi.com/api/v1`、
模型 `qwen-tts`、音色 `Cherry`、输出格式随意（网关实际下发 WAV）。

## 升级说明

- 直接运行 `Aurora-Setup-0.0.5.exe` 覆盖安装；已安装版会通过应用内自动更新收到推送
  （`latest.yml` 已同步更新源仓库）。
- 配置、会话、技能与凭据全部保留；本版本无配置迁移（新增的接口类型字段对旧配置
  天然回落为 `openai-compat`，原有 TTS 供应商行为完全不变）。
- 如果你在用千问AI平台的 TTS 且此前报 404：升级后按上面的「推荐配置」改一下
  接口类型、模型与音色即可；API Key 无需重新填写。
