# Aurora v0.4.6

本次版本是从 **v0.4.5** 到 **v0.4.6** 的完整更新，Aurora Center 同步升级到 **0.4.6**；
桌面端安装包本版未重新发布（更新源仍为 0.4.5，无桌面端功能变更）。重点重构 Center
登录后的后台工作台：用量页信息层级、全站毛玻璃材质与移动端适配，并把 v0.4.5 之后
的官网入口 / 顶栏修复一并收进正式版本（此前它们以 0.4.5 热修包形式部署过服务器）。

## 一、后台工作台重构

### 用量页

- 筛选区新增「全部 / 近 7 天 / 近 30 天」快捷区间；手改日期自动切换为自定义区间并退选快捷项。
- 统计卡从 3 张改为 4 张：主卡「区间总计」展示 token 总量、请求次数与占终身比；
  输入 / 输出 / 缓存命中三张分项卡各带占比或命中率；token 数以 K / M 紧凑格式展示。
- 趋势图配色与主题令牌联动：输入 = Center 信号色（渐变面积）、输出 = 品牌蓝、缓存命中 = 虚线灰；
  tooltip / 图例 / 坐标轴全部跟随暗浅主题，y 轴同样用紧凑格式。
- 空数据不再是一张空白画布：图表与「最近请求」均有空态提示。
- 「最近请求」设备列显示设备名而非裸 clientId。
- 图表 resize 加「宽度真变 + rAF 合帧」两道闸，避免滚动条出现 / 消失的宽度抖动把重绘塞进每帧
  （对齐桌面端 2026-10 性能轮口径）。

### 毛玻璃材质

- 登录后壳层新增氛围光斑层（青绿 / 蓝双色 radial 渐变），侧栏、壳层顶栏、控制台工具条统一
  `--center-wb-glass` + `blur(22px) saturate(1.4)`，与官网顶栏同配方；不支持 backdrop-filter
  的环境回落实底，可读性不受影响。
- 层级零改动：氛围层走 `z-index:-1` + `isolation`，不给侧栏 / 主区加定位，既有的
  scrim / 抽屉 / toast 层级关系保持原样。
- 移动端浮层（壳层导航抽屉、控制台双抽屉、底部导航）一律实底——浮在内容上的层不允许透出正文，
  玻璃只保留桌面文档流内的一份。

### 移动端适配

- ≤720px 新增底部导航（控制台 / 用量 / 自动化 / 文件 / 管理，管理员项按角色显示）；
  控制台页自动让位给自带的「设备 / 控制面板」标签，不出现双层底栏。
- 顶栏窄屏精简：隐藏 AURORA 前缀与设备数状态，只留页面名与连接状态。
- 用量 / 管理 / 文件三页表格窄屏卡片化：隐藏表头、每格左侧显示字段名
  （opt-in 的 `.ui-table--cards` + `data-label`）；自动化页保持横向滚动。
- 管理页 / 文件页移动端按钮与输入加大到 40px 命中高度；文件页「发送到设备」选择条可换行。

## 二、官网入口与登录后工作台（v0.4.5 tag 之后，已随 0.4.5 热修上线）

- 未登录路由拆分：`#/` 官网首页、`#/login` 登录 / 注册、`#/device` 设备授权；
  官网只读更新接口展示版本与安装包入口，不再连接 WebSocket、不读客户端列表。
- 登录后工作台改为左侧固定导航 + 顶部状态条 + 工作区；控制台保留
  「设备列表 | 会话流 | 控制面板」三栏语义。
- 页面按路由动态拆包：官网首屏不再加载 ECharts、Markdown / Mermaid / KaTeX 分包与中文 TTF，
  入口 JS 从约 1.34MB 降到约 655KB。
- 官网顶栏毛玻璃化，并修复三轮「透明叠字 / 内容透出」的真根因——共享 `--z-sticky` 与 hero
  同级的层级问题（新增 `--center-header-z`，不复用 `--z-sticky`）。

## 三、验收与测试

- Center 网页端验收新增 `mobile-workbench` 场景：底部导航 fixed 贴住视口底（±2px）、
  KPI 四卡纵向堆叠、快捷 chips 就位、管理表 thead 隐藏且单元格带字段名、控制台页底部导航让位。
- `usage` 场景统计卡断言随重构同步 3 → 4。
- 验收基线：**43 场景 × 明暗两档 = 86/86**；Center 单测 129/129；全仓 typecheck / build 通过。

## 升级说明

- 服务器按 `packages/center/deploy/README.md` 打包上传，`docker compose up -d --build` 换装；
  数据目录 `./data` 与 `.env` 不受影响，镜像 tag 升为 `aurora-center:0.4.6`。
- 桌面端无需操作：本版无桌面变更，自动更新源保持在 0.4.5。
