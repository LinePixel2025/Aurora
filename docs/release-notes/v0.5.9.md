# Aurora v0.5.9

本次版本汇总 **v0.5.8 → v0.5.9** 的全部更新。主线是 **Computer Use 桌面操控（配置 Schema
v39）**：用户在输入框输入 `/computer`（可带任务）或由 Agent 调用 `computer_start` 显式授权后，
Agent 可以截屏、看窗口、用虚拟光标与真实键盘鼠标操作本机，全程有顶部过程面板与可中断的状态条。
同时包含 v39.1 的「请求内开放工具 / 批量执行 / 下一步提示 / 等待收敛」、桌面小组件点击不抢前台
与「固定」按钮、开源迁移（MIT + 单仓库发布 + README 图文重写），以及
**插件开发工具包 v0.5.9**（脚手架 / 同口径校验 / 打包器）。

配置 Schema **v38 → v39**（新增 `computerUse`，默认关闭，升级不会开启任何桌面操控能力）。
插件 API 仍为 **v1**，已有插件无需修改。Aurora Center 服务器**不随本版升级**（仍为 0.5.2，
版本线独立），本次双投的仍是桌面安装包的三个更新资产。

## 一、Computer Use：Agent 操作真实桌面（v39）

- **入口与授权**：输入框 `/computer [任务]` 是用户显式授权，同时把「请使用 Computer Use 工具
  操作电脑，完成：…」作为指令交给模型；Agent 也可以自行调用 `computer_start` 建立授权。
  授权只在内存、按会话保存，**同时只允许一个会话**。
- **8 个工具、三层门控**：
  - 注册级：Windows + `computerUse.enabled` + 当前模型 `vision === true` + 非只读档；
  - 请求级：未授权只留 `computer_start`，已授权给 6 个动作工具 + `computer_stop`；
    自动化 / 自感知 / 子代理等不合格会话整组摘掉；
  - 执行级：`service.start()` 与端口 `ensureCallAllowed` 每次调用重查授权 / 总开关 / 视觉 / 权限档。
- **工具面每轮现取（v39.1）**：`computer_start` 之后动作工具在**同一次请求的下一轮**进入请求体，
  不必等用户再发消息；`computer_stop` 同理在下一轮撤掉整组。
- **授权 ≠ 开始操作**：`start` 不建浮层、不播光标动画；第一次截图 / 读窗口 / 动作才进入操作态。
- **退出即回前台**：只有 Agent 主动 `computer_stop` 才把 Aurora 显示、最小化恢复、切回该会话；
  用户手动停止、改配置、锁屏、退出都不抢焦点。
- **可见的操作过程**：每显示器一层透明浮层（虚拟光标 + 顶部光谱流光带）与顶部过程面板
  （560×116）；每个动作可带 `next` 一句话，显示「下一步：…」；不显示坐标 / 矩形 / 输入文字 /
  运行时长。浮层**不做内容保护**，远程桌面 / 屏幕共享下也能看到。
- **坐标以最近截图图片像素为准**：`physical = origin + image / scale`；没有截图 / 显示器变化会
  拒绝并要求重新截图；点击前 `WindowFromPoint` 命中测试、移动后 `GetCursorPos` 回执、
  `SendInput` 返回 0 必须报错。
- **虚拟光标不跟用户鼠标**：位置只由 `service.moveCursor()` 驱动；点击 / 滚轮先把虚拟光标滑到
  落点（系统指针原地不动），到位停 60ms 后再瞬移并 `SendInput`。
- **安全边界**：Aurora 自身、终端 / shell 宿主、任务管理器、UAC / 锁屏 / 登录界面为**不可配置的
  受保护目标**；用户可配 `allowedApps` / `deniedApps`（deny 优先，空允许名单 = 除保护目标与
  禁止项外全部允许）；`launch` 只接受 `.exe` / `.com`。`computerUse` 整组在
  `SETTINGS_READONLY_PREFIXES`：Agent 能进入用户**已开启**的能力，但不得自行开启 / 放宽总开关、
  动作限额与应用名单。
- **输入宿主**：常驻 PowerShell（NDJSON，懒启动 + 串行队列），脚本用 `-File` 启动并设置
  per-monitor DPI；宿主崩溃 / 超时 / 握手失败 → 失败关闭当前会话，不假装成功。
- **v39.1 效率**：模型批量下发 2–4 个动作（同一回复内串行执行，一批做完再截图核对）；
  授权时预热 PowerShell 宿主；无 `windowId` 的截图只查前台；逐字输入有总延迟预算；
  `launch` 等窗上限 2s。等待收敛为「明确知道要加载时才等」，不做每步一次往返。

## 二、桌面小组件：点击不抢前台 + 固定

- 桌面小组件窗口改为 **`focusable: false`**：点卡片 / 点按钮不会把 Aurora 切成前台应用，
  当前工作应用的焦点保持不变；代价是卡内文本输入拿不到键盘焦点（桌面常驻场景优先「不打断」）。
- 标题栏新增宿主绘制的**固定按钮**：只锁用户拖动 / 缩放（主进程 `setMovable` / `setResizable`），
  不动位置、层级与页面状态；状态写 `<userData>/plugin-widget-layout.json` 的 `locked`，
  缺省未固定，点击同样不抢前台。
- 冒烟新增 `focusable` / `resizable` 断言；插件清单字段无变化。

## 三、开源迁移与发布拓扑

- `LinePixel2025/Aurora` 改为**公开仓库**并新增 **MIT LICENSE**；README 重写为图文版
  （主视觉 + 9 张真实窗口截图）。
- 发布拓扑收敛到**单仓库**：安装包、`latest.yml`、`*.blockmap` 与源码都发在 `Aurora` 的
  GitHub Release；旧的独立产物仓库已删除。
- 本轮安装包的 `app-update.yml` 指向 `LinePixel2025/Aurora`，**从 v0.5.9 起恢复 GitHub 回退源**。
  v0.5.8 安装包内的回退源仍指向已删除的旧仓库：配置了 Aurora Center 的用户不受影响
  （Center 源优先）；未配置 Center 的 v0.5.8 用户需要手动下载本安装包覆盖安装一次。
- 新增 `.gitattributes` 统一 LF 检出，format:check 在 Windows 本机不再因 CRLF 假红；
  清理过期文档与 step 归档，发布 workflow 改用自带 `GITHUB_TOKEN`。

## 四、插件开发工具包 v0.5.9

- 新增 **`tools/create-plugin.mjs`**：从模板生成插件目录，自动填 `id` / `name` / `version`、
  附带 `types/aurora-plugin.d.ts`，并立刻跑一次校验。
- 新增 **`tools/pack-plugin.mjs`**：零依赖打包器（zlib + 手写 zip 头），包根直接是
  `manifest.json`，默认先校验再产出 zip，可直接安装或上传 Center 市场。
- **`tools/check-plugin.mjs` 升级为与宿主清单 zod schema 同口径**：补齐保留 id 段
  （`system` / `core`）、保留命令名、宿主事件白名单、主题令牌白名单与颜色 / 长度格式、
  配置字段（含 select 必填 options）、自动化动作 / 事件、工具超时与参数 schema 大小、
  图片文件存在、Skill 目录两种布局（目录本身或下一层子目录含 `SKILL.md`）等；
  未知字段改为 warning（抓拼写错误但不误判），并支持 `--json` 给 Agent / CI 用。
- `docs/01-contract.md` / `docs/02-guide.md` 快照同步到当前契约（banner、插件配置窗口、
  Center 侧栏面板镜像、小组件焦点 / 固定 / 隐藏关闭按钮、出站工具名归一）；
  模板增加契约类型文件；README / AGENTS / PROMPT / CHECKLIST 按新工具与 v0.5.9 更新。
- 插件契约与权限未变，已有插件不需要为了本版改任何代码；旧工具包会把宿主接受的清单
  误报为错误，升级时请整包替换。

## 五、兼容与迁移

- 配置 **v38 → v39**：新增 `computerUse` 组，迁移以默认值为底、已有对象在上；
  `enabled` 默认 `false`，升级不会打开桌面操控。
- 设置页新增「Computer Use」页（总开关、虚拟光标 / 流光 / 过程面板、移动与输入节奏、
  截图宽度、动作上限、闲置结束、应用允许 / 禁止名单）；该组对 AI 只读。
- 输入框工具行**不再新增**「操作电脑」开关；入口只有 `/computer` 与 Agent 的 `computer_start`。
- 插件清单 / 权限 / 宿主 API 不变；Center 服务器仍为 0.5.2，无需换装。
- 现有配置、会话、插件、自动化数据全部保留（`%APPDATA%/Aurora` 不在安装目录内）。
