# Aurora v0.2.5 更新说明

发布日期：2026-09-28 ｜ 安装包：`Aurora-Setup-0.2.5.exe`（Windows x64，未签名）

这一版加了**自动化（Automation）**：让 Aurora 在定时或课堂条件下自己动手做事。
参考 Codex / ChatGPT Tasks 一类 Agent 产品的 Scheduled Tasks 交互，自动化分两种模式：

- **Agent Mode** —— 触发后由 Agent 跑一次完整任务（能读文件、查资料、写东西、调工具），
  本次对话原样存进「自动化 → 历史」，**点开就能回放**，还记录触发时间与用时；
- **Normal Mode** —— 触发后按你预设的操作清单执行（弹系统通知 / 让 ClassIsland 提醒 /
  打开文件夹），快、确定、不花模型钱；历史里**只记触发时间与状态**，不展示具体操作。

触发器一共 7 类：每天定时（可限定星期几）、固定间隔，以及课堂条件 ——
距上课不足 N 分钟 / 上课时 / 距下课不足 N 分钟 / 下课时 / 下节课是指定科目。
ClassRoom 既有的**课前提醒**与**课前自动打开科目文件夹**已经作为「内置自动化」挂进
Normal Mode 的内置区，行为与以前完全一致（同一提前分钟数、同一文案、同一勿扰规则）。

配置 Schema **升级到 v19**：新增 `automations.enabled` 总开关（默认开启）。
自动化本身（定义与历史）存在用户数据目录，不占配置迁移；覆盖安装即用，无需重新配置。

---

## ⚙️ 一、自动化：两种模式，一个入口

主界面左栏新增固定项「**自动化**」（在「快速对话 / 子代理」下面）。点开后是双 tab 的
自动化页：

| | Agent Mode | Normal Mode |
|---|---|---|
| 触发后做什么 | 由 Agent 执行一段任务指令 | 按顺序执行预设操作 |
| 内容怎么写 | 一句「任务指令」（如「整理今天下载的资料，按科目归档到感知文件夹」） | 操作清单：系统通知 / ClassIsland 提醒 / 打开文件夹 |
| 成本 | 花模型调用（与普通对话相同） | 零模型调用 |
| 历史记什么 | 触发时间、用时、状态，**并可点开回放该次对话** | 触发时间、状态（不展示具体操作） |

每张卡片右侧三个按钮：**立即运行一次** / **编辑** / **删除**（删除是两段式，需要点两次
确认，避免误删）。

## 🧩 二、组件化的触发器与操作

**7 类触发器**（编辑器里下拉选择，参数按类型动态出现）：

- 调度类：`每天定时`（可勾选星期几，留空 = 每天）、`固定间隔`（5–1440 分钟）；
- 课堂类：`距上课不足 N 分钟`、`上课时`、`距下课不足 N 分钟`、`下课时`、`下节课是指定科目`。

课堂类触发器读的是你当前的课程表 —— 手动课表或 ClassIsland 联动都行；每节课只触发一次，
跨天（23:5x → 次日 00:0x）也算得对。

**3 类操作组件**（Normal Mode 专用，这是一份**封闭清单**：没有执行命令、没有任意写文件）：

- `系统通知`：标题 + 正文，可设置「点击通知打开的目录」；
- `ClassIsland 提醒`：经桥接弹出（需已配置桥接端点，未配置时该组件在编辑器里直接不可选）；
- `打开文件夹`：打开某个科目的资料文件夹，或任意指定路径。

要更强的能力（比如「把文件整理好」），用 Agent Mode —— 它受既有三档权限与确认卡约束，
与你自己在对话里让它干活是同一套规矩。

## 🔔 三、ClassRoom 的既有自动操作已迁入 Normal Mode

「课前提醒」和「课前自动打开科目文件夹」在 Normal Mode 页面的底部「内置」区里，
带「内置」徽章：

- 开关**直接对应**原来的设置（设置 → 模式 → ClassRoom 里的那两个开关），改哪边都一样；
- 触发时间沿用「课前提醒提前分钟数」（同样在设置页调）；
- 勿扰时段内静默跳过（同以前）；
- 内置自动化**不可删除**，也不能在编辑器里改 —— 它的行为由 ClassRoom 设置定义；
- 每一次触发同样会进自动化历史（Normal 口径：只记时间与状态）。

自动分类不受本次调整影响，仍是独立管线。

## ✍️ 四、用对话创建自动化（AI 工具 + 技能）

不想点表单？直接跟 Agent 说就行：

> 「每天早上 7:30 提醒我背单词」
> 「下节课是数学的时候，帮我打开数学资料文件夹」
> 「每两小时把今天的下载按科目整理一下」（这条会建成 Agent Mode）

为此新增了内置技能 `automation` 与六个工具：`automation_list`、`automation_create`、
`automation_update`、`automation_delete`、`automation_run`、`automation_history`。
**创建 / 修改 / 删除 / 手动触发都要你点确认**（AI 给自己排后台任务是敏感操作）；
查询类（列表与历史）不需要。AI 改不了自动化总开关，也改不掉别的只读项。

试跑习惯仍然保留：AI 建完会主动触发一次并把结果报给你。

## 🖥️ 五、Aurora Center 网页端也能管

Center 的 Web 控制台新增「自动化」页（`#/automations`）：选客户端 → 看它的自动化列表
（Agent / Normal / 内置三组）、开关启停、立即运行、新建与编辑（表单由客户端上报的组件
目录驱动，与桌面端一致）、查看运行历史。

数据仍存在你的电脑上（Center 只做转发，不落地自动化数据）；远程管理同样受
「允许 Center 远程开 session」闸门与账号属主 / 管理员权限约束。

## 🔍 六、其它

- 设置页「模式」页新增「自动化」区组（总开关，默认开启）—— 关闭后所有自动化暂停评估与
  触发，历史保留可查；
- 自动化触发的会话（`auto-` 前缀）**不会进主界面左栏**（它们属于某次运行，从历史进入），
  一次运行一条记录，不会把会话列表刷乱；
- 运行历史最多保留 500 条，超出淘汰最旧的。

## ⬆️ 升级与兼容

- 配置迁移 `v18 → v19` 只补一个默认值（`automations.enabled: true`），不改动其它设置；
- 既有课前提醒 / 课前打开科目文件夹的行为逐字保留，升级后你不需要做任何操作；
- Schema 版本推进后 `pnpm verify` 的断言同步更新（迁移链 19 条）。
