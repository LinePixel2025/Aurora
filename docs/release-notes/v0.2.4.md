# Aurora v0.2.4 更新说明

发布日期：2026-09-28 ｜ 安装包：`Aurora-Setup-0.2.4.exe`（Windows x64，未签名）

这一版围绕七条用户反馈做了一轮**「放手」与「补全」**：Agent 的确认卡与轮次上限全面放宽
（发文件不再弹卡、长任务不再被 8 轮掐断）、项目与工作目录统一为 Codex 式的「一个会话
一个工作目录」、ClassIsland 桥接的路径问题从静默失败变成可诊断、Center 网页端的会话管理
补上历史回放与移动端适配、分类流水与文件回滚两处 UI 重整。

配置 Schema **升级到 v18**：唯一的行为变化是把 `agent.loop` 的旧默认值（轮次 8 / 自动续 2）
抬升到新默认值（32 / 8）—— 这是「放宽」方向的迁移，用户显式改过的其它值不受影响。
覆盖安装即用，无需重新配置。

---

## 🤖 一、Agent 更放手：确认卡与轮次放宽（对齐 Codex）

参考 Codex / OpenHands 等主流编码 Agent 的档位设计（工作区内写自动放行、命令仍要过目；
不在个位数轮次上断长任务），本轮做了三处放宽：

### 1. 给 Center 发文件不再弹确认卡

你在对话里说「把这个文件发给 Aurora Center」，Agent 现在**直接发送**，不再逐次弹卡。
安全闸门保留在配置层：`center.allowFileTransfer` 可整体关闭、`center.maxFileMb` 限大小、
Center 连接本身可随时断开——这些开关都在设置页且 AI 自己改不动（docs/06 §11.2）。

### 2. 工作目录内的文件写入免确认（confirm 档）

`confirm` 档（默认档）下，`write_file` / `edit_file` 落在会话工作目录边界之内时**自动放行**
（Codex 式 auto-edit）；越界写入、终端命令与其它敏感工具**仍逐次确认**，默认行为只松了
「天天被问的那一类」。`auto` 档行为不变。

### 3. 长任务不再半途而废

轮次上限默认 **8 → 32**（可配 1–128），轮次用尽后自动续轮 **2 → 8**。
以前复杂任务跑到第 8 轮就停下来等你点「继续」，现在一口气干到底的概率大得多。
旧配置升级时由迁移自动抬到新默认值（docs/08 §1）。

## 📁 二、项目与工作目录：Codex 式「一个会话一个工作目录」

Work 模式的「工作目录」和「项目」原本是两套并行概念，经常打架：绑了项目的会话命令落在
项目根，提示词却让你把产出存到工作目录；auto 档在工作目录里写文件还会被当成「越界」逐次弹卡。

现在统一为**一条回落链**（docs/06 §5.1）：

> 会话绑定项目 > 当前项目 > **Work 模式工作目录**（仅 Work 模式激活时）> 电脑操控工具工作目录 > 用户主目录

缺省命令目录、文件写入边界、免确认判定、设置页「打开工作目录」按钮全部按同一条链解析——
提示词与工具链同源，Work 模式与项目指定不再互相打架。设置页的 Work 模式工作目录
从「只被提示词引用的死字段」变成真正生效的回落一级。

## 🏫 三、ClassIsland 桥接：路径问题可诊断 + 默认路径自动回落

「桥接经常没数据」的最常见原因是 **Aurora 端点与插件 outputPath 两边路径对不上**，而
Aurora 读不到时只会静默降级成空课表，看不出是「桥接坏了」还是「真没课」。本版：

- 文件源端点读取失败时，**自动按桥接插件的默认输出路径**
  （`%APPDATA%\ClassIsland\aurora-bridge\schedule.json`）回落重试一次；
- 回落成功会在状态里标记（`usedFallback`），日志明确提示「端点与插件 outputPath 不一致」，
  带上端点本身的失败原因——静默失败变成可诊断；
- 读取失败日志按「错误是否变化」分级：首次失败 / 错误变化记 warn，持续同一错误不再刷屏。

## 🌐 四、Center 网页端：会话管理五处补全

### 1. 切换会话能带上历史记录了

以前网页端切换 / 刷新后只有实时消息，之前的对话全部空白。现在新增历史回放链路：
打开会话即从客户端回放最近 200 条消息（含工具调用卡片），与实时消息按消息 id / 内容
配对去重，不重复不错序。

### 2. 隐藏会话即时同步

在网页端把某个会话设为「客户端不可见」后，客户端左栏**立即**消失（原来要等下一次
任意刷新才生效）。

### 3. 自动滚动到位

工具卡更新、任务卡、子代理报告、确认卡出现等一切会改变列表高度的事件都会触发吸底；
你上翻读历史时不再被强行拽回底部，回到底部后恢复自动跟随。

### 4. 对话窗口不再无限变长

修掉了三处高度约束断裂（矮视口的 `min-height`、移动端 `height:auto`、全局确认栏占位
未计入），任何视口下页面本身不再产生滚动，只有消息列表滚动。

### 5. 移动端适配

`100dvh` 动态视口 + 刘海屏安全区（`safe-area-inset`）+ 窄屏布局改 flex 自适应
（去掉按魔法数估算的高度），手机上会话面板不再溢出或被裁切。

## 🧹 五、界面整理

- **分类流水**（主界面右栏与设置页）：每条流水改为两行式布局，窄栏不再互相挤压溢出；
  修正「已修正后徽章仍显示处理中」的短暂错位。
- **文件备份 / 回滚**：从主界面右栏**整体迁入设置页 → 智能与工具 → 文件备份**，
  主界面不再展示快照列表；「立即清理」按钮同步可用（按会话保留策略淘汰，不是删光）。

## ⚙️ 配置迁移（v17 → v18）

- 唯一变化：`agent.loop.maxRounds` 恰好为 8 时抬升为 32、`autoContinueRounds` 恰好为 2 时
  抬升为 8（放宽方向的迁移，用户显式设置过的其它值原样保留）。
- 其余所有配置、会话、凭据原样保留；覆盖安装即用。

---

**升级**：覆盖安装后首次启动自动完成迁移。如需回退到 v0.2.3，建议先备份
`%APPDATA%\Aurora\config.json`（新版配置版本更高，旧版无法向下迁移，恢复备份即可回到原状）。
