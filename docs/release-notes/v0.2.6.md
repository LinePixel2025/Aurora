# Aurora v0.2.6 更新说明

发布日期：2026-09-28 ｜ 安装包：`Aurora-Setup-0.2.6.exe`（Windows x64，未签名）

这一版做的是**「用起来顺手」**：把上一版（自动化）留下的一批生硬界面收拾干净，
并给 Agent 补上两个「像别的 Agent 一样」的能力 —— **子代理的独立对话界面**与**向用户提问**。

**没有任何配置迁移**：Schema 仍是 **v19**，覆盖安装即用，不用重新配置。

---

## 🧩 一、子代理：现在有「自己的对话界面」了

以前的子代理只有主对话里一张工具卡：看不到它的过程，也读不到它的报告全文。
上一版给了「运行轨迹」，这一版再进一步 —— **它就是一段对话**：

- 在「子代理」页面点开某次运行，看到的是完整的：
  **主代理的任务指令 → 子代理的正文 → 它做过的每一次工具调用（点开看参数与结果）→ 最终报告**。
  最后一条正文会被标上「**最终报告**」——那正是回传给主代理的那段。
- 折叠态仍是紧凑轨迹（进度条 + 步骤 + 报告），展开态才是对话 —— **同一段内容不说两遍**。
- 主对话里 `task` 工具卡的展开体用的是**同一个视图**，不用再跳到页面。
- 工具调用现在带**入参**（「它拿什么参数做了什么」一眼可见），
  并且不再出现「时间线上是一堆半句」——连续正文增量会合并成一段。
- **只读**：视图里没有输入框、没有发送键。子代理的生命周期跟着父请求，
  要中止就中止父请求（这条提示也写在视图底部）。

## 🔐 二、子代理的权限：主模型可以选

派生时主模型会显式声明权限，你也能在卡头一眼看到：

| 权限 | 子代理能用的工具 | 说明 |
|---|---|---|
| `read`（缺省） | 查询与只读类 | 与以前完全一致 |
| `write` | 额外可用 `write_file` / `edit_file` | 能改文件，**不是绕过确认** |

`write` 的安全边界三条，全部沿用既有链路，没有新开口子：

1. **写入仍走同一条确认链** —— 你当前的权限档（只读 / 变更前确认 / 完全权限）、
   项目根边界、免确认命令模式统统照旧生效：根内按档位放行、根外照样弹确认卡片；
2. **只读档下写了 `write` 也没用** —— 工具表交集为空，子代理照样拿不到写工具；
3. **命令 / MCP / 再生子代理永远拿不到** —— 写入白名单是固定枚举（只有两个文件工具），
   要跑命令请回主对话走完整确认。

子代理卡头会显示「可读写」徽章（悬停看它实际拿到了哪些工具）。
装配层没接确认链时（例如单测）会**降级为只读并明确告知模型**，不会假装文件已经改好。

## 🙋 三、Agent 现在可以「问你一句」

新增 `ask_user` 工具：Agent 遇到**答案会决定后面几十步走向**的分叉时（目标不明确、
两种方案各有取舍、要动的文件无法撤销），可以先问你一句再继续 —— 不用猜，也不用你手动补一条消息。

界面上是一张卡片（与敏感工具确认同区域、同款交互）：

- 支持**选项**（2–4 个，带说明）或**自由输入**；给选项时也能自己写；
- **多选**可选；倒计时 ≤ 30 秒转红；
- **跳过** = 让 Agent 按自己的判断继续；
- **超时 3 分钟按「未回答」继续**，不会把这一轮请求挂死；
- 与「敏感工具确认」语义不同，两者可以同时在场：一个问「要不要执行这个动作」，
  一个问「这件事你想怎么办」。

它不受「电脑操控工具总开关」门控，**在只读档也照常可用**（提问不写盘、不执行命令）。
子代理**不会**向你提问 —— 澄清需求是主代理的职责。

## 🎛️ 四、界面减负：自动化页与对话区

上一版新做的自动化页「太像表单」，这一版按「每个操作都配上图标 + 说明不占版面」重做：

- **条件选择从下拉改成图标磁贴网格** —— 7 类触发器一次全在眼前，每类带自己的图标，
  鼠标悬停看这一类的说明；参数里的下拉也换成分段胶囊、星期改为胶囊多选，
  **整个编辑器里不再有原生下拉框**；
- **每个操作都有图标** —— 卡片摘要从「拼成一整句」改成图标胶囊（`系统通知`、`打开「数学」`），
  模式徽章、历史状态、反馈条、区组头、字段标签也都带上语义图标；
- **能压缩的说明一律改成鼠标悬停提示** —— 页头副标题、字段提示、内置区说明、操作清单说明
  都不再占版面；表单改成「左标签 / 右控件」两列，长标签换行不再挤压控件；
- **删除仍是两段式**（首次点击变红并提示「再点一次确认删除」）。

对话区与输入区：

- 输入区的思考等级下拉以前显示 `auto（不指定，兼容性最好）`，在窄控件里被省略号切成
  「auto（不指定，兼…」—— 现在显示 `auto` / `low` / `medium` / `high`，
  完整解释鼠标悬停即见；模型下拉同理（悬停看完整模型 id）；
- **思考块**从「外层灰卡 + 内层灰文本框」的双层盒子改成**左侧竖轨的旁注**
  （流式期间竖轨变强调色），正文与思考之间留一档间距，工具卡之间也拉开 —— 
  一屏能分清「思考 → 回答 → 工具」三段，不再是挤在一起的灰色堆叠。

## ⚙️ 五、其它细节

- 提问与确认两条链在协议层**彻底分开**（`askUser:*` 与 `proactive:*`）：
  两者对「超时」的语义相反（确认按拒绝、提问按未回答继续），混在一组里迟早会被改错一处。
- 已知限制：远程（Aurora Center）会话里 Agent 提问时，卡片出现在**这台电脑**的对话窗上
  （与远程确认卡片的推送链不同，本轮未做网页端问答）——单机自用时无影响。
- 内置技能与工具表口径不变；`ask_user` 属于 Agent 自身能力，不受工具总开关门控。
