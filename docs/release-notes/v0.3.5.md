# Aurora v0.3.5 更新说明

发布日期：2026-10-03 ｜ 安装包：`Aurora-Setup-0.3.5.exe`（Windows x64，未签名）

v0.3.5 是一轮**客户端大型功能轮**：把主界面右侧栏从"信息展示栏"升级成"工作台"——
新增文件预览、真 PTY 交互终端、内置浏览器三个功能面板；两条新的斜杠命令 `/init`（生成
AGENTS.md）与 `/compact`（压缩上下文）；上下文条的缓存命中改为**平均命中率**并按会话
持久累计；以及一组会话状态修复（切换会话不再丢工具计时与过程显示）。

**没有任何配置迁移**：配置版本仍是 **v25**，覆盖安装即用，凭据、项目、会话、自动化全不动。
会话文件新增的字段（工具时间戳、会话级用量累计、压缩留痕）全部是**可选字段零迁移**——
老会话文件照常可读，新字段从这一版起自然写入。

同期 **Aurora Center 服务端重新部署为 0.3.6**（镜像 tag `aurora-center:0.3.6`）。
本轮改动集中在内核与桌面端，服务端代码与 0.3.5 相同 —— 重新构建部署是为了让线上版本
与发布线一致，避免"线上到底是哪一版"说不清（功能上 0.3.5 与 0.3.6 无差异）。

---

## 🗂 一、右侧栏工作台：文件 / 终端 / 浏览器

右侧栏顶部新增一条**功能标签**（文件 / 终端 / 浏览器 / 上下文），原来的任务面板与
模式感知信息卡整体收进「上下文」标签，默认仍展示它 —— 老习惯零改变。

右栏同时**变宽了**（264 → 384px），并且**左缘可以拖动调宽**（280–560px，双击复位，
宽度记忆在本地）。文件预览与终端在窄栏里根本没法用，这是配套的必须改动。

### 1. 文件预览（「文件」标签）

输入路径即可预览当前工作目录内的文件：

- **Markdown** 用与聊天正文**同一个渲染器**（表格、代码高亮、公式、图表都正常）；
- **图片**直接显示（PNG / JPG / GIF / WebP / BMP / SVG / ICO，上限 10MB）；
- **纯文本**等宽字体展示（上限 2MB，超出截断并标注）；
- **二进制文件**如实说明"不支持预览"，绝不显示乱码；
- **最近预览**列表（最近 8 个，存在本地），点一下就能回到上次看的文件。

安全边界与文件工具**同一条**：路径必须落在当前会话的工作目录之内（项目对话 = 项目根，
Agent 对话 = 桌面 Aurora 目录），越界直接拒绝并说明原因。

> 这一版未做"点击消息里的文件路径直接打开预览"——路径识别的误报面较大，
> 先观察"路径输入 + 最近记录"的实际用法再定交互。

### 2. 真 PTY 终端（「终端」标签）

完整交互式终端（xterm + 真实 PTY），**不是**"输入命令看输出"的伪终端：

- 打开即是一个常驻 PowerShell，`vim`、`python`、`npm run dev`、交互式脚本都能正常跑；
- **切走标签再切回来，终端内容不丢**（滚动缓冲保留）—— 它是一个持续存在的会话，
  不是"每次点开都新开一个窗口"；
- 窗口关闭 / 应用退出时 shell 一并收掉，不会留孤儿进程；
- 起始目录跟随当前会话的工作目录（与文件预览同一条解析）。

终端是**给你手动操作的面板**：它不接 AI 工具，也不会弹确认卡 —— 和在系统里开一个
终端窗口的权限边界完全一致。

### 3. 内置浏览器（「浏览器」标签）

带地址栏、前进 / 后退 / 刷新 / 主页的网页面板（默认必应，主页按钮一键回）。

- 只放行 **http / https** 地址，`file://` 等本地协议在输入处即被拒绝；
- 弹窗被禁用（网页的 `window.open` 不会弹出新窗口）；
- 已知取舍：**切到别的标签再切回来，网页会重新加载**（浏览器面板没有可迁移的会话状态，
  这版接受这个简化）。

## ⚡ 二、两条新斜杠命令：`/init` 与 `/compact`

输入 `/` 就能看到它们，选中即执行。

### `/init` — 为项目生成 AGENTS.md

选中后 Aurora 会先探查当前工作目录（读 package.json、配置文件、目录结构），然后：

- **已有 AGENTS.md**：在原文基础上补充与修正（构建命令、目录职责、代码约定），
  **不会推翻重写**；
- **没有**：新建一份简短的中文指南（≤60 行），包含项目说明、常用命令、目录职责、
  必须遵守的约定；
- 只写从文件里读到的**事实**，探查不出的小节直接省略，不留占位文字。

生成的 AGENTS.md 会在此后每一轮对话中自动注入，让 AI 更懂你的项目。
写入走模型自己的文件工具，受权限档与工作目录边界约束，没有旁路。

### `/compact` — 压缩上下文

把当前会话的历史压成一段摘要，**之后**的请求只携带压缩点之后的内容 + 这段摘要，
上下文占用立刻降下来，长对话可以继续跑很久。

- **消息本体不删除**：界面上仍可回看全部历史；
- 摘要**随会话落盘**：重启后依然是压缩后的口径（不是只对当前窗口生效）；
- 正在回复中不能压缩（会提示先停止或等待）；
- 压缩完成后消息区会出现一条说明（压了多少条、摘要多长）。

## 📊 三、平均缓存命中率（替换"本次缓存命中"）

输入框底部上下文条的缓存片段，之前显示的是**最近一轮**的命中量，现在改为
**平均缓存命中率**（本会话累计命中 ÷ 累计输入）：

- 单轮命中率抖动大（第一轮通常 0%，之后才涨），平均值才反映服务商缓存的真实收益；
- **按会话累计并持久化**：切走再切回、甚至重启应用，累计值都连续；
- 展开详情卡里能看到精确的累计命中 / 累计输入 token 数；
- 服务商不返回缓存字段时该片段整段不显示（不会把"没回传"显示成"0%"）。

## 🔧 四、会话状态修复：切换会话不再丢东西

这版修掉一组"切走再切回就变样"的老问题：

1. **工具调用计时独立、持久**。耗时徽章的计时起点从"你看到它开始跑的那一刻"改为
   工具**真实发起时刻**（随工具卡落盘）——切走会话再切回、甚至重启应用，
   每个工具的真实耗时都原样显示，不再从切回时刻重新计时。
2. **过程显示持久**。消息的轨迹展开 / 折叠、思考块开合、工具行开合、终态动画状态
   **按会话分别记忆**：切走再切回保持原样（此前会被重置为"全部折叠"）。
   切到子代理页 / 自动化页再回来同样保持。
3. **流式中文切换不再截断**。切走时正在生成的那一轮，即使中途切回，正文也会
   用落盘的完整内容补全对齐（此前会停在切回时刻的半截）。

## ⬆️ 升级方式

直接运行 `Aurora-Setup-0.3.5.exe` 覆盖安装即可：配置、会话、项目、自动化与凭据全部保留
（配置版本 v25 无迁移）。卸载与重装同前，数据目录 `%APPDATA%/Aurora` 不会被清理。

首次使用时若 ClassIsland 联动装的是随包插件，本次**桥接契约未变**，无需更新插件。
