# Aurora v0.8.4

本次版本汇总 **v0.8.3 → v0.8.4** 的全部更新，主题是**工具面护栏**：插件与 MCP 是两类会不断
增长的工具来源（插件越装越多、MCP 服务器的工具清单由服务端决定），此前没有任何硬上限，
装得多时每轮请求的 `tools` 会无限膨胀，甚至越过 provider 的单请求 tools 上限导致整条对话
失败。本版给两类来源各加一道**确定性的全局硬上限**，并把「哪些工具没注册」变成界面上看得见、
安装前能预演的信息。

本版配置 Schema **v47** 不变（无迁移）；插件 API 仍为 **v1**；Aurora Center **0.7.0** 不变。
已有配置 / 会话 / 子代理 / 插件 / 自动化数据全部保留。

## 一、插件工具全局上限 64

- 全部启用插件的工具合计最多 **64** 个（`PLUGIN_TOOL_FACE_LIMIT`，防失控常量，不做成设置项）。
  注册前先按只读档过滤（只留 `readonly: true`），再按 `plugin.<id>.<name>` 字典序取前 64 个；
  超出部分**不注册** —— 模型看不到、也调不到，但插件进程继续运行，命令 / 面板 / 小组件 /
  自动化 / Skill 都不受影响。
- 顺序只由名字决定，与安装顺序、`Map` 插入序无关：新增一个名字靠前的插件可能挤掉名字靠后的
  工具；停用 / 卸载后下一次同步会自动把腾出的名额补给被跳过的工具。
- **设置页可见**：插件列表新增「插件工具已用 / 64」，插件行在发生截断时带「N 个工具未注册」；
  插件配置窗口的「扩展点」区逐个工具标「未注册」，并给出原因与恢复办法。
- **日志**：`已同步插件工具` 带 `{ registered, skipped, limit, mode }`；跳过的名字只在
  截断集合变化时 `warn` 一次，避免设置变更触发同步时刷屏。

## 二、MCP 工具全局上限 64

- 全部已连接 MCP 服务器的工具合计最多 **64** 个（`MCP_TOOL_FACE_LIMIT`）。分配按
  「服务器名 + 工具名」字典序统一重算，**与连接先后 / 配置顺序无关**；超出部分不注册，
  服务器仍保持连接，其余 MCP 工具照常可用。
- 断开 / 出错 / 移除一台服务器后，其它服务器此前被截断的工具会**自动补回**；设置页每台
  服务器显示的「N 个工具」是**实际注册数**，日志里截断会 `warn` 一次并列出被跳过的前 20 个名字。
- 与插件一致：MCP 工具不参与 `agent.tools.enabled` 门控（它们本来就全量 `confirm`）。

## 三、安装确认弹窗预演工具面

- 本地插件包的安装确认弹窗（以及 `plugins:inspect` 的 `warnings`）新增两类预警：
  - **本插件装完有几个工具不会注册**（本插件自身就超过 64 时）；
  - **会挤掉哪些已有插件工具**（名字靠前的插件插队时，列出数量与前三个名字）。
- 同 id 重装 / 升级不会把自己算成「被挤掉」；只读档只按 `readonly` 工具计数；装得下时
  不产生任何警告，弹窗保持原样。

## 四、预算与口径修正

- 工具面预算 ratchet（`TOOL_FACE_BUDGET = 65 个 / 42,000 字符`）的**运行期测量回到只统计内置**；
  插件 / MCP 各有硬上限后不再计入，否则「装一个 3 工具插件 / 连一台中等 MCP 服务器」会让
  告警永久亮着、失去意义。
- 单测新增「内置全量 + 插件上限不越过 provider 常见的 128 tools 上限」的断言；未来新增内置
  工具会强制重审这两个上限。
- 已知边界：三类来源**没有跨来源总闸**，内置 63 + 插件 64 + MCP 64 同时取满时请求体仍可能
  越过 128；当前用三份独立上限把最坏情况限制在 191 以内，统一总闸留待后续版本。

  `pnpm verify` **26/26**（含 `config.version = 47` 与 `v0 → v47` 迁移链 **47/47**）。
- 全量冒烟 **313/313**（本机当轮实测；条目数随本机配置 / 示例插件浮动，以 `SUMMARY` 为准）。
- 全量截图 **139 条**：本机单轮 130 条 + 引导 6 + 记忆库 / 流光 3。插件列表与配置窗口两条

## 升级说明

直接覆盖安装即可。本版没有配置迁移。若你安装了很多插件或连接了较多 MCP 服务器，升级后
可能有部分工具**不再出现在 Agent 工具面**（按名字截断）：在设置 → 插件列表 / 插件配置窗口
可以看清已用数量与哪些工具未注册；停用不用的插件或 MCP 服务器后，下次同步会自动补回。
