# Aurora v0.5.4

本次版本汇总 **v0.5.3 → v0.5.4** 的全部更新：修复插件 / MCP 点号工具名在严格网关触发的
整请求 400，AI 模型页新增按 provider 分组的默认模型下拉；同时把 Aurora Center 从 0.4.9
换装到 **0.5.0**，正式上线公开插件市场。

配置 Schema 保持 **v36**，没有新增迁移；Aurora Center 代码版本线仍独立（不建 tag、
不上传 GitHub Releases），本次双投的仍是桌面安装包的三个更新资产。

## 一、插件 / MCP 点号工具名修复

- 内部注册名继续保留点号：插件工具为 `plugin.<id>.<name>`、MCP 工具为
  `mcp.<server>.<tool>`，注册表、落盘、确认卡片、事件与界面都用这一套名字；
- 出站边界新增唯一实现 `packages/agent-core/src/llm/toolNames.ts` 的
  `createToolNameCodec()`：非法字符（含点号）替换为 `_`、截断到 64 字符；同批工具线路名
  冲突时按排序追加 `_2` / `_3`，映射确定且跨请求稳定，不影响提示词前缀缓存；
- 请求体 `tools[].name` 与消息历史 `tool_calls[].name` 都换成线路名
  （`[a-zA-Z0-9_-]`），模型回传的 `tool_call.name` 在进入循环时解码回内部名；
  落盘与界面始终显示内部名；
- 系统提示词里的工具清单（`describeTools`）同步使用同一份线路名，避免模型看到两套名字后
  调用不存在的工具；
- 此前的现象：装一个带工具的插件或 MCP 后，严格网关（DeepSeek Responses / OpenAI 官方等）
  在**调用模型之前**校验 `tools` 数组，只要有一个点号名字就整请求 400，每条消息都失败；
  本版不再依赖 provider 的宽容度，两套协议共用循环层这一道编解码。

## 二、AI 模型页默认模型选择

- 设置 → AI 模型页新增「默认模型」卡：按 provider 分组的单个下拉（`<optgroup>`），
  选项为每个已保存 provider 的 `modelList ∪ {model}`，值以 JSON 编码
  `(providerId, model)`，避免模型 id 里的分隔符冲突；
- 切换即保存（不点「应用」）：写 `llm.active = providerId` 与
  `llm.providers.<id>.model = model`，并把该模型补进 `modelList`；保存失败按设置页错误提示；
- 补齐空态：没有任何已保存 provider 时列表区显示 `data-empty="llm.providers"` 空状态卡，
  新增模型后下拉随 provider 一起出现；
- Center 官方占位：`llm.active` 指向 Center 官方 provider（页面不展示的保留 id）时，
  下拉显示一个禁用的「Center 官方模型（由 Aurora Center 管理）」占位项，不改写配置；
  选择任意本机模型即切回本机 provider；
- 截图探针新增 `settings-llm-default.png`，同时覆盖分组渲染与「切换即落盘」两条口径。

## 三、插件市场正式上线

- Aurora Center **0.5.0** 起提供公开插件市场：
  `https://aurora.linetech.online/#/marketplace`，未登录也可浏览与下载；管理员在
  `#/pluginsAdmin` 上传（zip ≤ 20 MB）→ 确认发布 → 版本列表 / 撤回，同版本不可覆盖；
- 桌面端入口为 **设置 → 插件 → 市场**：从当前配置的 Center 拉取列表，显示作者 / 下载量 /
  本机版本，有新版本时给「更新」按钮；下载后先校验大小与 SHA-256 再交给安装器，
  校验失败不落任何安装状态；
- 安装前展示名称、标识、作者、大小、SHA-256 与申请权限；页面明写
  「插件代码将以你的用户权限运行，可读写本机文件与网络」，即**安装即信任**——
  插件进程不是 OS 沙箱；
- 本版市场**无签名**：SHA-256 只保证下载完整性，不证明发布者身份；只安装你信任来源的插件。

## 四、兼容性与升级

- 配置 Schema 仍为 **v36**，无迁移；已有配置、会话、插件与小组件布局原样使用；
- 旧插件行为不变：编解码只发生在出站边界，插件清单与插件进程仍只认原始点号工具名，
  不需要改代码或重装；
- Aurora Center 版本线独立：换装 0.5.0 只升 `packages/center/package.json` 并按
  [部署文档](../../packages/center/deploy/README.md) 重新打包，**不创建 git tag、
  不上传 GitHub Releases**；
- 桌面安装包继续双投 GitHub Releases 与 Center 更新源，三个资产版本保持一致；
- 安装包仍为 Windows x64、未签名；首次运行 SmartScreen 提示时选择「更多信息 → 仍要运行」。
