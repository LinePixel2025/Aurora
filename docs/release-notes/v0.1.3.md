# Aurora v0.1.3 更新说明

发布日期：2026-09-26 ｜ 安装包：`Aurora-Setup-0.1.3.exe`（Windows x64，未签名）

这一版是**对话体验修复版**，修的就是你在实际使用中报上来的三个问题：

1. **深度思考的显示跟不上模型** —— 思考内容滚得比模型输出慢，界面还会明显卡顿；
2. **对话窗太杂乱、浮层互相遮挡** —— 点开某些面板后，输入框底部整排控件被压住点不动；
   展开/收起动画「乱跳」；
3. **对话没有归档功能** —— 历史会话全挤在一个列表里。

**配置 Schema 保持 v11，本次无需任何迁移**（归档状态保存在会话文件里，不写入配置文件）。
直接覆盖安装即可，会话历史、分类流水与凭据全部保留。

---

## 🐛 一、深度思考不再「跟不上」，界面不再卡顿

### 你之前看到的现象

思考过程一格一格往外挤，比模型实际输出慢；有时思考内容还没铺完，Agent 已经把整个任务做完了。
高密度输出（推理型模型尤其明显）时界面还会出现**肉眼可见的半秒级冻结**。

### 根因（两层叠加）

1. **界面侧的代价是「每个字 × 整份对话」**：每收到一个 token 都会把**整份对话的正文重新解析一遍**
   用于渲染 markdown。思考内容本来不需要走这条路径，却按「整份对话」的代价付费 ——
   于是对话越长越慢，思考密集阶段尤其致命。
2. **全链路没有任何合并**：一个 token 就过一次进程间通道、就触发一次界面刷新。
   推理模型思考阶段常每秒 80～150 个 token，界面每秒被叫醒上百次，每次都要付上面那笔钱。

### 修复

三条链路各管一段，且**顺序与最终内容完全不变**（只是在途合并，不丢不改）：

- 界面**按消息缓存**渲染解析结果，只有该条消息的正文真的变了才重新解析 —— 思考增量不再触发重解析；
- 界面**每帧只写入一次**（同一帧内的多个增量合并），把刷新频率从「每秒上百次」压到「每秒最多 60 次」；
- 主进程**每约 16ms 合并一批**增量再下发，减少跨进程唤醒次数。

### 实测效果（本机，同一份代码前后对照）

| 指标 | 修复前 | 修复后 |
|---|---|---|
| 最坏界面卡顿（主线程被占住的最长时间） | **661ms**（半秒级冻结） | **51ms**（四窗口同开时 65ms） |
| 掉帧数 | **238** | **0**（四窗口同开时 3） |
| 最坏帧间隔 | 137ms | 29ms |

同时新增了一个**高密度输出压力场景**（模拟每秒上百 token 的连续吐字）纳入自动化验证 ——
原先的探针只发两个分片，这种「渲染跟不上」的问题在它面前根本测不出来。

> 说明：这项修复解决的是**界面侧**的卡顿与掉队。本机离线压测里，模拟服务自身的发送路径
> 已成为新的耗时主要来源，所以「真实模型速度下是否还落后」我们会继续单独跟踪
> （详见 `docs/06 §16.3`）。

## 🐛 二、输入框的浮层不再互相遮挡（「完全访问」那一处就是它）

### 你之前看到的现象

点开输入框底部的「上下文详解」后，**那一排控件整条被压住、点不动**：
权限模式、模型、思考等级、麦克风、停止、发送 —— 包括发送键。
另外，输入 `/` 打开命令浮层之后再点权限按钮，权限菜单会被命令浮层盖住，看起来像「点了没反应」。

### 根因

三个浮层各自锚在不同的元素上、各自写死层级：上下文详解卡锚在**工具行下方**往上弹，
卡片底边正好落在工具行内部，把整排控件盖住；命令浮层又恰好比权限菜单高一层。

### 修复

三个浮层**统一锚在整张输入卡上方**、共用同一层级、并且**互斥打开**（打开任一个会自动关掉另外两个），
三者都支持**点击输入卡外部**与 `Esc` 关闭。权限菜单现在与输入卡左缘对齐，视觉上也更整齐。
附带修掉：命令浮层此前只能靠「输入内容变化」或 `Esc` 关闭，现在点击外部也能关。

## 🐛 三、展开 / 收起的动画不再「乱跳」

### 你之前看到的现象

工具卡展开时先「卡一下、再猛地窜出来」；收起时相反，先不动、末尾猛缩。
切换会话时列表像换了两遍、滚动条还会跳两次。

### 根因

- 展开动画的终点被写死为「窗口高度的 70%」，而工具卡的实际内容只有一百多像素 ——
  于是所有可见位移被挤在时间轴最前面一小段，剩下的时间都在空转；
- 滚动跟随收不到「过渡期间长出来的高度」的信号，所以动画还在动、滚动条已经停在半路；
- 切换会话时旧消息还占着位置 250ms，与新消息同时存在，列表高度一度接近翻倍。

### 修复

- 展开/收起的终点改成**实测内容高度**（动画曲线全程有效，不再空转）；
- 滚动跟随补上「高度过渡结束」这条信号，并在过渡期间把视口跟到底；
- 切换会话直接换内容、不再新旧同屏；工具卡的进场错位延迟也收窄了作用范围
  （此前它会误伤卡片上此后任何过渡）。

> 过程中还修掉两处更深的坑：动画**中途内容继续生长**时不能做高度动画（思考块的实时展开正好是
> 这种情况 —— 会被裁掉再补跳，已改为淡入）；以及 flex 布局会把工具卡里的**参数块压扁**成一条
> （展开时内容在动画期间被压缩、结束才弹回，已修）。

## ✨ 四、会话可以归档了

- 会话项**悬停时右侧出现「归档」按钮**，单击即归档（**可逆、不弹确认**）；
- 归档的会话收进左栏底部的**「已归档 · N」分组**（默认收起），仍然**可以点开继续对话**；
- 正在看的会话被归档时，标题旁会给一条**「已归档 · 取消归档」**提示条，一键撤销；
- 全部会话都被归档时，列表上不会再显示「还没有会话」这种自相矛盾的文案；
- **归档状态保存在会话文件里**（不写入配置），因此本次**不需要配置迁移**；
  升级前已有的会话文件照常读取（缺字段视为「未归档」）；
- 已知边界：归档只在**当前窗口**即时生效，其它窗口（如桌面提示条）要等下次刷新会话列表。

## ✨ 五、其它改动

- **斜杠命令浮层的 `Esc`**：任何情况下都能关掉它了 —— 此前若焦点不在输入框（例如刚点过权限按钮），
  `Esc` 会失灵；
- **自动化验证**：新增 4 个界面探针场景 —— 浮层几何断言（浮层与工具行矩形不相交、
  发送键中心点命中自身）、展开终点等于实测内容高度、归档分组往返（真实点击 + 撤销 + 提示条出现/消失）、
  高密度输出压力；并订正了几处文档与实现不一致的表述；
- **文档**：`docs/06 §16.3`「增量下发与渲染吞吐」、`docs/07 §2.3 / §5.1 / §5.2 / §5.3`、
  `docs/08 §1.2` 同步本轮口径。

## 🐛 已知问题（未在本版修复）

- **会话文件首次访问与写入并发时（极少见）可能出现内存中的历史被覆盖**：同一个会话在
  「第一次读盘」与「同时写入」撞在一起时会丢弃一段内存历史，并可能写到磁盘上。
  已定位到原因（读盘的完成标记早于读盘完成置位），计划在后续版本单独修复；
  日常使用（单窗口顺序操作）不会触发。
- 工具卡在 `running`（例如子代理正在跑）时展开，若恰好有一行新步骤到达，
  动画末尾会有约一行（19px）的位置修正。已记录，暂不为此牺牲这个场景的高度动效。

## ⬆️ 升级说明

- 想使用归档：把鼠标移到左栏某个会话上，点右侧出现的「归档」图标即可；在底部「已归档」分组里

  命令通道与课表契约完全不变。
- 自动更新：已安装旧版的用户会在后台收到更新提示（更新源 `LinePixel2025/Aurora-releases`）。
