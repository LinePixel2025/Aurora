# Aurora v0.5.7

本次版本汇总 **v0.5.6 → v0.5.7** 的全部更新：桌面插件**侧栏面板镜像到 Aurora Center**
（登录后在 Center 工作台侧栏直接查看并操作自己设备上的插件面板），「提醒」页聚合
**定时提醒与勿扰时段**，插件新增 **`ctx.usage` 本机用量统计**。配置 Schema 仍为 **v38**，
**无迁移**；插件契约只做加法（新增 `usage` 权限与宿主 API，既有插件不改也能用）。
Aurora Center 代码版本线独立：中心服务器同步升级到 **0.5.1**（不建 tag、不上传 GitHub
Releases），本次双投的仍是桌面安装包的三个更新资产。

## 一、Center 插件侧栏面板镜像（新能力）

桌面插件不再只属于桌面：连上 Center 后，**已启用插件的侧栏面板会自动出现在 Center 工作台
侧栏**，每个「插件 + 面板」一条入口；多台设备时在页内切换设备。

- **只镜像侧栏面板**（`contributes.panels`）：桌面小组件与提示条小组件（`contributes.widgets`）
  **永不上 Center**。插件不需要新增任何清单字段或权限。
- **按账号 + 自有设备出现**：只有当前账号自己名下、且此刻在线的设备；**管理员也看不到
  他人设备的插件面板**（插件内容属个人数据，归属只认设备属主）。
- **声明式面板**：网页端用与桌面同构的渲染器绘制，按钮、确认条、输入 / 选择控件与
  `refresh` / `event` 语义和桌面右栏一致；返回的新 schema 会替换当前面板，非法 schema
  保留旧面板并报错。
- **页面型面板**：在 `sandbox="allow-scripts"` 的 iframe 中打开，静态资源由 Center
  从**市场包**直出（`/p/<插件 id>/<版本>/<入口>`）——本机插件文件不出机；页面里的
  `window.auroraPlugin.request` / `onEvent` 经 postMessage 桥中继到本机插件进程。
  该版本**未发布到本 Center** 时，页面明确提示「该版本未发布到本 Center」，不静默白屏。
- **实时推送**：插件 `ctx.ui.panelEvent` 只在网页端订阅了该面板时转发；刷新网页或重连后
  自动重新订阅。
- **总闸**：沿用客户端的「允许 Center 远程操作本机」（`center.allowRemoteSession`），
  关闭后网页侧栏不出现任何插件入口，已打开面板的调用被拒绝。
- **边界与限制**：每账号最多 24 条侧栏入口；单次调用参数 ≤ 256 KB、回执 ≤ 512 KB、
  事件 ≤ 64 KB；每连接每秒 20 次调用、最多 64 个订阅；请求超时 20s。日志只记
  `pluginId / panelId / method`，不记参数与 payload。旧客户端不上报目录、旧服务器不认识
  新消息时均安静忽略，不影响既有功能。

## 二、「提醒」页聚合定时提醒与勿扰时段

设置 → 提醒页新增两个区组，与原有页面同一字段、同一保存语义，**即时生效**：

- **定时提醒**：自动化总开关（`automations.enabled`）+ 课前提醒三件套
  （`modes.classroom.preClassReminder` / `preClassLeadMinutes` / `preClassOpenFolder`）。
  与「模式」页和主界面自动化页改的是同一份配置；非 ClassRoom 模式或课表没有节次时，
  控件按既有门控收起并给出说明。
- **勿扰时段**：`advanced.quietHours.start` / `.end`，与「通用」页同一字段；
  留空 = 不启用，只填开始时间时按默认 `07:00` 补全。
- 本项**不新增配置字段、不升 `CONFIG_VERSION`**。

## 三、插件 `ctx.usage`：本机用量统计

插件新增 `usage` 权限与 `ctx.usage.summary({ days? })`（缺省 30 天，夹取 1–90）：

- 返回 `tokens`（总量 / 缓存命中量 / 命中率 / 轮次 / 后台自感知部分）、`images.generated`、
  `voice`（TTS / STT 次数与字符数）以及 `daily[]` 逐日数组（含空白日）。
- **只统计本机、从本版本起累积**：历史会话没有逐日时间戳，因此不回溯；账本按本地日期
  分桶、保留 90 天。
- **只存计数**：不含提示词、回复、图片、音频、文件名或任何凭据；provider 没回传 usage 的
  轮次不伪造 0，生图 / TTS / STT 失败也不计入。
- 该权限在安装确认里逐条展示；示例插件 `hello-aurora` 与 `plugin-dev-kit` 已同步用法。

## 四、兼容与升级

- 配置 Schema 保持 **v38**，本次**没有迁移**；已有设置原样保留。
- 插件契约向后兼容：`usage` 是新增权限，未声明的插件行为不变；Center 面板镜像不要求
  插件改清单，声明式面板开箱即用，页面型面板需把该版本发布到 Center 市场才能加载资源。
- Center 服务器升级到 **0.5.1**（插件面板中继、`/p/` 资源托管、owner 校验与限速）；
  旧客户端连新 Center 不会出现插件入口，其他功能不受影响。
