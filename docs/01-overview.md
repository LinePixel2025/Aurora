# 01 · 项目总览

状态：`已定稿`（v1 基线）

## 1. 产品定位

Aurora 是一款**常驻 Windows 系统托盘的系统级 AI Agent 工具**，把 Windows 接入 AI 生态，为用户提供**无感、自主**的 AI 服务：

- **无感**：不打断用户当前工作，以屏幕右侧提示条（悬停展开面板）等轻量形态存在，随取随用、用完即隐。
- **自主**：AI 能实时感知系统状态并主动服务——如模式切换后主动引导配置、新文件自动分类、上课前自动打开科目文件夹。
- **可扩展**：内置 **Skill** 系统与 **MCP** 支持，能力可插拔、可扩展、可接入外部数据源。

目标用户（v1）：学生（首发 ClassRoom Mode）→ 后续扩展办公人群（Work Mode）与开发者（Code Mode）。

## 2. 设计原则

1. **常驻而克制**：常驻托盘，但默认以最小占用形态存在（屏幕右缘 8px 提示条），需要时再展开完整窗口。
2. **主动而不冒犯**：AI 主动发起引导与提醒，但所有主动行为均可配置、可关闭，且支持静默时段。
3. **感知驱动**：一切主动行为基于系统感知（时间、课程表、文件事件、电源、前台应用等）触发，而非无差别打扰。
4. **模式即上下文**：Work / Code / ClassRoom 三种模式为 AI 提供不同的上下文、提示词与能力集合。
5. **安全透明**：AI 的敏感操作（移动文件、执行命令等）必须可解释、可确认、尽量可回滚；凭据本机加密存储。

## 3. 核心概念（名词表）

| 名词 | 说明 |
|---|---|
| **模式（Mode）** | 三大使用场景：Work Mode（办公）、Code Mode（编码）、ClassRoom Mode（课堂学习）。同一时刻仅启用一个，可在设置中切换；切换后 AI 主动引导完成该模式的设置。 |
| **提示条（Edge Bar）** | 桌面右缘的常驻提示条（8px 竖条 + AI 状态灯）；**悬停**展开面板，**点击**在桌面拉出完整的 AI 交互窗口。这是删除「AI 服务窗」后**唯一的常驻入口**（另有托盘与全局快捷键）。 |
| **AI 交互窗口（Chat Window）** | 完整对话窗口，支持 Markdown、代码块、工具执行过程展示，从提示条拉出；侧栏为「快速 / 会话」双栏（快速会话没有独立窗口），标题栏「收起」= 直接隐藏窗口。 |
| **智慧感知文件夹（Smart Folder）** | ClassRoom Mode 核心：用户把新文件拖入该文件夹，Aurora 智能分析文件内容，自动分类进对应科目文件夹。 |
| **Agent 内核（Agent Core）** | 对话、工具调用循环、Skill、MCP、系统感知的统一运行时（`packages/agent-core`）。 |
| **Skill** | 以 `SKILL.md` 描述的可复用能力包（指令 + 可选脚本），AI 按需自动匹配或由用户显式调用。 |
| **MCP** | Model Context Protocol，连接外部数据源 / 工具服务的开放协议，由 Agent 内核统一托管。 |
| **系统感知（Perception）** | Aurora 实时感知系统状态的能力（时间 / 课程表、电源、网络、前台应用、显示器等），用于注入 AI 上下文与触发主动行为。 |
| **主动引导（Proactive）** | AI 在特定事件（首次安装、模式切换、分类完成、课前提醒）下主动发起对话的机制。 |

## 4. 范围与非目标

### 4.1 v1 范围（P0 / P1）

- 托盘常驻 + 设置窗口 + **首次安装引导**（AI 模型配置为必填）
- 通用交互 UI：**右侧提示条**（唯一常驻入口）、**AI 交互窗口**（侧栏含「快速 / 会话」双栏）、设置窗、引导窗
- **Agent 内核**：多模型流式对话、工具调用循环、Skill 系统、MCP 支持、系统感知
- **模式系统框架** + **ClassRoom Mode** 完整实现：智慧感知文件夹自动分类、对话式引导、手动课程表课前提醒
- Work Mode / Code Mode **接口预留**（注册占位，不实现功能）
- 打包发布（Windows 安装包）

### 4.2 非目标（v1 不做，但预留）

- Work Mode、Code Mode 的功能实现（仅定义 `IMode` 接口与能力位，见 05 §4）
- 与 **ClassIsland** 的联动（仅预留 `IScheduleProvider` 集成点，见 05 §3.4）
- 跨平台（macOS / Linux）：架构上不锁死（agent-core 不依赖 Electron），但不承诺 v1 支持
- 云同步 / 多设备、自动更新（后期接入）

## 5. 成功标准（v1 验收）

- [x] 首次安装 → 完成引导 → 托盘常驻，全程 5 分钟内完成（v0.1.0 已达成；引导 5 步，模型配置必填）
- [x] 交互窗输入 → AI 回复，首字延迟 ≤ 3s（正常网络、本地模型另计）
      —— v0.3.0 起为真实模型流式回复（`KernelAgentHost`）
- [x] 新文件拖入智慧感知文件夹 → 30s 内完成分类并发出系统通知

      → 落盘 + 系统通知 + 分类流水（`AURORA_SMOKE=1 pnpm dev` 实时投放文件端到端断言）
- [ ] 分类准确率：常见文档（PDF / Word / PPT / 图片 / 压缩包）≥ 90%
      —— 内容提取链路已实测可用（`officeparser` 解析 pdf/docx/pptx/xlsx 等，
      `AURORA_SMOKE=1 pnpm dev` 证明提取结果真的进入分类判定），并配有规则优先、
      置信阈值与「待分类」兜底；

- [x] Skill 与 MCP 均可通过设置界面安装 / 配置并实际生效
      —— v0.3.0 起 `use_skill` 注入技能正文、MCP 工具注册为 `mcp.<server>.<tool>` 并可被调用
- [x] 系统感知信息可注入 AI 上下文，且能被 AI 正确引用（“我电脑现在什么状态”类提问）

      `perceptionSummary` 进入系统提示词；`system-status` Skill 可直接读取当前值
- [x] 课前提醒按课程表触发并自动打开对应科目文件夹
