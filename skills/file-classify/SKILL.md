# file-classify

## 目标

给定一个刚进入「智慧感知文件夹」的文件，输出它应该归属的科目。

## 输入

- `path`：文件绝对路径
- `evidence`：内容证据（文档前 N 段文本 / 图片元数据 / 压缩包文件名），上限 8KB
- `subjects`：当前科目列表与每科关键词

## 步骤

1. 先看文件名：命中的科目关键词优先级最高（如「数学试卷.pdf」→ 数学）。
2. 再看内容证据：找学科特征词（公式、文言文、单词表、电路图、化学式等）。
3. 仍不确定时参考文件类型与来源目录（如 `课件/`、`作业/`）。
4. 输出结构化结果：

```json
{ "subject": "数学", "confidence": 0.0, "reason": "判定依据（一句话）" }
```

## 约束

- 只允许输出科目列表中的科目名；无法判断时输出 `"subject": ""` 并给出 `reason`，由上层放入「待分类」。
- `confidence` 低于阈值的样本一律走「待分类」，不要猜。
- 不要编造文件中不存在的内容作为依据。
